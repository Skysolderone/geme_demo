# 视觉风格基准（设计文档 §20，tactical-ui 裁决 6 / 7）

正式视觉方向：**明快低多边形奇幻棋盘**。3D 低多边形、固定倾斜俯视镜头；场景是悬浮于奇幻世界中的立体战争沙盘，温暖自然光、低多边形地貌，哑光石材、木材与布料质感。

## 基准图的适用范围

- 首张基准图：`siege-style-03-low-poly-fantasy.png`。
- 本目录全部参考图**只用于确定材质、色彩、轮廓与信息层级**。
- 参考图**不代表最终地图布局与固定 UI 尺寸**：制作新地图或 UI 布局时参考其材质、色彩、轮廓与信息层级，但不照搬其地图布局与 UI 尺寸。
- 画面中的 `ROUND 7` 标识**仅表示当前大回合**，不表示总回合数，不具任何规则含义。

## 落地约定（数据层在 `src/Siege.Presentation/Style/VisualBaseline.cs`）

- **阵营**：PlayerId 0–3 → 红 / 蓝 / 金 / 紫主色 + 三角 / 塔楼 / 太阳 / 莲花旗帜图案。阵营辨识不得只依赖颜色。
- **棋子轮廓**（程序生成的低多边形几何体）：普通子 = 圆头兵、堡垒子 = 塔楼、连珠子 = 双球连杆、倍增子 = 金字塔、协同子 = 多瓣水晶。
- **HUD 布局**（按参考图）：左上回合旗标、顶部中央行动顺序条（展开即顺序层）、右上排名、左下手牌、底部中央五个信息层按钮（Territory / Liberties / Influence / Relic / Hand）、右下结束回合。
- **UI**：深色半透明面板、克制的金色边框、高对比信息色，PC 策略游戏信息密度；不采用手游广告式大按钮与夸张弹窗。
- **预览与信息层**：暂放棋子半透明发光；预计提子用清楚但克制的虚线 / 轮廓；信息层临时压低场景饱和度与装饰对比。
- **判读优先**：方格边界始终清晰；树木、遗迹、水面、高低差只作不可通行地块或装饰，渲染层级在一切判读信息（网格、落点、气、归属、棋子、预览）之下。障碍格用简单岩石几何体表示；装饰与正式美术资源不在 tactical-ui 范围内。
