## 渲染约定（BoardGeometry / BoardView）

| 要素 | 画法 | 数据来源 |
|---|---|---|
| 高度 0 / 1 / 2 | 地砖按层堆叠，每层抬升 `LayerHeight = 0.35` 格宽；h=1 层侧面土色、h=2 层侧面岩灰 | `BoardCellView.Height` |
| 崖壁（Δh=2） | 露出土色 + 岩灰两条色带，高 0.70 格宽 | 相邻格高度差 |
| 缓坡（Δh=1） | 只露一条土色色带，高 0.35 格宽 | 相邻格高度差 |
| 深水 | 比同层地砖低 0.10 的蓝色水面（与底座齐平）+ 两道浅色波纹，没有地砖 | `Surface.DeepWater` |
| 桥 | 木板面与同层地砖齐平 + 四根角柱（0.07 见方，不占落点） | `HasBridge` |
| 林地 | 深绿地表 + 三棵小树放在地砖角上（树冠半径 0.09，落在棋子底座之外） | `Surface.Forest` |
| 土路 | 暖色地表，只作视觉 | `Surface.Road` |
| 栅栏 | 三根立柱 + 两根横杆，放在两格之间的缝上，厚 0.05 | `DefaultBoardView.Fences` |
| 岩石 | 灰色地砖 + 低多边形岩石（按该格高度抬升） | `Terrain.Obstacle ∧ Surface ≠ DeepWater` |
| 坐标标注 | 平铺在棋盘外圈 h=0 平面，近边与左右离边缘格格心 `LabelMargin = 1.2` 格，远边 `FarLabelMargin = 1.7` 格（远半盘射线仰角只有约 46°，顶行 h=2 地砖向远处投 ≈ 1.2 格遮挡） | `Coord.Column / Row` |
| 相机 | 固定俯角 60°（对注视点）：盘心附近 h=2 高台向远处只投 0.40 格遮挡，紧贴崖壁身后的 h=0 格格心仍能点到；远半盘射线更平（45–50°），v3 远半盘没有紧贴崖壁的低地可落子格 | — |

## 已知限制

- 桥面没有方向：桥用四根角柱而不是两侧栏杆，因为视图模型不带"水流方向"，栏杆方向无从推出（推的话就是 Godot 自算邻接）。
- 深水与岩石都按视图模型的高度抬升；v3 上它们都在 h=0 或 h=2 外圈，看不出差别。
- 左下角的 `A` 与 `1` 仍可能被手牌面板部分遮挡（与 `art/coord-labels/README.md` 相同）。
- 相机固定；引入相机旋转前不要动标注的平铺方式（见 `art/coord-labels/README.md`）。
- 插旗提示面板放在左列、通知条放在顶部顺序条之下：两者原位置（顶部居中 / 底部居中）在 13×13 + 60° 相机下分别压住远边与近边标注。
