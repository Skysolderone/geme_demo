# map-elements-v2 人工检查清单

本清单随实施逐段补充，段 E 定稿（tasks 5.3）。**当前进度：段 A（地块）已做完，等负责人确认方向；段 B–E 未开始。**

## 取图口径

- 机器：macOS / Apple M3 / Metal 4.0 Forward+，Godot 4.7.2 .NET，窗口 1600×900。改前改后都在这台机器上取，与 Windows 上的历史截图不可比。
- 命令：`--auto-demo --map=<图> --screenshot=<png>:<帧>`，无人值守演示种子固定；近景另加 `--shot-cell=<格> --shot-zoom=<档>`，压暗图加 `--shot-ownership`（第 40 帧）。
- 同参数重复取图：没有水面的图逐像素相同；有水面的图只在水面动画区域不同（v5 的外接矩形 x 574–998、y 283–645）。
- 每张图旁边的 `.log` 是当次运行的完整输出，含 `[parts]` / `[batch]` / `[perf-steady]` 自证行。

## 段 A——地块（待负责人确认）

改了什么：地砖顶板四边倒角、顶面分成带亮度细差的小面（3 档网格 × 4 个朝向，按格坐标散列挑）；

配色没有动：顶点色只当亮度系数，材质仍按原底色共用。

## 段 B——水系与设施
