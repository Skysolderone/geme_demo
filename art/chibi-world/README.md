# chibi-world：全部素材卡通化 · 人工检查清单

任务：`.trellis/tasks/11-21-chibi-world`。风格依据与单位相同：`art/chibi-pieces/README.md`、`art/chibi-pieces/reference.png`。特征是卡通分阶明暗、粗黑描边、饱和配色。

三段串行，本文件按段追加：
- 段 ①：装饰 18 类（本节）
- 段 ②：地块 + 浮岛
- 段 ③：天空 + 标记 + 界面

## 段 ①：装饰 18 类

`tools/blender/chibi_terrain.py` 生成 `src/godot/parts/terrain_chibi/<名>[_<档>].glb`，共 19 种 Kind、67 个文件。栅栏的 `fence_x` / `fence_z` 合算一类。

运行时由 `TerrainParts` 加载，装饰的加载链是：

1. `terrain_chibi/<名>.glb`
2. `terrain_full_art/<名>.tscn`（改前样式）
3. `LowPoly` 程序生成

删掉 `terrain_chibi/` 即回到改前样式。地块部件（地砖、侧面、浮岛等）不走这条链，本段不动。

脚本断言（超限不导出，退出码 1）：

| 断言 | 内容 |
|---|---|
| 档数 | 从 `TerrainParts.cs` 读各 Kind 的档数（字面量或 `LowPoly.*Variants`），与脚本里的 `VARIANTS` 逐个核对，不一致则什么都不导出 |
| 预算 | 本体 ≤ 600 三角形；描边 ≤ 本体；材质槽（含 Line）≤ 7（裁决 6 加 Glow 槽后由 6 放宽，与单位上限一致） |
| 包围盒 | 本体不超出 `terrain_full_art` 同名旧部件的实测包围盒，容差 0.006 |
| 包围盒的比较口径 | 格角点缀（草丛、小石、小花、石碑）逐档比；宝箱两档取并集；其余按同类各档的并集比 |
| 不挡格心与单位 | 放在可落子格上的装饰（林地小树、荒漠、沼泽、岩台、浅滩、桥、草丛、小石、小花、石碑），格心半径 0.36（棋子脚下圆环）内的最高点 ≤ 0.007，即只许贴地薄片。0.007 与旧水洼同高，领地着色在 +0.008 |
| 法线朝外 | 每个零件的面法线按面积加权后须朝外，否则描边外壳会整件发黑。荒漠第 4、5 档是镜像档，镜像后把全部面翻回 |
| 石碑例外 | 石碑格心圈内上限放宽到 0.045：碑座内角与旧石碑同位，在 0.315 处，高 0.04 |

### glb 契约与运行时

**命名与坐标**

- 物体名 `<槽>_<部件>`，不建父子层级，导出时应用变换。
- 各档的整体朝向（遗迹、晶簇、火盆、拱门、宝箱转角，荒漠镜像）直接烘进网格。
- 原点 = 所在格地砖上表面，与 `Kind.Anchor` 一致。Blender 的 −Y = Godot 的 +Z。

**材质槽**

| 槽 | 用途 | 运行时材质 |
|---|---|---|
| Stone | 石材 | 卡通分阶（`Visuals.Toon`） |
| Shade | 深色石 / 深木 / 沙纹 / 裂纹 | 卡通分阶 |
| Wood | 木料 | 卡通分阶 |
| Leaf | 深绿 | 卡通分阶 |
| Moss | 浅绿 / 青苔 | 卡通分阶 |
| Water | 水洼 | 卡通 + 卡通高光 |
| Crystal | 紫晶 | 卡通 + 卡通高光 + 自发光 0.22 |
| Gold | 金饰 | 卡通 + 卡通高光 |
| Flame | 火舌 | 不受光、不投影 |
| Bloom | 花瓣 / 浅色点缀（桥板、箱盖、浅晶、余烬按种类取色） | 卡通分阶 |
| Bone | 象牙：兽骨、绳、白水纹 | 卡通分阶 |
| Line | 描边外壳 | 见下文"描边" |

颜色按（种类, 档, 槽）取：`TerrainParts.ChibiColor`。同槽同色全图共用一份材质。

**描边**

- `Line_Hull` 由本体沿顶点法线外推得到，运行时成为名为 `Outline` 的节点。
- 材质是全图共用的一份 `Visuals.Outline(Visuals.OutlineInk)`：只画背面，不受光，墨色 (28,24,30)，不投影。
- 拾取沿用 `PieceModels.IsOutline` 的约定。
- 贴地薄片（沙纹、裂纹、水洼、睡莲叶、浅滩水纹）标 flat，不进外壳。所以荒漠、沼泽、岩台、浅滩的描边面数少于本体。

**加载与合批**

- glb 实例化后，`TerrainParts` 按槽合并成"根下一层、每槽一个网格 + 一个 Outline"。每档只合并一次并缓存，网格与材质在各实例、各区块之间共用。
- `BoardView.PartBatchSet` 无需改结构即可合批：每个槽、外加描边，各一个 MultiMesh。

**共用材质工厂**

- `Visuals.Toon` / `Visuals.Outline` / `Visuals.OutlineInk` 从 `PieceModels` 提出，单位与装饰共用。
- 单位外观不变：改前、改后的 `--piece-gallery` 两张图（十种 + 四阵营）逐像素一致（MD5 相同）。

描边厚度按装饰尺寸定（起点 0.02），由脚本中的 `OUTLINE` 设定：

| 档位 | 厚度 | 种类 |
|---|---|---|
| 大件障碍 | 0.018–0.022 | 岩石、遗迹、松树、晶簇、火盆、拱门、宝箱 |
| 中件 | 0.012–0.015 | 小树、荒漠、沼泽、岩台、栅栏、桥、石碑 |
| 小件 | 0.010 | 浅滩、草丛、小石 |
| 最小件 | 0.007 | 小花 |

## 段 ②：地块 + 浮岛

地块与浮岛**不重新建模**：网格仍取 `terrain_full_art/*.tscn` 的快照（或程序生成），只在运行时换材质、换色板，并在高差处加描边。

**材质**

- 地砖、衬底、缓坡、崖壁、河岸泡沫、石沿、台面边框 / 转角：一律 `Visuals.ToonVertex`，即 `Visuals.Toon` 加顶点色。顶点色色带（岩缝、土沿、倒角）保留，分阶明暗叠在色带上。
- 浮岛岩层 / 垂岩 / 云团、岛面、岛崖、根须：同上。
  - 云团另设半透明（α 取色板）、不接收阴影。
  - 浮岛岩层（`island_layer`）对局里没有摆放，只在 `TerrainParts` 里换了材质；岛的轮廓实际由 `BoardView.AddFloatingIsland` 现场搭的阶梯断崖画出。
- 深水水体：`Visuals.Toon(色, specular: true)`，同装饰水洼。
- 保持不受光（不改）：领地着色、出生区亮条、格线、`TerrainShadow` 的高差压暗、水面流动层。
- 瀑布：仍是滚动条纹着色器（不受光、半透明），只把 `water` 色换成色板值。换成卡通材质会丢掉流动，所以没换。
- 部件自带材质的替换在 `TerrainParts.PieceOf` 里做：按（种类, 档）各建一份卡通材质并缓存，合批键不变。

### 高差描边（裁决 4 / R2.3）

材质全图一份 `TerrainParts.ReliefOutline`，即 `Visuals.Outline(Visuals.OutlineInk)`：只画背面、不受光、墨色同单位、不投影。描边节点名为 `Outline`，拾取跳过。

**崖壁 / 缓坡外缘**：`TerrainParts.EdgeOutlineMesh`，一条格边一件。

- 只摆在"邻格比本格低"的格边上。邻格层数读全图岛面格表，虚空按 0 层算。
- 两条外缘都更低的格角另补一件 `CornerOutlineMesh`，补上凸角缺的那一小方。
- 同高相邻的格之间什么都不摆，平地之间没有描边。
- 每件由两部分组成：
  - 外壳竖墙：崖面外推 0.035，从棱线上方 0.035 落到两层之下，埋进低处地面；正面朝外，所以只有背向相机的远侧崖沿露出一线。
  - 压边：棱线外侧一条宽 0.035 的水平带，正面朝下。俯视时总能画出来，所以朝相机的崖沿也有墨线。单纯的反向外壳做不到这一点，因为朝相机那面的外壳会被剔除。
- 棱线高度：
  - 大图：面砖铺满整格，取面砖上表面。
  - 小图：面砖内收，取衬底顶（面砖上表面下 0.04）。

**台面外框**

- 连体棋盘的边框件 / 转角件：各配一份反向外壳（`TerrainParts.HullOf`：顶点按位置焊接、法线按面积平均，再外推 0.035），按网格归并成 MultiMesh。
- 单块棋盘的四条边框盒：各配一个外推 0.035 的盒子。按块计，不按格。

**浮岛外轮廓**

- 阶梯断崖：每段剖面沿该格角的斜接方向再外推 0.08（斜接保证转角处外壳相接）。
  - 顶上多一圈：从棱线上方 0.08 落到岛面。
  - 最后一圈（岛底收口）再往下推 0.08。
  - 棱线外侧一条朝下的压边。
  - 瀑布口不描。
  - 全岛合成一个网格。
- 垂岩：`HullOf` 外推。实例按 (0.38, 长, 0.38) 非等比缩放，外推量按缩放的倒数补偿，世界厚度约 0.06。同档与本体同变换，各一个 MultiMesh。

**平地（地砖、衬底）不描边。** 对照图（大图同款，棱线取面砖上表面）里的取样（`surface-swatch-A.png`，日志 `取样 *-crest-* / *-seam`）：

### 天空（R3.1）

两版都是 Layer −1 的画布背景（环境 `BGMode.Canvas`），代码在 `SkyBackdrop.cs`。

- 不动灯光、环境光、色调映射和 SSAO，段 ② 的取样数字仍然有效。
- 没有随机数，云是静止的，同一机位截图可以复现。
- 原图缺失时退回引擎的程序天空，与改前一致。

**image（缺省）：原图调色。** 着色器在 HSV 空间按色相分段处理：

| 色相段 | 原图里是什么 | 处理 |
|---|---|---|
| 粉 / 品红（0.86–1.0 与 0–0.03） | 云的粉色阴影 | 色相拉到天蓝 0.58，饱和 ×0.35，读作白云的淡蓝阴影 |
| 淡紫（0.70–0.86） | 远山、雾 | 色相拉到蓝灰 0.62，饱和 ×1.1 |
| 天空（0.44–0.66） | 天空 | 色相向蔚蓝 0.575 拉 60%，饱和 ×1.18；只提饱和的话天空会发青 |
| 低饱和暖色（0.03–0.14，饱和 < 0.3） | 云的桃色亮面 | 饱和 ×0.55，云读作白色 |
| 其余 | 岛上的绿、暖色岩石 | 饱和 ×1.30 |

最后以 0.5 为中点，对比度 ×1.06。各段交界用 smoothstep 过渡，不出色带。

**toon：代码绘制。**

- 天空：竖向四阶分段渐变，自上而下为 46,126,218 / 71,152,232 / 107,183,242 / 160,213,249。
- 云：七朵卡通云，每朵是五个圆的并集再把底边削平。亮面 253,254,255，下沿一条暗面 195,216,242，共两阶。
- 云的外缘有一圈 0.0045 屏高宽的深天蓝细线（62,114,184）。没用墨色：天空是远景，墨线会和盘面描边抢视线。
- 屏幕底部一条云海。
- 纵横比取自 `SCREEN_PIXEL_SIZE`，窗口改尺寸后云不变形。

### 地图标记（R3.2）
