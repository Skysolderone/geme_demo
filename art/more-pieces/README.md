## 画法约定（四种新轮廓，`LowPoly.PennantParts / ChainLinkParts / CrossedSpearParts / SteleParts`）

| 棋子 | 画法 | 与易混对的判据 |
|---|---|---|
| 旗手子 | **竖直**细杆（半径 0.025、高 0.80）+ 杆脚矮圆台 + 杆头小球 + 杆右侧一面阵营色方旗（0.26×0.20），总高约 0.9，十种里最高 | vs 匠人：匠人柄斜 14°、顶上横置实心槌头、另有斜撑，整体歪向一侧；旗手的杆绝对竖直、细得多，顶部是一块薄旗面 |
| 铁链子 | 两节竖立长圆环（外半径 0.13、内半径 0.085、竖向拉长 1.35 倍）**上下相扣**：下环正对镜头（本体色，中间透出地砖），上环侧立（阵营色，一道竖直窄椭圆） | vs 连珠子：连珠是左右两个**实心**球 + 横杆 + 中柱（横放哑铃）；铁链没有球没有杆，环中有洞 |
| 哨兵子 | 两支长矛（0.62）在正面各斜 24° **交叉成 X**，矛尖四棱锥朝上，交叉处一道阵营色绑绳 | 十种里唯一的 X 字形，左右镜像对称（与匠人的"主干斜立、整体歪向一侧"分得开） |
| 界碑子 | 扁基座 + **矮宽**碑身（宽 0.52、高 0.26、厚 0.11）+ 顶部圆弧，整块后仰 14°（60° 俯视下让碑面多露出来），碑面两道阵营色横纹；总高约 0.5 | vs 堡垒子：塔楼高约 0.7、粗圆柱 + 顶圈 + 四枚雉堞；界碑矮、扁、顶上一整道圆弧，碑面有两条横纹 |

工坊高亮不另起画法：隔一格的格目标与几何四邻的格目标同一套"冷青白薄色块 + 虚线环"（`art/artisan-v4/README.md` 画法约定），
"哪格是隔一格"由位置本身回答（距落点两格）。目标集合来自富预演（← 改造合法性唯一实现，工坊标记经批次上下文传入），Godot 不自判。

## 像素自查（不看图，只数像素；脚本在实现会话的 scratchpad，数字记在这里）

十种对照图：按"红通道占优"（阵营红 / 本体粉，草地、天空、标签都不满足）分出十枚棋子的外框，再以外框底边中点为锚取同样大小的窗口、缩到 1/4 后比**平均绝对灰度差**。

| 对 | 灰度差（1/4 缩略图） | 外框高 / 宽（像素，原尺寸） |
|---|---:|---|
| 铁链 / 连珠 | 11.4 | 107×105 vs 96×122；顶部 1/4 宽 51 vs 113 |
| 界碑 / 堡垒 | 13.2 | 105×105 vs 137×104 |
| 旗手 / 匠人 | 23.9 | 131×123 vs 118×161；顶部 1/4 宽 86 vs 153 |
| 原六种两两之间的最小值（倍增 / 协同） | 9.8 | — |
| **十种 45 对里的最小值：界碑 / 普通** | **8.4** | 105×105 vs 110×106 |

三组易混对都高于原六种之间已经接受的最小差（倍增 / 协同 9.8）。**界碑 / 普通子是十种里灰度差最小的一对（8.4），低于原六种的最小值**——
60° 俯视下两者都是"底座圆盘上一块中等高度的浅色体"，界碑已加宽加高、后仰并加两道横纹（从 6.3 提到 8.4）。它不在规格点名的三组易混对里，
留给负责人看图决定是否再改（例如把界碑再压矮、加宽到接近底座直径）。这项数字只是粗指标：窗口主要被底座圆盘占据，判读以人眼为准。
