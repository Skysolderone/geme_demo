## 人工检查清单（负责人对照）

1. 主题名可读：`flags-themes` 里每个占位的编号下方是中文主题名，不是方块 / 问号；字号小于编号、灰度与编号相同；新局界面（`--map-select`）的占位只有编号、没有主题名。
2. 核心区亮条位置：各 `theme-*` 里阵营色描边只围棋盘正中的 3×3（偶数边长时偏西 / 偏南一格），描边贴格内侧、不压到相邻格；整块棋盘的外框仍沿整块外接矩形一圈。
3. 各地形部件可辨：高台的崖壁（两道色带）与坡（一道色带）分得开；深水比地砖低、桥面与地砖齐平；栅栏立在格缝上；林地格有小树；棋盘内岩石是岩石造型。没有任何一格空缺或透出底座。
4. 接缝连成一片：`spliced-closeup` 两块棋盘之间无边框、无缝隙，格线连续；`splice-mid` 滑入方棋盘上的树、栅栏与地砖同步移动。
5. 格线与高差：高台、深水格上的格线是否显眼或被遮挡得别扭（格线画在 h=0 面上，高台格只靠地砖缝读格界）——若觉得不清楚，记为后续视觉项。
