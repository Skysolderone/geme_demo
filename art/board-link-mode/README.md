## 人工试玩检查清单（负责人对照）

1. 占位可辨：插旗与对局中，他人出生棋盘只有灰边框 + 编号，灰度与自己台面边框明显不同；点占位无效果。
2. 拼接动画：本机参与链接时依次是 对方棋盘从接缝一侧滑入贴合（棋盘上的边框、格线、信物 / 改造 / 禁手标记与信息层叠加物随地砖一起滑；本机是被贴方时本机棋盘滑过去、相机随本机棋盘同步移动）→ 相机重定界到合并战场一屏可见 → 对方棋子 / 设施 / 已揭示信物显现 → 横幅"棋盘拼接：与 X 交战"，约 3.2 s，按住空格 / 左键提速；他人链接无动画。
3. 接缝连成一片：拼接后两块出生棋盘之间没有边框、没有缝隙，格线照常连续；边框只沿合并战场的外轮廓一圈；本机阵营色描边只在自己那块的外缘。
4. 他人链接画面不跳：他人链接把本机战场收拢平移时，本机棋盘在画面里位置不变（相机注视点随之平移），没有演出。
5. 横幅顺序：本机战场结算先"战场胜出" / "战场落败（第 N 名）"再出局横幅；决赛结算只有终局横幅，不重复。
6. 他战场数值不可见：势力排名栏、势力层、顺序层、手牌对比里他战场玩家只剩名字 + 在局 / 出局 + "所在战场已结算（胜出）"，无数值、无手牌类型。
7. 相机范围：推屏止于"当前战场 ∪ 5 块占位"的包围盒，空格回家回到自己棋盘；链接后范围随新布局变化、位姿不复位。
8. 全局预览：战场一屏看全时没有"全局 [M]"按钮；预览只盖当前战场。
9. 提示条：他场结算提示依次显示、每条约 3 s 后消失，多条不互相覆盖。
