## 已知限制

- 地标尺寸按格宽 1.0 设计，在 1600×900 整盘视图下单个地标只有几十像素；三档靠轮廓与高度区分，火苗自发光帮助篝火在远半盘也能看出。
- 退到格角后的旗帜只有 0.62 倍，远半盘上徽记图形可能偏小；此时棋子本身带阵营徽记，控制方仍可由棋子读出（占据时控制者就是棋子主人）。
- `--auto-demo` 只跑 4 个大回合，"中局"截图取第 4 大回合（第 44 帧，信息层关闭）；终局图（第 90 帧）的据点状态与中局相同，居中的结算面板盖住岛心，地标以中局图为准。
- 争议旗不带覆盖方信息（覆盖方在势力层面板里读）。
- 规格场景的具体实例在截图里没有一一对应：「控制方可辨」写的是**石碑**被唯一覆盖（中局图石碑全是争议，第 4 / 5 项改用篝火的旗）、「争议与无人可区分」写的是两个**篝火**（中局图争议在石碑、无人是营帐与篝火）。旗帜画法与档位无关，判读不受影响；若负责人要求逐字对应，需另挑帧补图。
- 「占据时棋子可被拾取」：拾取是数学投影、地标无碰撞体（`LowPoly` / `BoardView` 中无 `CollisionShape` / `StaticBody` / `Area3D`），不需看图；第 7 项只看"可见"。
