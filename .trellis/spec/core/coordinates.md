# 坐标

## 围棋记法是权威记法

- 列字母 `A`–`L`，**跳过 `I`**（围棋惯例）：`A B C D E F G H J K L`，共 11 列
- 行数字自下而上，从 `1` 起
- 左下角为 `A1`

日志、错误信息、测试用例、规格文本与一切面向人的输出 MUST 使用该记法。

**为什么。** 对局记录要能被人直接复盘。代价是多一层映射，这是有意支付的。

## 映射唯一

围棋记法 ↔ 内部数值索引的双向映射 MUST 只有一处实现。往返转换必须是恒等的。

内部用什么索引形式是实现细节，但不允许第二处转换逻辑，也不允许在别处手写字母表（尤其不要忘了跳过 `I`）。

## 四邻接

邻居 = 左右相邻列的同行格 + 上下相邻行的同列格，且位于棋盘内。

- **不含斜向**，任何规则都不例外
- 越界方向与障碍格具有完全相同的封堵语义
- 连接、气、覆盖、围杀共用同一个遍历实现

角格 `A1` 的邻居恰为 `{B1, A2}`。
