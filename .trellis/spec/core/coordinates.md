# 坐标

## 围棋记法是权威记法

- 列字母自 `A` 起、**跳过 `I`**（围棋惯例），个数随棋盘宽度：11 列 `A B C D E F G H J K L`，13 列（v3 基准图）`A B C D E F G H J K L M N`。字母表只在 `Coord.ColumnLetters` 一处，任何地方写死 11 列或 `A–L` 都是缺陷（`terrain-model` 段 B 清过一轮）
- 行数字自下而上，从 `1` 起
- 左下角为 `A1`

日志、错误信息、测试用例、规格文本与一切面向人的输出 MUST 使用该记法。

**为什么。** 对局记录要能被人直接复盘。代价是多一层映射，这是有意支付的。

## 映射唯一

围棋记法 ↔ 内部数值索引的双向映射 MUST 只有一处实现。往返转换必须是恒等的。

内部用什么索引形式是实现细节，但不允许第二处转换逻辑，也不允许在别处手写字母表（尤其不要忘了跳过 `I`）。

## 几何四邻与两套导出关系

**几何四邻**：邻居 = 左右相邻列的同行格 + 上下相邻行的同列格，且位于棋盘内。不含斜向，任何规则都不例外。角格 `A1` 的几何邻居恰为 `{B1, A2}`。

几何四邻本身**不是规则邻接**。规则走的是在它之上由格属性实时导出的两套关系（见 `boundaries.md` 单一实现表）：

| 关系 | 切断条件 | 对称 | 消费者 |
|---|---|---|---|
| 气边 | 障碍、未架桥深水、abs(Δh) ≥ 2、栅栏 | 是 | 连接、棋串、气、围杀、连珠成线、校验器距离 / 口袋 / 出生区连通 |
| 覆盖关系 | 障碍、林地（不接收）、h_t − h_s ≥ 2；一格宽深水则落到对岸 | 否 | 覆盖、空格归属、唯一覆盖、信物发现 |

越界方向与障碍具有完全相同的封堵语义。

标准算例（与 `terrain` 规格、设计文档 §3.1 一致）：h=0 的 `F6` 上方 h=2 的 `F7` → 不计气、`F7` 上的棋子覆盖 `F6` 而 `F6` 不覆盖 `F7`；`F6`–`G6` 有栅栏 → 不成串、`G6` 非气、但 `G6` 被覆盖；`F6`→深水 `G6`→同高 `H6` → `H6` 被覆盖、`G6` 不记录。

## 高度进 3D 坐标

`BoardGeometry.Center(coord, width, height, level)` 带层高（`LayerHeight`），坐标标注锚点用 h=0 的三参重载放在棋盘外圈。相机 60°（45° 时远半盘高台拾取失准）。改相机或层高必须重跑 `--auto-demo --pick-check`（见 `testing.md`）。
