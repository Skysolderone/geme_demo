# 11-02 large-default：新局面板默认大图

## 背景
big-map（11-01，合并 d5b4e8ab）做出了 150×150 大图，但新局面板默认尺寸仍为"小（浮空岛）"，打开就是旧的 49×49 座位盲选预览与座位口径文案，必须手点"大"才切换；选大图后预览走分块流式加载（只建注视点周围 ±2 分块），小地图在选图阶段被隐藏，看不到整块大陆。负责人 2026-11-02："为什么一开始选择地图的页面还是这样 需要变更"。

## 裁决（负责人 2026-11-02 全按推荐）
1. 新局面板默认尺寸改为"大"：打开即 150×150 大陆预览 + 大图说明，标识缺省 `link:<种子>:<人数>:l`。Godot 有人值守、未给 `--map=` 时进面板即默认大图。Sim 命令行缺省（link:1:4）与 Godot 无人值守缺省（MapCatalog.DefaultId）不动，基线与自检命令依赖小图。
2. 小图去留：选项保留，排在"大"之后并标"旧模式"（显示名形如"小（浮空岛，旧模式）"）；不删小图模式，不改小图任何行为。
3. 面板文案：顶部说明与尺寸提示先写大图、后写小图；默认态开头用 `Labels.LargeMapIntro`，不再以"座位盲选"口径开头。
4. 大图预览画面：新局面板选大图时显示整块大陆的缩略（复用小地图 `Minimap` 的像素图放大居中，或等价的整图缩略），不走分块流式只看局部；点"开始"进局后才按原流式渲染。
5. 人数默认 4 人不变。

## 约束
- 不碰 Siege.Core 规则、AI、地图生成；不改小图任何行为（截图基线、`link:1:4` 黄金、15 条决策基线、导出字节一致必须保持）。
- 选图界面守门：Godot 选图源码不直接引用生成器 / 规则常量，文案经 `Labels` 取。
- 不生成多余文档；规格若有口径变化只改 `openspec/specs/map-selection`。
