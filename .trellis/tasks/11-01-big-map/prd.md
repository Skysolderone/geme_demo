# 大地图：跳出棋盘形式（big-map）

## 目标

负责人 2026-11-01 原话："整个模式都需要变更，只是移动使用棋子格式；地图都应该跳出棋盘形式；单独一个地图应该非常大，就算多个玩家同时选也没有感觉。"

把现在"一座 45×45 浮岛 + 四角固定座位"的局面改成：**一张 150×150 的大陆**，玩家在全图任意可落子格自由插旗、彼此相距 ≥ 60 格开局互不感知；地面默认没有任何格子，格子只在落子 / 预演 / 改造时局部出现；镜头跟随自己的出生点、右下小地图概览。规则内核（气 / 提子 / 覆盖 / 势力）不变，落子仍按格。

## 现状（以代码为准；设计文档 §3.2–§4.1 仍是废弃的 5 块旧口径）

- `LinkMapGenerator`：岛外接矩形 2 人 45×33、3 / 4 人 45×45（`IslandWidth` 45、`Margin` 2），可落子约 950–1420；每人一个固定 8×8 出生座位（`SeatSide` 8，2 人东西、3 人一顶两底、4 人四角），座位间距恰 25（`SeatGap`）；中立平台 n–n+1 块；河道 / 湖泊 / 岩区 / 海湾约占岛面 27–29%。单张生成 2 / 3 / 4 人 38 / 63 / 121 ms。
- 标识 `link:<种子>:<人数>`（`LinkMapId`，三段，人数 2–4）。
- 插旗：`FlagPlanting` / `PrototypeZoneAssignment.BlindPicks`，选的是出生座位编号（`BirthZone` int），座位互斥、撞座按先后改派到空座位；锁定后 `MatchFlow.LockFlags` 写 `PlayerRecord.BirthZone`，整岛可见。
- 构筑期：`PublicRules.LegalRange` / `EditScope` 第 1–3 大回合限 `Map.BirthBoard(zone)`（8×8 座位），第 4 起全图。
- 终局：整轮 Pass / 填满 / 只剩一人；大回合上限 `MatchOptions.DefaultRoundCap` 100 到点按势力结算（`FlagPlanting.cs:33`）。
- Godot `BoardView.Build`：逐格建地砖节点，装饰合 MultiMesh；格缝淡刻痕、信息层下清晰；锁定后全岛可见，M 全局预览。
- AI `HeuristicTurnController`：对 `LegalRange` 内全部空格枚举候选，再按候选格上限预筛。
- 新局面板 `MapSelectModel`：种子 / 换一张 / 人数 2–4 / 难度。

## 裁决（2026-11-01，负责人"全按推荐"）

| 编号 | 项 | 裁决 |
|---|---|---|
| 1 | 「只是移动使用棋子格式」读法 | **A**：不加移动阶段；格子只在落子 / 射程 / 改造时出现，地图本身不再是一块板。规则内核不动。 |
| 2 | 「多个玩家同时选也没有感觉」读法 | 出生点彼此足够远、开局互不感知：任意两旗间距（切比雪夫距离）≥ 60 格。 |
| 3 | 单图规模 | 不分人数统一 **150×150**（外接矩形；可落子约 1.5 万）。 |
| 4 | 出生方式 | 全图自由插旗：点任一合规可落子格即旗，旗心 9×9 为出生圈；与已插旗者太近（见 2）按插旗先后改派到最近的合规格。 |
| 5 | 构筑期（第 1–3 大回合）范围 | 旗心半径 6 的方域（13×13）∩ 可落子格；改造范围同；第 4 大回合起全图不变。 |
| 6 | 终局 | 「填满」不再可达（保留代码，不删）；大图缺省对局时长 **60 大回合**到点按势力结算（沿用上限安全网机制，界面明示"第 X / 60 大回合"）；整轮 Pass、只剩一人照旧。小图缺省仍 100。 |
| 7 | 格子显隐 | 地面默认**完全无格**；只在光标周围与合法落子范围画局部格网；信息层打开才显示已加载区块的全图格。 |
| 8 | 视野与镜头 | 规则仍全公开（不做迷雾）；锁定后镜头落在自己出生点的局部视角；右下小地图概览（地形色 + 棋子点 + 视口框，点击跳转）。 |
| 9 | Godot 渲染 | 地砖改 MultiMesh、按 16×16 区块分块，只建相机附近区块（流式加载 / 卸载）。 |
| 10 | AI | 最小适配：候选只取己方棋子 / 己方旗切比雪夫 8 格内的空格 ∪ 对手棋子 2 格内的空格，不改评价（AI 仍放最后，只保证大图能跑）。小图走法逐步不变。 |
| 11 | 地图标识与可玩路径 | 加尺寸段 `link:<种子>:<人数>:<档>`，档 `s` = 现小图、`l` = 大图；三段写法 = `s`，现有标识、存档、黄金值全部不变；新局面板加尺寸选项，缺省小图。 |
| 12 | 地形生成 | 复用现有要素按面积放大成一块大陆：多条河、多个湖泊 / 岩区、更多中立平台、不规则岸线；大图不预置任何出生座位；单张生成预算 ≤ 1 s（Release）。 |
| 13 | 派发方式 | 顺序分段，单 worktree（分支 `map/big-map`，目录 `E:/wws/geme_demo-bigmap`）：段 A 规则 + 生成器（Core / Sim / 规格 / 测试）→ 段 B Godot → 段 C AI 最小适配；每段一个 implement agent + 一个 check agent，段与段之间向负责人汇报再派下一段。 |
| 14 | 文档 | 设计文档 §3.2–§4.1 随段 A 改写为现行口径并加「大图档」一节，不新增文档；`openspec/specs` 直接改规格文件（同 map-coastline 做法）。 |

## 分段与验收

### 段 A：Core（标识、生成器、自由插旗、构筑范围、对局时长、Sim、规格、测试）

- [ ] `link:<种子>:<人数>:l` 种子 1–20 × 2 / 3 / 4 人全部生成成功、过静态校验；外接矩形 150×150；可落子 12 000–18 000；非可落子占大陆面 25–35%；出生座位数 0、中立平台数在区间内；可落子格沿气边连通；单张 ≤ 1 s（Release）。
- [ ] 三段标识与 `:s` 完全等价：小图黄金哈希、15 份决策基线、存档 / 日志往返逐字节不变。
- [ ] 自由插旗：合规旗格 ≥ 大图可落子格的 50%；4 名 AI 盲选（种子 1–20 × 对局种子 1–5）锁定后两两间距 ≥ 60；人为给出 4 个相距 < 60 的旗，锁定后按先后改派、结果确定且间距 ≥ 60。
- [ ] 构筑期：第 1–3 大回合合法落子范围 ⊆ 旗心 13×13 ∩ 可落子 − 禁入；改造范围 = 旗心 13×13 ∩ 全部格；第 4 大回合 = 全图可落子 − 禁入。小图口径（8×8 座位）不变。
- [ ] 对局时长：大图缺省 60、小图缺省 100，`--round-cap` 显式给值优先；公开快照 / 日志首部 / 存档在**大图**上带档位、旗格与时长，**小图上这些新字段一律不写出**（null 不序列化、`RoundCap` 仍存解析后的整数），保证小图逐字节不变。
- [ ] Sim：`run --map=link:7:4:l --count 1 --difficulty Simple --turn-limit 3` 跑完不报错（只到构筑期，候选在 13×13 内；全图阶段的冒烟放段 C，段 A 的 AI 在大图全图阶段跑不动是已知的），记录每步耗时（只记录，不修 AI）。
- [ ] 规格与设计文档改完；快速测试全绿（重钉的快照逐条说明）。

### 段 B：Godot（分块渲染、无格地面、局部格网、小地图、自由插旗界面、尺寸选项）

- [ ] 新局面板有"尺寸 小 / 大"（缺省小）；`--map=link:7:4:l` 直接开局。
- [ ] 插旗阶段：大图上点任一合规格落旗，旗心 9×9 预览圈，太近给提示；锁定后镜头落在自己旗心。
- [ ] 地面默认无格；暂放 / 预演 / 改造时光标周围 7×7 与合法范围显示局部格网；信息层（1–4 键）打开时已加载区块显示全图格。
- [ ] 分块：150×150 大图建场景 ≤ 2 s，稳定 ≥ 30 fps（本机），平移时区块按需加载 / 卸载，拾取 `--pick-check` 抽样 2000 格往返一致。
- [ ] 小地图：右下角，地形色 + 棋子点 + 视口框，点击跳转；HUD 显示"第 X / 60 大回合"。
- [ ] 小图画面与改前一致（截图对比 `link:5:4`）。

### 段 C：AI 最小适配（局部候选预筛）

- [ ] 大图上标准难度 4 人一局每步 ≤ 3 s（本机），`--turn-limit 20` 跑完（含第 4 大回合起的全图阶段）；小图 15 份基线与黄金值逐步不变（预筛只在大图生效）。
- [ ] AI 盲选旗格用 `flag-pick` 子流在合规旗格里均匀抽。

## 边界

不改：气 / 提子 / 覆盖 / 势力 / 活形 / 同形 / 信物 / 征募 / 部署上限 / 先手值；不做战争迷雾；不删"填满"与小图任何口径；不加移动阶段；不跑 200 局；AI 评价不改维度与权重。
