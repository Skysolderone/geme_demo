# 设计：出生座位 + 25×25 战场

裁决来源：prd.md S1–S8（2026-10-28）。

## E1 几何

- 岛改为长方形 `Island(W, H)`：n=2 → 45×33，n=3 / 4 → 45×45；留白 M=2，画布 (W+4)×(H+4)；四角切角 3 格照旧。
- 座位平台固定 8×8（座位之间公平），距岛边 2 格（`EdgeGap`）：
  - n=2：西、东各一，纵向居中（H=33 时西座位 x∈[M+2, M+10)，东座位 x∈[M+W−10, M+W−2)，横向间距 45−4−16 = 25）。
  - n=3：西南、东南两角 + 北边横向居中（纵向间距 25）。
  - n=4：四角。
  - 座位位置由人数决定，不消费随机；布局流只抽一次镜像 / 旋转（2 人：是否东西互换无意义，可不抽；实现可选，写进 Layout summary）。
  - 实施结果（段 A）：镜像 / 旋转**未实施**，布局流不为座位消费任何随机（已写进 `LinkMapGenerator.Layout` summary）；n=2 座位纵向取 `M + (H−8)/2`（偏南 1 格），n=3 北座位横向取 `M + (W−8)/2`。
- 间距定义：两矩形之间相隔的格数 gapX、gapY（重叠方向为负），间距 = max(gapX, gapY)；校验 `SEAT_GAP` 要求 ≥ 25（常量 `SeatGap = 25`）。

## E2 平台

- 座位：`BoardPlateKind.Birth`，带主题（River / Forest / Palisade / Mixed，布局流抽，可重复）。
- 中立平台：`BoardPlateKind.Public`，**链接档也带主题**（放宽 `MapFile.ParseTheme`"只有出生棋盘带主题"：链接档的公共棋盘同样必须带主题；非链接档无此档，规则只剩链接档）；宽高 6–8；数量 n=2 → 2–3、n=3 → 3–4、n=4 → 4–5；沿用贴紧式候选落位，与所有平台间隔 ≥ 3、距岛边 ≥ 2。
- 平台内部、抬升（h=2）、坡道（2–3，外圈非角格，朝外是低地）、新地表叠加：座位与中立平台一视同仁，沿用现有 `DraftBoard` / `OverlaySurfaces` / 坡道逻辑。
- `MapData.Boards` 顺序：座位在前（按出生区编号），中立平台在后；`BirthZones` 只含座位核心区（n 个）；`BirthBoard(zone)` 只数 Birth 类，保护期范围（S5）自然只是座位平台。

## E3 低地

- 沿用：n 条河道（各 2 座桥）、岛缘林地 / 岩石、全图可落子格沿气边连通（不满足重抽低地）。
- 中央入口 `CentralEntrance` 取岛几何中心格（不再是"中央平台中心"）；若该格不可落子，取离中心最近的可落子低地格（先行后列）。
  - 实施结果：中心格取 `(M + (W−1)/2, M + (H−1)/2)`（偶数边偏西南）；该格可落子即直接用（可能落在中立平台上、高度 2）；否则在岛上高度 0 的可落子格里按曼哈顿距离取最近，并列先行后列（`LinkMapGenerator.CentralEntranceOf`）。

## E4 盲选插旗（S2）

- `ZonesMustExceedPlayers` → 链接档改为"出生区数 = 人数"。
- `FlagPlanting.Plant` 仍是选中即锁定、仍允许选别人已选的座位（盲选不泄露信息）。
- `LockAll` 改派：按插旗先后（`Plant` 调用顺序）逐个处理；某座位已被更早插旗者占用的，记为撞座位。然后对撞座位者与未插旗者，按玩家编号升序，用 `flag-pick` 子流在**当前空座位**里均匀抽一个。结果各不相同。
- 同种子同插旗顺序结果确定；`PrototypeZoneAssignment.BlindPicks` 的语义随之改为"从空座位里抽"，相关测试与金值重钉并注明原因。
- 存档恢复 `RestoreLocked` 不变（直接写结果）。
- 实施结果：没有需要改派的玩家时不消费 `flag-pick`；原型路径 `AssignBlind` 把人工那一名当作先插旗者交给 `BlindPicks`，产出即最终座位，随后依次插旗锁定时不再抽。
- 测试接缝（段 A）：`MatchDebugAccess.LockFlagsAs` 按给定座次直接锁定、不改派、不消费 `flag-pick`（规则层夹具如"四人同锁棋盘 0"沿用）；`LookaheadFixtures.CreateSession`（手写 5 块平坦图上的 AI 行为夹具）保留 E4 之前"每人在全部出生棋盘里各抽一次"的座次，经 `LockFlagsAs` 锁定，以免重钉 AI 金值（S7）。

## E5 校验器（链接档）

- 预算三行按 n：画布宽高恰等（W+4, H+4）、出生区数 = n、出生区格数 9、可落子格区间（实施时按 1–20 种子实测给区间）。
- 新增 `SEAT_GAP`（任意两座位间距 ≥ 25）、`SEAT_SIZE`（座位 8×8）、`NEUTRAL_PLATE_COUNT`（中立平台数区间）；`ISLAND_EXTENT` 改为长方形 W×H。
- 平台规则（`PLATE_HEIGHT` / `PLATE_THEME` / `ISLAND_PLATE_GAP` / 坡道 / 平台内连通 / 新地表）对 Birth 与 Public 两类平台同样适用。
- `规格档分流守门Tests` 约束照旧。
- 实施结果（段 A）：声明字段 `ZonesMustExceedPlayers` 与 `BIRTH_ZONE_COUNT_NOT_ABOVE_PLAYERS` 删除，出生区数由预算行区间 (n, n) 表达（`BIRTH_ZONE_COUNT_OUT_OF_RANGE` 报"必须恰为 n 个"）；`PlateList` 加 `SeatGap: 25`，`BirthSide` 收为 (8, 8) 只供 `SEAT_SIZE`。
- 可落子格区间实测：种子 1–20 为 2 人 1389–1438、3 人 1902–1951、4 人 1861–1952；按它向外取整的下限 1350 / 1850 / 1800 在种子 21–200 上撞到 5 张图（如 `link:59:2` 为 1333），改用种子 1–600 扫描（只生成地图、不跑局）：最小 1324 / 1819 / 1795、最大 1440 / 1968 / 1952。下限各留约 70–100 格余量取 1250 / 1750 / 1700，上限取岛内格数上界附近的 1480 / 2000 / 2000（2 人岛 45×33 去切角为 1461 格，3 / 4 人 45×45 为 2001 格）。

## E6 入口

- Sim：`play` 插旗提示与 `map` 输出只列座位；渲染区分座位与中立平台。
- Godot：选图预览只给座位编号与可点；中立平台照常画出（不带编号或用不同样式）；长方形画布取景；人数选项不变。
- 信物刷新（relic-redesign）：核对刷新区域是否假定"全部平台 = 出生棋盘"（`BirthBoardArea` 等），中立平台应归入公共区域；有问题按最小改动修，并在交付说明列出。
- 实施结果（段 B）：插旗提示与占位只给座位；Sim `map` 输出把出生座位与中立平台**分两段**列出（中立平台编号只作对照），文本图中立平台记 `n`、`play` 插旗占位图记 `=`；Godot 中立平台画淡色细框（`DefaultBoardView.NeutralPlates`，无编号、不可点）；未展开占位时取景为整张画布。`BirthBoardArea` 只读 `BirthBoards()`，中立平台天然属公共区域，未改。日志首部 `Boards` 只列出生座位（下标 = 出生区编号），中立平台不入日志首部。

## E7 确定性

随机只来自 `MapRandom.ForLinkLayout` / `ForLinkSurfaces`（含人数）与对局 `flag-pick` 子流；座位几何不消费随机；全程整数，不读时钟。消费顺序写进 `Layout` summary。
