# 地图出生座位：玩家之间留 25×25 战场

## 目标

用户原话（2026-10-28）：「还是不对，玩家之间一定要保留 25*25 的棋盘空间去作为战斗空间，就算一开始两个人同一张地图」。

上一版浮空岛（10-26-map-expand-25，已合回 main c570f30）所有平台都可作出生、平台间距只要求 ≥3，两名玩家可能挨着出生甚至盲选到同一块，2 人岛 30×30 也放不下中间 25×25。本任务改为**固定出生座位**：每张图恰 n 个出生座位，任意两座位之间留出 25×25 的战场；其余平台改为中立平台。

## 现状（代码确认）

- 生成器 `LinkMapGenerator.Layout`（src/Siege.Core/Board/Maps/LinkMapGenerator.cs:134）：岛为正方形 `Island(side)`，边长 30/35/40；`PlacePlates` 中央 8×8 + 贴紧式候选，全部平台 `BoardPlateKind.Birth`，`BirthZones` = 全部平台核心区。
- 盲选插旗 `FlagPlanting`（src/Siege.Core/Match/FlagPlanting.cs）：允许多人选同一出生区（`ViewFor` 有"同一块棋盘的玩家"）；未选者由 `PrototypeZoneAssignment.BlindPicks` 在全部出生区里均匀指定，与他人选择无关。
- `BoardPlateKind` 已有 `Birth` / `Public`；`MapFile.ParseTheme` 规定只有出生棋盘带主题。
- 校验器 `MapValidator` 链接档按人数三行预算；`ZonesMustExceedPlayers` 为 true。

## 已定裁决（2026-10-28，用户："S1–S8 全按推荐"）

| # | 项 | 裁决 |
|---|---|---|
| S1 | 25×25 口径 | 任意两名玩家出生平台的外接矩形间距 ≥ 25 格，中间能完整放下 25×25 战场（战场里可有低地 / 河道 / 桥 / 中立平台） |
| S2 | 出生方式 | 每张图恰 n 个出生座位，玩家只在座位里盲选；撞座位时用现有随机子流把后选者改派到空座位。推翻旧 Q6"所有平台都可选" |

## 需求

- 生成：`link:<种子>:<人数>` 确定性生成；恰 n 个出生座位 + 中立平台。
- 间距：任意两座位外接矩形的切比雪夫间距（两矩形之间相隔的格数，取横纵较大者）≥ 25。
- 插旗：座位互斥；锁定时撞座位 / 未选者改派到空座位，确定性。
- 入口：Sim 与 Godot 只能选座位；中立平台可见、可落子（第 4 大回合起），不可作出生。

## 验收标准

- [ ] 任意种子 1–20 × n∈{2,3,4}：座位数 = n；任意两座位间距 ≥ 25；中立平台数在 S4 区间；每块平台 h=2、2–3 个 h=1 坡道；可落子格沿气边全图连通；校验通过。
- [ ] 岛外接尺寸：2 人 45×33，3 / 4 人 45×45（不含留白）。
- [ ] 盲选：多人选同一座位时锁定后各占不同座位；未选者只落空座位；同种子同选择结果相同。
- [ ] Sim `run --count 1 --players 2` 与 `--players 4` 成功；Godot 选座位开局、整岛可见，保护期只能落自己座位。
- [ ] 全量测试通过（失败 0）。

## 不在范围
