## 实现清单

## 1. 覆盖层

- [ ] 1.1 实现按格存储的覆盖表（覆盖者数量 + 唯一覆盖者），每次盘面变化全量重算。验证：断言同一玩家 4 枚棋子覆盖同一空格仍只判为一个独占格。
- [ ] 1.2 实现四邻接覆盖传播，障碍与越界不记录覆盖也不穿透。算例（设计文档 §7.1）：中央棋子 `F6` → 覆盖 `E6/G6/F5/F7`，斜向 `E5` 不覆盖。
- [ ] 1.3 实现占据优先：已占据格由棋子所有者直接控制，不因敌方覆盖变争议。算例（设计文档 §7.1）：A 的棋子在 `D4`，B 三枚棋子覆盖该格 → 仍属 A。
- [ ] 1.4 实现空格归属三态（独占/争议/中立）与障碍排除。验证：三态各有独立用例；障碍格不出现在任何玩家的归属集合中。
- [ ] 1.5 实现唯一覆盖查询，并与空格归属共用同一份覆盖表。验证：交叉一致性测试——对全盘每一格断言两套判定不矛盾。
- [ ] 1.6 断言弃赛者遗留棋子照常产生覆盖与争议。算例（设计文档 §12.2）：弃赛者 D 与参赛者 A 同时覆盖某空格 → 该格为争议，A 不得分。

## 2. 棋子效果

- [ ] 2.1 实现五种棋子的基础军势（1/4/1/1/1）与"类型效果不提供额外气、免死、复活"的约束。算例：纯堡垒子棋串失去全部气 → 被整体移除。
- [ ] 2.2 实现连珠子极长线扫描（横、纵各一遍，长度 ≥2 计 `L×(L−1)`）。算例（设计文档 §9.2）：长度 3 的横线 → 6 点。
- [ ] 2.3 断言不拆子区间。算例：长度 4 的连珠线 → 只计 `4×3=12`，不额外计入长度 2/3 的子区间。
- [ ] 2.4 实现十字交叉双向计入。算例：交点棋子同时属于长度 3 横线与长度 2 竖线 → `3×2 + 2×1 = 8`。
- [ ] 2.5 实现协同子加值（`协同子数 × 除协同子外的类型数 × 2`）。算例：协同子×3 + 普通子×1 + 堡垒子×1 + 连珠子×1 → `3×3×2 = 18`；纯协同子串 → 0。
- [ ] 2.6 实现倍增子倍率 `1.5^n`，采用整数/定点运算（乘 3^n 除 2^n），禁止二进制浮点。验证：对 n=0..8 的边界值断言跨平台结果一致，且恰好为整数的值取到该整数。
- [ ] 2.7 实现位置加值分来源记账（连珠来源 / 协同来源），两者之和等于总位置加值。验证：明细字段断言。
- [ ] 2.8 断言实时重算。算例（设计文档 §9.2/§10.1）：长度 4 连珠线中间一子被提 → 加值由 12 降至 0；2 枚倍增子被提 1 枚 → 倍率由 2.25 降至 1.5；一次提子导致棋串分裂 → 按两条独立棋串分别重算。

## 3. 势力计算

- [ ] 3.1 实现棋串军势公式 `⌊(基础 + 加值) × 1.5^倍增子数⌋`，逐棋串各取整一次。算例（设计文档 §10.1）：普通子×3 + 堡垒子×1 + 倍增子×2 → 基础 9、倍率 2.25、军势 20。
- [ ] 3.2 断言取整位置正确。算例：两条棋串未取整军势各 16.5 → 分别取整为 16+16=32，而非先求和 33 再取整。
- [ ] 3.3 实现总势力 `独占空格数 + 棋串军势之和`。算例：12 独占 + 军势 20 与 7 → 39。
- [ ] 3.4 断言领地分不参与倍率、棋子所在格不重复计作领地。算例（设计文档 §10.1）：无竞争的孤立普通子 → 该局部恰好 5 点势力（军势 1 + 4 个独占空格）；10 领地 + 倍率 2.25 棋串 → 领地仍计 10。
- [ ] 3.5 断言势力不可消耗、不累计历史积分。验证：不存在任何消耗势力的接口；势力由 80 跌至 12 后当前值为 12 且无历史字段。

## 4. 势力明细与排名

- [ ] 4.1 定义并实现势力明细结构（领地分总计、独占格坐标集合、逐棋串的棋子坐标/基础军势/位置加值/加值来源拆分/倍增子数/倍率/取整后军势）。验证：明细可复算出总势力且完全一致。
- [ ] 4.2 实现每次合法批次结算与每次 Pass 后的全量势力重算与公开排名更新。验证：Pass 路径同样触发重算。
- [ ] 4.3 实现弃赛玩家处理：势力照常计算与显示并标记"已弃赛"，但排除出势力名次。算例（设计文档 §10.2/§12.2）：弃赛者势力 45 高于参赛者 30 → 名次中不出现弃赛者。
- [ ] 4.4 实现势力名次输出（排除已弃赛与已出局玩家），并如实输出并列组信息，不自行打破并列。算例：两名参赛者均 37 分 → 输出并列信息交由 `add-match-flow` 裁决。

## 5. 契约与回归

- [ ] 5.1 固化对下游的四个输出契约（空格归属表、唯一覆盖查询、势力明细、总势力+名次）。验证：契约级测试覆盖正常与边界输入。
- [ ] 5.2 建立数值回归用例集，覆盖：标准算例 20、孤立子 5 点、十字连珠、纯协同串、倍率边界取整、领地不进倍率、弃赛者覆盖、棋串分裂重算。验证：全部通过并纳入持续回归。
- [ ] 5.3 为遥测暴露倍率峰值与其出现的大回合序号。验证：跑一局后日志中可读出峰值与轮次，供 §16 数值区间回归使用。
