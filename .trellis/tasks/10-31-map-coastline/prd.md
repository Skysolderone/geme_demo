# 地图生成：不规则岸线与 30% 景观（map-coastline）

## 目标

让链接图（`link:<种子>:<人数>`）的岛形从"矩形切四角"变成按种子噪声啃出海湾的不规则岛，内陆多出湖泊、岩区、加宽的河道，非可落子格占岛面约三成——这是参考图（粉彩浮岛）的骨架，美术线（map-restyle / map-surface）只换了皮，跳不出方板的根源在这里。

## 现状

- `LinkMapGenerator`：岛 = 固定矩形（2 人 45×33，3 / 4 人 45×45）切四角各 6 格（`CornerCut` 3）；座位 8×8 钉在角 / 边、距岛边 `EdgeGap` 2；中立平台 n–n+1 块；河道 n 条、1 格宽、各 2 座桥；岛缘零星林地与岩石；全岛可落子格沿气边连通否则重抽低地。
- `MapValidator` 链接档预算：可落子格 2 人 1250–1480、3 人 1750–2000、4 人 1700–2000；实测 4 人约 1861–1952，非可落子只占 7%。
- Godot `BoardView.IslandCells` 按每行可落子 / 深水格的跨度铺岛面，岛面因此总是矩形。

## 裁决（2026-10-31，负责人"全按默认"）

1. 岸线只啃岛缘：按种子噪声向内咬 1–4 格深的海湾，四角切角从固定 3 改为 4–7 随机；不挖内部虚空。座位、座位外 2 格边距、坡道朝外格、中立平台及其 3 格间隔一律受保护；座位间距 25 不变。
2. 非可落子占岛面 30%±5：啃边约 250 格 + 内陆湖泊 / 岩区约 200 格 + 河道加宽约 150 格（4 人口径，2 人按比例）。校验器预算表按种子 1–20 实测重钉（4 人约 1200–1500，2 人约 900–1150）。
3. 内陆要素：河道 1–2 格宽蜿蜒、仍每条 2 座桥；湖泊（未架桥深水）4–9 格；岩区 3–6 格；全岛可落子格沿气边连通的要求不变，不连通即重抽。
4. 不加新的高度要素；只动平面要素。
5. 同标识出新图（同 seat-gap-25 S6），基线 / 快照重钉；`openspec/specs/link-map-generation/spec.md` 加"岛形"一节、预算改数，直接改规格文件（同 map-surface 做法）。
6. AI 不管：候选格上限按可落子数自动取；只记录。
7. Godot：把"与画布留白连通的障碍格"当作虚空（不铺岛面、沿边落断崖），内陆被包住的障碍格仍当岩石 / 场景格；纯表现，不改数据。
8. 单线三段顺序各派一个子 agent：段F Core → 段G Godot → 段H 试玩截图检查；分支 `map/coastline` 从 main 开。
9. 验证规模：种子 1–20 × 2 / 3 / 4 人生成 + 校验 + 连通；Sim 1 局 4 人；不排 200 局。

## 段F 追加裁决（2026-10-31，负责人"全按默认"）

- F1：湖泊 / 岩区不得落进座位外 2 格（`EdgeGap`）那一圈；中立平台外 3 格允许有湖泊 / 岩区。代价：4 人图低地重抽变多、耗时约再涨三成；15 份决策基线与黄金哈希再录一次。
- F2：生成耗时验收由"不超过改前 2 倍"放宽为"单张 ≤ 100 ms（Release，种子 1–20 平均）"；不改输出的等价优化留待以后。
- F3（2026-10-31）：湖泊 / 岩区投放尝试上限 `MaxClusterAttempts` 1500 → 3000 接受（4 人单张 193 → 121 ms、低地重抽最多 18 → 6 次；种子 0–1000 两档都零失败）。
- F4（2026-10-31）：耗时验收再放宽为单张 ≤ 150 ms（实测 2 / 3 / 4 人 38 / 63 / 121 ms；剩余重抽全是河道画不通），河道或等价优化留待以后。
- F5（2026-10-31）：`信物遥测Tests.小样本AI有拾取行为` 样本拉长（2 人 16 → 24 小回合、4 人 32 → 48 小回合）；仍为 0 即记入 AI 待办并标跳过，不碰 AI 走法。

## 验收

- [x] 段F：种子 1–20 × 2 / 3 / 4 人全部生成成功、过静态校验；非可落子占岛面 25%–35%；座位数 = n、座位间距 ≥ 25、中立平台数在区间内；每张图可落子格沿气边连通；生成耗时单张 ≤ 150 ms（F4）。快速测试全绿（重钉的快照除外要逐条说明）。
- [x] 段G：Godot 上海湾处不铺岛面、断崖沿海湾落下；内陆岩区仍是岩石装饰；`--pick-check` 全部可落子格往返一致；三张截图（2 / 3 / 4 人全局）。
- [x] 段H：Sim `run --count 1 --players 4` 跑完；Godot 自动演示 2 / 3 / 4 人各跑到第 2 大回合并截图。

## 边界

不改座位数、座位间距、保护期、插旗、信物、AI 走法、高度规则、画布尺寸（49×37 / 49×49）。

## 实施结果（2026-10-31）

- 段F：非可落子占岛面 2 / 3 / 4 人 27.1–29.6% / 27.0–29.2% / 27.0–29.1%；可落子 954–1001 / 1337–1398 / 1366–1420；单张 38 / 63 / 121 ms；种子 0–1000 零失败。海湾只咬 30–120 格（保护区占住岸线，4 人切角恒 4），三成景观主要来自内陆湖泊 / 岩区。
- 段G：Godot 岛面按画布留白泛洪识别虚空；link:5:4 拾取自检 1377 / 1377；种子 0–300 × 3 档无对角夹点。
- 段H：Sim `run --seed 7 --count 1 --players 4 --turn-limit 120` 30 个大回合零失败、70 s（改前 168 s）；全套快速测试 2015 通过、0 失败、1 跳过。
