# 设计：多平台浮空岛（link 档替换）

裁决来源：prd.md 已定裁决 Q3–Q6 + 裁决表 R1–R10（2026-10-26，R8 取消：AI 不管）。

## D1 标识与入口

- 标识 `link:<种子>:<人数>`，人数 ∈ {2,3,4}；`LinkMapId` 为唯一解析：`Parse` 返回 `(ulong Seed, int Players)`，`Format(seed, players)`。
- 旧 `link:<种子>`（两段）抛 `FormatException`，消息给出新格式与示例 `link:1:4`。裸 `link` 仍由入口取种子，入口须同时给出人数后再 `Format`。
- `MapCatalog.DefaultId` = `link:1:4`。`LinkMapGenerator.Generate(ulong seed, int players)`，缓存键 `(seed, players)`。
- `MapData.MaxPlayers` = 人数 n；平台数 P > n（校验器 `ZonesMustExceedPlayers` 保持 true）。
- 三个入口：
  - Sim `play` / `run`：`--players` 决定人数；未给 `--map` 时缺省为 `link:1:<players>`；裸 `link` → `link:<友好种子>:<players>`；显式标识的人数与 `--players` 不一致即报错退出（不静默改）。
  - Godot：新局界面加人数选项（2/3/4，缺省 4），`MapSelectModel.CurrentId` 带人数；开局人数 = `map.MaxPlayers`（GameRoot.MapSelect.cs:64/249 现为 `Min(4, MaxPlayers)`）；`--map=link:s:n` 照常。

## D2 岛的几何（R1 / R2）

- 岛边长 W(n) = 30 + 5(n−2)：30 / 35 / 40（R1 改裁：26 / 31 / 36 单轴放不下 2+6+3+8+3+6+2=30 的最小排布）。岛占 `[M, M+W)²`，画布 (W+2M)²，留白 M = `Margin` = 2，留白格为障碍（场景）。
- 岛四角各切去一个 3 格的直角三角（共 6 格/角，障碍），让轮廓不是死方块；切角不计入"可落子区外接矩形"，外接矩形仍是 W×W。
- 平台数 P：n=2 → 6–8，n=3 → 8–10，n=4 → 10–12（布局流抽取）。
- 平台边长：中央平台 8×8 固定居中（岛中心；岛边长与 8 奇偶不同时——即 3 人局 W=35——偏西南半格）；其余平台宽、高各在 6–8 抽取（主题生成器已验证的区间；原裁决 R2 写 5–10，下限受核心区 + 外圈限制、上限受主题生成器限制，收窄为 6–8，中央 8）。
- 摆放（实施修订：纯随机试位在几何可行时也排不满，改为贴紧式候选——每块在横纵两向都顶在岛边距线上或与已放平台恰隔 3 格，抽到的尺寸无位置时退到 6×6）：其余平台按抽到的尺寸逐个落位（布局流），约束：完全在岛内且距岛边 ≥ 2 格、不压切角、与已放平台的外接矩形间隔 ≥ 3 格（低地走廊至少 3 宽）。单块尝试至多 200 次；放不下即整张布局在同一条流上重抽（至多 50 次，超出抛 `MapGenerationException`）。放够 P 的下限即可停止追加到抽到的 P。
- 所有平台 `BoardPlateKind.Birth`，各带主题；出生区 = 各平台核心 3×3（`BoardPlate.CoreCells`，不变）。

## D3 平台地形（Q5 / R3 / R4）

- 主题 ∈ {River, Forest, Palisade, Mixed}（不再出现 Plateau），按平台编号用布局流均匀抽取，可重复；中央平台同样抽主题。
- 复用 `DraftBoard` 生成平台内部（`drafted` 传空：平台互不相邻，没有接缝），之后统一"抬升"：平台内全部格高度置 2（主题自带的高度——Mixed 的 1 格台——被抹平，可接受）。
- 坡道：每个平台 2–3 个（布局流抽数量），落在外圈非角格、两两不在同一条边（3 个时至少分布在 3 条边）、且坡道格的朝外邻格是可落子 h=0 低地（不是深水 / 岩石 / 切角 / 另一平台）。坡道格高度 1、地表草地（"非信物格"随 D5 作废删除）。坡道之外的外圈格与低地高度差 2 = 崖壁（自然断气，规则不改）。
- 新地表叠加（`OverlaySurfaces`，独立子流）照旧按平台逐块进行，在抬升之前做（其候选条件读的是主题原始高度）。

## D4 低地（R4）

- 平台外、岛内、非切角的格为低地：h=0 草地。
- 河道：条数 = n，每条是 1 格宽的深水折线，从岛边出发走到岛边或某平台崖下，不进平台、不占坡道朝外格、不占切角；每条恰 2 座预置桥（桥格不相邻）。
- 岛缘点缀：岛最外一圈随机若干林地（可落子，参考图的林带），少量岩石（障碍）；岩石不得落在坡道朝外格。
- 连通硬约束：全部可落子格沿**气边**（`Adjacency.LibertyNeighbors`）连通为一片；不满足在同一条流上重抽河道 / 岩石（至多 50 次）。几何战场自然恰 1 个。

## D5 信物（R5，已作废）

- 不放静态信物格（依据 relic-redesign R29，2026-10-26 用户裁决"直接删掉"；段 A3 实施）：生成图 `RelicCells` 为空，布局流不再为信物消费随机（同种子的坡道 / 低地因此与段 A1 / A2 不同，平台落位、主题与平台内部不变）。
- 原定"每平台核心区 2 个出生区信物、低地 n+2 个公共信物"的放置代码、常量与校验规则一并删除。
- 旧信物系统（`Siege.Core.Relics`、RelicLedger、RelicGenerator 等）不拆，留给 relic-redesign；地图没有信物格时整局照常空跑。

## D6 构筑保护期（R6）

- `PublicRules.BuildProtectionRounds` 仍为 3；保护期范围 = `map.BirthBoard(zone).Cells()`，坡道格在平台外接矩形内，自然属于自己平台。规则代码不改。

## D7 校验器（链接档规则重写）

`MapValidator` 声明表的链接档一行改为按人数的岛屿规则：

- `Budget` 按 n=2/3/4 三行：可落子格区间、出生区数 = 平台数区间、出生区格数 9；外接列 / 行区间并入每行（W(n)+2M 恰等，允许 ±0）。信物区间随 D5 作废删除（不放静态信物格，依据 relic-redesign R29，2026-10-26 用户裁决）。
- 删除：外圈 h=0（`BOARD_RIM_NOT_FLAT` 原口径）、核心区 h=0（改为"核心区 9 格同为 h=2 草地、无障碍深水桥、无内部栅栏"）、棋盘外不得有深水（`ValidateFlatScenery`）、紧贴布局（`ValidateSpliced`）、接缝气边（`ValidateSeams` / `SeamPairs` / `SeamHasLiberty` 若无他用一并删）、"信物须在棋盘内"、主题两两不同、每块至多 1 个公共信物。
- 段 A3 再删（不放静态信物格，依据 relic-redesign R29，2026-10-26 用户裁决）：信物格数区间（`RELIC_COUNT_OUT_OF_RANGE`）、每块平台恰 2 个出生区档信物（`BIRTH_BOARD_RELIC_COUNT` / `PlateRules.BirthRelics`）、公共信物在低地且 ≤ n+2（`ISLAND_PUBLIC_RELIC` / `Budget.PublicRelicsMax`）。
- 新增 / 改写：
  - `ISLAND_PLATE_GAP`：平台互不重叠、外接矩形间隔 ≥ 3。
  - `PLATE_HEIGHT`：平台内可落子格除坡道外 h=2；坡道 h=1，数量 2–3，在外圈非角格，朝外邻格为 h=0 可落子低地。
  - `PLATE_THEME`：主题必填、不得为 Plateau。
  - `ISLAND_LIBERTY_SPLIT`：全部可落子格沿气边连通。
  - `ISLAND_EXTENT`：可落子区外接矩形 ≥ W(n)×W(n)（验收的核心断言）。
  - ~~公共信物在低地、数量 = n+2 以内。~~（段 A3 删除：不放静态信物格，依据 relic-redesign R29，2026-10-26 用户裁决）
- 保留：结构、地形边界、可落子预算、出生区容量、信物格合法（通用结构校验，`RelicCells` 为空时自然通过）、豁免理由、必死口袋、平台内隔断线规则、平台内连通（`BOARD_SPLIT`）、改造目标 ≥ 2、平台内新地表位置与上限。
- 守门测试 `规格档分流守门Tests` 的约束（规格档分支只在声明表内）继续遵守。

## D8 确定性

- 随机仍只来自 `MapRandom.ForLinkLayout(seed)` 与 `ForLinkSurfaces(seed)`；人数是生成参数，须进入两条流的派生（同种子不同人数是不同的图）。消费顺序写进 `Layout` 的 summary。全程整数运算，不读时钟。

## D9 Godot 视野

- 40×40 + 留白 = 44×44 格时，整张岛须能在默认窗口看全（相机缩放 / 初始取景按地图外接矩形计算），可缩放可平移；不做参考图美术（R7，另起任务）。
- 实施（段 B）：最远缩放上限 `FarthestCap = 28` 不动（提高它会让既有相机夹具一屏看全、相机测试大面积失效）；改为新局界面与插旗阶段以全局预览为初始取景（外接矩形一屏看全，距离越过上限），拉近即退出预览照常缩放 / 平移，锁定后开局对准自己的平台；对局中 M 键 / "全局"按钮随时切回整岛。
