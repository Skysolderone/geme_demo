# 卡通棋子：十种棋子改为卡通描边的角色 / 建筑造型

## Goal

十种棋子重做为参考图风格（用户 2026-11-21 提供的截图，存于 `art/chibi-pieces/reference.png`）：

- 闭盔骑士类角色和塔、碑、修道院类建筑混搭；
- 卡通分阶明暗加粗黑描边，饱和配色；
- 去掉八角大底座，棋子直接站在格子上，阵营色放在羽缨、盾、屋顶、垛口上。

对局相机俯角 60° 不动，辨认靠俯视剪影与阵营色块。

## 版本沿革

- v1（本任务前一轮，未提交）：大头 Q 版小兵 + 八角底座，用户看图后要求按参考图重做。v1 的 Blender 管线、glb 加载与回退链保留复用。

## 用户裁决（2026-11-21）

1. 5 个角色 + 5 个建筑（下表）。
2. 卡通着色加描边，只改棋子；棋盘卡通化另开任务。
3. 去掉八角底座，徽记移到棋子身上（盾面、旗面、建筑挂旗）。

## 第二轮裁决（2026-11-21，用户："按照你的建议"）

4. 脚下阵营色整格方块改为细圆环（不透明、合并进 Enamel 槽、压暗），不遮挡格子和领地着色。
5. 徽记在可用面积内放大，保证远景可见。
6. 钢盔色压暗一档，金方在强光下不发白。
7. 拾取跑 `--pick-check` 实测；描边厚度以实测 0.03 为准，回写 design。

## Requirements

1. **造型**，`PieceStyleTable` 和轮廓语言不变：

   | 棋子 | 语言 | 造型 | 俯视辨认特征 | 徽记位置 |
   |---|---|---|---|---|
   | 普通子 | Rounded | 剑士：闭盔（T 字面甲）、阵营色羽缨、圆盾 + 短剑 | 圆盔 + 羽缨 + 圆盾 | 盾面 |
   | 哨兵子 | Crossed | 长矛兵：闭盔、身侧竖一根高长矛，背后再斜插一根，两根交叉 | 交叉的两根长矛（X） | 胸前小盾 |
   | 旗手子 | Banner | 旗手：闭盔、竖直旗杆、杆顶一侧大旗 | 竖杆 + 旗面 | 旗面 |
   | 匠人 | Tooling | 工匠：敞口盔、皮围裙、肩扛斜向大锤 | 斜柄 + 横置锤头 | 围裙 |
   | 铁链子 | Interlock | 链枷兵：闭盔、手持链枷，链条由相扣中空环组成、末端挂铁球 | 相扣环链 + 球 | 盾面 |
   | 堡垒子 | TowerMass | 石垒：圆石塔、阵营色垛口顶、木门 | 高圆塔 + 垛口 | 塔身挂旗 |
   | 界碑子 | Slab | 矮宽圆顶石碑，阵营色碑额 | 矮宽单板 | 碑面 |
   | 连珠子 | Connection | 两座小塔用一段城墙相连 | 双塔 + 连接墙 | 墙面挂旗 |
   | 倍增子 | Radial | 修道院：尖顶钟楼，顶上一枚四向放射的风向标 | 尖顶 + 放射星标 | 门楣 |
   | 协同子 | MultiNode | 水晶祭坛：石台上三到四簇晶体 | 多簇晶体 | 台面 |

2. **三组易混对去色可辨**：铁链 / 连珠、界碑 / 堡垒、旗手 / 匠人。
3. **卡通渲染**：
   - 棋子材质改为卡通分阶漫反射；
   - 描边用反向外壳（cull front、无光照、深色），作为一个额外的材质槽合并，每颗棋子只多一次绘制调用；
   - 暂放半透明时描边也要跟着变淡。
4. **去掉八角底座**，脚下改为一圈阵营色细圆环（外半径约 0.36、环宽约 0.05），不超出格子，不盖住格子中心。徽记由 glb 里的锚点 `Anchor_Emblem`（空物体）定位，运行时把徽记网格挂上去。
5. **阵营色**：每颗棋子的阵营色面积要足够大，60° 俯视下一眼能认出阵营；四个阵营里每种棋子的冠饰都不能和金属色混在一起（金方要能分清）。
6. **性能**：每颗本体 ≤ 1200 三角形，加上描边外壳合计 ≤ 2400；材质槽（含描边）≤ 7 个。
7. **回退**：glb → tscn → LowPoly 的链路保留；回退造型保持旧样式（带底座）即可。
8. **可重复生成**：一条命令重新生成全部 glb。
