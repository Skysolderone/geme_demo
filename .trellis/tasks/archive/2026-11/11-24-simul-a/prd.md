# 新玩法段 A：同时决策 + 同格冲突 + 全灭不判负 + 占满终局（simul-a）

## Why（提案）

用户 2026-11-24 决定按 Jungle v0.1 交接稿（`D:\ws_feature\Jungle\docs\2026-11-12-siege-gameplay-design-v0.1.md`，下称 v0.1）做"新玩法"。它作为**新增模式**与现有模式并列，现有模式不动；先做规则，演出另开任务。旧玩法是轮流决策，未轮到的玩家要等；新玩法改成统一回合，全员同时决策，同格靠战力争夺。段 A 做完要能实际玩一局。

对应 v0.1 章节：§4（空间内核）、§5.2（势力 / 战力分开）、§6（同时决策与三种顺序）、§7.1–7.2（时序与读取盘面）、§8（征召与部署）、§9（同格冲突）、§10（终局与胜利资格）、§14（未决事项，本段按下表裁决）。

前置 change：无。复用现有链接小图、征召、整体与气、活形分析、势力计算、插旗。

## What Changes

- 新增规则内核：统一回合流程，包括回合开始固定结算顺位、全员同时准备（整理手牌、征召、暂放）、全员提交后统一揭晓、同格冲突、整批落下、按顺位围杀、孤立自绝、活形锁定与势力计算，以及终局判定和排名。
- 新增新模式专用的部署校验：只按回合开始时的盘面和本人批次校验；同一玩家同回合的落点在同一座岛上八邻禁落；活形内部空格双方都不能进入；提交时不判自杀，取消同形禁则。
- 新增同格冲突：战力 = 基础战力 + 回合开始时就存在、四邻相接的己方单位数；比大小；最高战力并列时掷 d6 决胜。
- 全灭不判负；没有势力归零出局。主动认输的玩家，单位留在场上，排名固定末位。
- 终局：所有可部署格占满（活形内部已锁定的空格不需要补）、连续一整回合无人部署、大回合上限兜底，或剩余参赛玩家不超过 1 人。
- 最简贪心 AI（G6），保证能对局。
- Sim 入口能跑新模式，Godot 新局面板加"新玩法"选项，可以人机对局。冲突只显示文字和飘字。

## 段 A 裁决（2026-11-24 用户"全部按默认"，抄自 journal 末条，只列段 A 项）

来源标注：【Clash】11-21 Clash 规格已采用的做法 /【现有】geme_demo 现状 /【拟】立项会话提议。

| 编号 | 裁决 |
|---|---|
| Q02 | 【拟】每人只按回合开始时的地图和自己的批次校验，提交时不判自杀；【Clash】同一回合内自己的落点八邻禁落（同一玩家不会两枚落同格）；【拟】取消同形禁则；非法批次不能提交，也不消耗手牌 |
| Q03 | 【Clash】先打完冲突 → 按结算顺位依次提走对手无气整体 → 清掉自己仍然无气的整体（孤立自绝）→ 锁定活形 → 统一算势力 |
| Q05 | 【现有】首回合按种子定顺序；之后按上回合势力排名，同势力先看上回合顺位，再看种子 |
| Q06 | 【拟】战力 = 基础战力 + 回合开始时已存在、与该格四邻相接的己方单位数（每个 +1）；信物加成放段 B；势力沿用现有算法（独占空格 + 军势），活形内部空格算所有者领地 |
| Q07 | 【现有】部署上限 3；胜利名额：2 人局 1 名、3 人局 1 名、4 人局 2 名 |
| Q08 | 【现有】排名比较顺序：势力 → 信物数 → 独占空格 → 单位数 → 种子 |
| Q09 | 【拟】提交前可以随意改，提交后锁定；征召候选私有；本地人机不限时；对手提交后只显示"已提交" |
| Q10 | 【拟】连续一整回合无人部署即终局，按势力排名；保留现有大回合上限兜底 |
| Q11 | 【Clash】认输者的单位留在场上，继续挡路，也可以被围杀；排名固定末位；剩余参赛玩家 ≤ 1 人直接终局 |
| Q14 | 【Clash】d6；非最高战力者先出局；最高战力并列者同时掷，点数低的出局，最高点仍并列只让这几人重掷 |
| Q15 | 【拟】沿用现有单位外观；冲突只做文字和飘字的简版 |
| Q16 | 【拟】沿用现有链接小图；不做失败返程表现 |
| G1 | 【拟】用现有单位类型，每种新增"基础战力"，先取基础军势（堡垒 4，其余 1） |
| G2 | 【拟】保留插旗、前 3 回合只能部署在出生区、地形改造、高地；活形改为双方禁入；取消势力归零出局，也取消 Pass 撤销当回合征召 |
| G3 | 【拟】八邻禁落按同一座岛（出生岛）算，跨岛互不影响 |
| G5 | 【拟】新局面板加"新玩法"选项，与现有模式并列 |
| G6 | 【拟】新模式先用最简贪心 AI，保证能对局；AI 问题只记录不修 |
