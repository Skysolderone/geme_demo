# 09-16-merge-board-layer

> 规格权威：`openspec/changes/merge-board-layer/`。
> 设计文档来源：§14.2 战术信息层。

## Goal

用户在试玩截图上圈出底部按钮栏的领地、气、势力三个按钮，标注"重复"。实测确认领地层与气层点亮的空格集合**恒等**（21 对 21，双向差集为空）——覆盖 = 棋子的四邻接相邻格，气 = 棋串的空邻格，"被某方覆盖的空格"就是"某条棋串的气"。

把这两层合并为**盘面层**的两种读法：归属与棋串。信息层由五种变为四种，键位顺延为 1/2/3/4。

## Acceptance

| 验收项 | 对应规格 |
|---|---|
| 两种读法点亮同一批空格 | Scenario「两种读法点亮同一批空格」 |
| 归属读法另有占据格与中立格 | Scenario「归属读法另有棋串读法没有的格」 |
| 点击模式三态循环 | 「盘面层的读法切换」Scenario 1 |
| 按住模式下层键不改读法 | 同上 Scenario 2 |
| 读法跨越关闭被记住 | 同上 Scenario 3 |
| 切换读法无副作用 | 同上 Scenario 4 |

## Out of scope

- 势力层（与排名面板的重复性质不同，需单独评估）。
- 覆盖与气的规则、层互斥规则、两种输入模式本身。

## Notes

- **按住显示是默认模式**，而按住期间无法"再按一次"同一个键。读法切换因此不得绑在层键上，用独立键 `Tab`。规格把这条写成 MUST NOT，它是从交互本身推出的约束。见 design.md D3。
- 改既有测试时**逐条确认换的是称呼不是断言强度**，不得借机把断言改松。
