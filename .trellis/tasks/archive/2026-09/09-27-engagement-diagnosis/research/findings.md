- b01：第 4 大回合对方区对我合法空格 0.2 格；20 局 0 子落进对方区；保护期后落点本方近侧侧翼 55.1% / 中央 18.1% / 本方区 13.5% / 远侧侧翼 13.2%；R7+ Pass 55%，85 次决策中 47 次无过阈值单点、37 次无正收益单点。

**原因**：① 地图结构（强）——对方区在保护期结束时已被棋子 + 活形眼封死，每家各有一块贴墙易做眼的近侧侧翼，可提目标几乎不存在；同规则同 AI 的 3 人图无提子仅 1/20。② 眼位权重放大锁死（中）——Eye 50 使无提子降到 11/20，但 R3 领先者 20/20 全胜。③ 停手阈值不是原因（强，反证）。④ 活形硬约束不是原因（淘汰的全是自填眼）。⑤ 威胁权重是弱杠杆。

**方案**：A 地图 v2——侧翼改为双方等距共争、去掉易做贴墙小眼的岩石 / 深水、可移一个公共信物进侧翼（推荐）；B 小图单独眼位 / 敌损权重；C 提高活形门槛（动 §6.4、需重扫校准）。

- b06：部署上限 4.52–4.85；合法空格 28.3 → 20.8；对我禁入格 29.4 → 34.1；本方受保护眼格 12.7 → 9.0；125 次 Pass 中仅 16 次是阈值挡下正收益点。

**结论**：方向仍成立、幅度约减半；主因是可落空间随名次递减（禁入格贡献明显），Pass 的直接原因是无正收益点；阈值只对垫底者有明显影响。

**方案**：A 落后者降低停手阈值（AI 口径）；B 禁入上限 / 衰减（动规则）；C 按"落后就要挨打"接受（推荐）。
