## 实现清单

## 1. 盘面状态模型

- [x] 1.1 定义格子数据结构：坐标、地形（可落子/障碍）、出生区归属、是否信物格、占用（玩家+棋子类型）。验证：单元测试断言障碍格写入占用被拒绝；信物格可正常写入占用且信物标记不变。
- [x] 1.2 定义棋盘容器与围棋记法坐标（列字母 `A`–`L` 跳过 `I`、行数字自下而上从 1 起），并实现与内部索引的唯一双向映射。验证：单元测试断言 `A1` 的邻居集合恰为 `{B1,A2}`；11 列字母序列为 `A B C D E F G H J K L`；任意标识往返映射后不变。
- [x] 1.3 实现最小写入原语（设置占用、清除占用），不含任何规则判定。验证：单元测试断言写入/清除后 `取格子` 返回值一致，且不触发任何提子逻辑。

## 2. 四邻接与派生计算

- [x] 2.1 实现唯一的四邻接邻居遍历，作为全项目唯一入口。验证：全仓搜索确认无第二处邻居遍历实现；单元测试断言斜向不被返回。
- [x] 2.2 实现棋串计算（同玩家、四邻接洪泛、跨棋子类型合并）。算例（设计文档 §9.2）：同玩家普通子 `C3`、堡垒子 `C4`、倍增子 `C5` → 返回单个 3 枚棋子的棋串。
- [x] 2.3 实现气计算（相邻空的可落子格去重；障碍、越界、任意玩家棋子均不计气）。算例（设计文档 §10.1）：棋盘中央孤立棋子 → 气数 4；上方改为障碍 → 气数 3。
- [x] 2.4 实现无气判定。算例：一枚棋子四周全被敌方棋子/障碍/边界封堵 → 判定无气。
- [x] 2.5 实现"枚举玩家棋串"与"存在可落子空格"查询。验证：单元测试断言棋盘填满时后者返回否（对应设计文档 §12.3 终局条件 3）。
- [x] 2.6 断言所有查询无副作用。验证：连续执行 1000 次随机查询后盘面序列化结果逐字节不变。

## 3. 盘面序列化

- [x] 3.1 实现确定性盘面序列化，内容仅含每格占用者与棋子类型，按固定坐标顺序遍历。验证：同一盘面重复序列化结果逐字节相等。
- [x] 3.2 断言序列化排除非盘面信息。算例（设计文档 §6.2）：两份盘面占用完全一致但手牌与信物控制不同 → 序列化结果相等；同一玩家同一位置换用不同棋子类型 → 序列化结果不相等。

## 4. 地图数据与校验

- [x] 4.1 定义地图数据格式：外接尺寸、地形网格、出生区（编号+归属格）、信物格位置、信物强度预算分区、咽喉格标注、校验豁免标记。验证：能完整往返读写一张手工地图且无信息丢失。
- [x] 4.2 实现人数适配预算校验（2 人 50–65/2/7–9；3 人 75–90/3/10–12；4 人 100–115/4/13–15）。算例：4 人地图 130 可落子格 → 拒绝并报告超出 100–115。
- [x] 4.3 实现障碍占比校验（占外接区域 8%–12%）。算例：11×11 地图 5 个障碍（约 4.1%）→ 拒绝并报告低于 8%。
- [x] 4.4 实现出生区容量校验（通用规则：每区可落子格 ≥ 9，可容纳前三大回合 9 枚基础部署；"每区 12–15 格"是 4 人基准图的属性，由基准图测试单独断言，不作为通用规则——套到 2/3 人图会误拒）。验证：模拟单玩家在区内连续三大回合各落 3 子且无提子，每步均存在合法空格。
- [x] 4.5 实现出生区距离均衡校验（到最近公共信物格、中央入口、标注咽喉的四邻接绕障最短落子距离，两两差值 ≤ 容差，默认 1，逐图可放宽但必须记录理由）。算例：A 距离 4、B 距离 9 → 拒绝并输出出生区编号与两个距离值。
- [x] 4.6 实现必死口袋保守校验（出生区内被障碍/边界围成的连通空区面积 < 8 即失败，支持逐图豁免）。验证：构造一个 4 格死角地图 → 拒绝并输出该口袋坐标。
- [x] 4.7 实现信物格校验（必须位于可落子格、必须标注强度预算分区）与出生区数量校验（等于地图支持的最大人数）。验证：构造把信物格放在障碍上的地图 → 拒绝。
- [x] 4.8 断言地图加载不消费随机数。验证：用 3 个不同对局种子加载同一地图，地形/障碍/出生区/信物格位置逐字节一致。

## 5. 4 人基准地图

- [x] 5.2 标注中央区、交通咽喉与高风险边缘区的信物强度预算分区。验证：人工检查每个信物格都归属到出生区或公共争夺区之一，且公共区分区标注覆盖中央与咽喉。

## 自审修复记录

多 agent 审计因会话额度用尽未产出结论（8 个 agent 全部报错，0 条结构化发现）。改为自查，修了 3 个真问题：

1. **恒真测试**：`四邻接Tests.邻接实现唯一` 断言 `Adjacency.Neighbors(...) == board.Neighbors(c)`，而后者实现就是 `return Adjacency.Neighbors(...)`——永远成立，实现写错也不会红。已换成手写四方向偏移独立算期望值。变异验证：删掉 Adjacency 的"上"方向后 73 个测试红 19 个，还原后全绿。
2. **Godot 守门盲区**：`AssertNoGodotDependency` 只检查 `PackageReference`，`ProjectReference` 与直接 dll 引用都能绕过。已扩展到 `ProjectReference`，并加 `内核不引用Godot` 测试检查真正落进程序集的引用——这才是兜底。
3. **`LoadUnvalidated` 对生产代码可见**：跳过静态校验的入口是 `public`，生产代码误用会把必死口袋、距离失衡带进对局。已改为 `internal` + `InternalsVisibleTo(Siege.Core.Tests)`。

另补 6 项独立验证（自己算，不调用 MapValidator）：D2 三种变换下障碍/信物/咽喉/出生区不变、四区到三类地标距离精确相等（极差 0）、全盘 109 格连通无小口袋、校验输出跨 50 次运行确定。

测试总数 68 → 88。
