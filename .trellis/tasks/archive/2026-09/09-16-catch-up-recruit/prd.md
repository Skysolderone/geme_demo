# 09-16-catch-up-recruit

> 规格权威：`openspec/changes/catch-up-recruit/`。本文件只承载目标、验收映射与范围边界。
> 设计文档来源：`2026-09-10-siege-core-gameplay-design-v1.md` §5.3、§10.2、§11、§16

## Goal

multiplier-rebalance 之后第 3 大回合领先者胜率 54.0%（§16 目标 ≤ 50%）。200 局拆解排除了先手顺序（第 1 大回合随机顺序下 1–4 号位最终名次 2.52 / 2.66 / 2.48 / 2.33）、信物（领先者与其他人同为 2.00 枚）、领地（9.6 vs 9.5）；差异在保护期征募运气——领先者倍增子 1.79 / 堡垒子 3.37 / 棋串 3.9 条，其他人 0.96 / 2.77 / 5.0 条。本任务给落后者供给侧补偿。

## Requirements

- 名次 > ⌈参赛人数÷2⌉ → 展示数 +1；名次为最大名次且 > 1 → 选取数 +1；并列共享名次；出局 / 弃赛者不计入、不获补偿。
- 补偿在效果快照生成时读一次，回合内不回收、不累计。
- 开关进 `MatchOptions`（标准局开启），公开、入存档、旧存档回填开启。
- 结构参数来源拆分新增「落后补偿」；手牌面板显示。
- Sim 日志首部记开关，报告新增落后补偿段落。
- 设计文档 §5.3 / §10.2 / §11 与变更记录。
