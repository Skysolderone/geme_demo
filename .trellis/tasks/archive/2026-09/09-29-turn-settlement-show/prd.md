# 09-29-turn-settlement-show

> 规格权威：`openspec/changes/turn-settlement-show/`（proposal / design / specs / tasks）。

## Goal

图形版每个小回合结算后按节拍播放演出（落子 → 提子 → 势力重算），势力值滚动显示并带增量，演出可提速但必须播完。

## Requirements

- 节拍由"结算前公开快照 + 结算后公开快照 + 结算记录"经纯函数生成；规则内核零改动。
- 节拍生成与演出时间线是不依赖引擎的表现层视图模型，带单元测试；图形脚本只做接线与绘制。
- 演出期间对局不推进；镜头与信息层仍可操作。
- 提速倍率 4，按住生效；不提供跳过。
- 无人值守运行（自动演示 / 定帧截图 / 限定大回合数 / 拾取自检）演出时长为 0，输出与改动前相同。

负责人裁决（2026-09-29）：演出时机取每个小回合；内容四项全要，分两次变更交付——本任务为第一次（骨架 + 落子 / 提子 + 势力滚动 + 提速），飘字细化与信物 / 据点 / 出局横幅留给后续 change `settlement-show-callouts`。

已裁决（2026-09-30）：提速按键为按住空格或鼠标左键。
