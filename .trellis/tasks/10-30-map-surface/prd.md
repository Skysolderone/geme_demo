# 表现层去棋盘感（map-surface）

## 目标

在不动地图数据与规则的前提下，把 map-restyle 之后仍然"像一块粉彩方板"的画面推向参考图的连续石岛：格缝淡成刻痕、坐标环与底板撤掉让断崖露出来、地面按噪声分片、装饰放大加密、加 SSAO 与更重的阴影。

## 裁决（2026-10-30，负责人"全按默认"）

1. 格缝：同地表相邻格合成连续地面，格线改成淡刻痕（亮度差约 8%）；信息层打开（按住 / 切换 T）或悬停格时显示清晰格线。`openspec/specs/visual-style-baseline/spec.md` 里"方格边界 MUST 清晰"已改成"默认淡刻痕、信息层下清晰"。
2. 坐标标注默认隐藏、信息层打开时显示；撤掉标注底板（apron）与石沿框（rim），断崖直接露在岛缘。相机可行矩形与 `FarLabelMargin` 不动。
3. 地面分片：草地格按坐标噪声分成三片（淡紫石 / 淡草绿 / 淡泥褐），片内连续成块；其余七种地表不动，三片的色距与土路 / 荒漠 / 岩台拉开，灰度下仍可辨。
4. 装饰：草丛带宽 0.12→0.22、高 0.12→0.20、密度 13%→28%；新增小石块、小花两类格角点缀；火盆 / 拱门 / 宝箱 / 水晶不动。
5. 光影：开 SSAO，主光阴影不透明度 0.48→0.65，主光色再暖一档。
6. 机位不动（60° 俯角是拾取约束）。
7. 两段顺序派发：段D（1 + 2 + 5）→ 段E（3 + 4），各一个子 agent，主会话审 diff、复跑构建与拾取自检后提交。分支 `art/map-surface` 从 main 开。

## 验收

- [ ] 段D：默认画面格线只剩淡刻痕、坐标环与底板消失、岛缘断崖在默认机位可见；按住 T 后格线与坐标清晰；`--pick-check` 1861/1861。
- [ ] 段E：草地成片分色、草丛明显、格角有小石块与小花；八种地表灰度仍可辨（目视）；`--pick-check` 通过。
- [ ] `dotnet build` 零警告零错误；`dotnet test`（快速集）通过；部件快照重导无悬空材质。

## 边界

不改规则、地图数据、`Siege.Core` / `Siege.Presentation` 的视图模型与键位解析、HUD 文案、相机位姿与缩放。
