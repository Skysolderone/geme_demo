# 地图风格重做：粉彩浮岛

## 目标

把整张战场地图（地砖、岛缘崖壁、水面、桥、装饰物、光照与镜头）重做成参考图那种明亮粉彩的低多边形浮岛风：淡紫灰层叠岩壁、亮青水面带岸线泡沫、暖木板桥、深褐泥地块、草丛、紫水晶、火盆、石拱门、中央圆形符文平台、格间深缝、暖主光加柔和天光。

## 裁决（2026-10-30，负责人"保留方格，按默认"）

1. 格形保留方格四邻，只借风格不借六边形。
2. 范围 = 地砖 / 岛缘崖壁 / 水面 / 桥 / 装饰物 / 光照 / 镜头。HUD、角色模型、规则、地图数据不动。
3. 资产路线：继续 C# 程序化低模（`LowPoly` / `LowPolyMesh` / `TerrainParts`）重做配色与造型，再导出到 `parts/terrain_full_art`；不引入外部资产包。
4. 风格要素全选：a 淡紫灰岩壁 / b 亮青水 + 岸线泡沫 / c 暖木板桥 / d 深褐泥地块 / e 草丛 / f 紫水晶 / g 火盆 / h 石拱门 / i 中央圆形符文平台 / j 格间深缝 / k 暖光 + 柔天光。h、i 只是装饰，无规则含义。
5. 分支：`art/plateau-height` 已合回 main（ec7df67），本任务在 `art/map-restyle` 上做。未跟踪的 `src/godot/parts/terrain_plateau_temp/` 是高台线的临时导出，不删不提交。
6. 单线顺序三段：段A 配色 + 材质 + 光照环境（主会话）；段B 几何（崖壁 / 水面 / 桥）；段C 装饰套件 + 中央平台（各派一个子 agent）。
7. 设计产物只此一份 PRD，不另写 docs。

## 需求

- 八种地表仍要一眼可辨，灰度下也能分开（沿用 `Visuals` 的判读约束）；格距、高度、拾取、规则一律不变。
- 岛缘崖壁从板岩灰改为淡紫灰 / 粉灰，分层带有明暗；水面改亮青绿，岸边有浅色泡沫带。
- 桥改暖木板面配绳栏；栅栏同系木色。
- 装饰物（草丛、水晶、火盆、石拱门、宝箱）只放在不可落子格或格角，不遮格心、不进拾取。
- 中央公共平台（中立平台）加圆形符文台面装饰，不改平台格数与规则。
- 光照：暖主光 + 偏蓝柔天光，柔和阴影；镜头俯角保持 60°（拾取约束）。
