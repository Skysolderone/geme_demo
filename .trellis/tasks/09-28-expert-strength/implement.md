### 1.3–1.8 实现

- `AiSearchConfig`：新增 `DiverseSupplementLimit`、`TwoPlyWeightPermille`（构造缺省 0、`WhenWritingDefault` 不写出、缺字段按 0 读、`Validated()` 拒负）；`Expert` = `Hard with { W 4, S 8, λ 1000 }`；`Easy/Standard/Hard` 不变。
- `LookaheadRecord.cs`：`CandidateSource { Original, Supplement }`；`LookaheadEntry` 加 `Source`、`TwoPlyBonus`（原排序 / 0 时 `ToString()` 不写）；`LookaheadRecord` 加 `SupplementRehearsals`、`TwoPlyRehearsals`（0 时 `ToText()` 不写）。一层配置下文本与改动前逐字节相同（G1 证）。
- `HeuristicTurnController`：专家时把排除重跑 `Rerun(x)` = `Greedy(原排序去掉 x 格全部单点, 同一阈值)` 交给前瞻（S = 0 传 null，完全走原路径），并数它经 `rehearse` 的预演次数；`PrefilterCells` 改为 `internal static`（多一个 `cellLimit` 参数，行为不变），供两层扫描复用；`ForSimulation` 的守卫加上两项必须为 0。
- `ExpertLookahead`：`LookaheadSet(…, width, S, rerun)`（格集合去重 → 前 W → 按锚次序 / 落点次序排除重跑补足，原排序在前）；两参旧重载保留；`Choose` 先模拟全部候选，再按"至少一个有对手"统一计两层加分（无对手的在 B1 上计）；`TwoPlyBonusOn` / `NextMoveContext`（大回合 + 1、`PublicRules.LegalRange`、`PublicRelicEffects.Deploy`）/ `BestSingleGain`（B2 投影视图为"前"新建评价器、`TryEvaluate`、不施加阈值、同一预筛）/ 静态 `TwoPlyBonus(λ‰, g) = max(0, g) × λ / 1000`。新类型 `Simulation`、`LookaheadMember` 为 internal 嵌套类型，单列为信息边界闭包的根。
- 两层单点的库存数量口径（规格只定类型集合）：每种持有类型给"下一大回合公开部署上限"枚，与 E5 补丁相同，只为让单点预演足额（维度 7 供给匹配因此不罚单点）。见待决 1。

### 既有测试改写与理由

1. `专家难度的一层前瞻Tests.前瞻宽度进入记录`：专家一行期望加 `"DiverseSupplementLimit":8,"TwoPlyWeightPermille":1000`（预设新增两项，非 0 写出，次序接在前瞻宽度后）；三档旧难度三行一字不改；另加一层配置 = expert-lookahead 时代字面量、RunConfig 中两项各出现一次。
2. `…旧记录按不前瞻读入`：加断言两项缺字段读 0、旧专家记录读为一层配置、新预设往返不丢字段。
3. `…前瞻宽度拒绝负数`：加两项负数被拒。
4. `…前瞻宽度为1时与高难逐步相同` → 改名 G2、改配置、加一条断言（理由见上）。
5. `难度分级Tests.难度名称与次序`：专家预设字面量加两项；三档旧预设三行不动，另断言三档两项为 0。
6. `专家前瞻的记录Tests.ExpertSample`：由"未显式给 Search 的专家"改为显式一层配置（v5 上候选格上限 0、阈值 80，与改动前首部落成的 Search 逐字段相同），断言一字不改。
7. `专家前瞻的确定性与耗时Tests.耗时上限_预演次数代理` → 改名 `预演次数代理计入新增部分`，专家一方加两层预演并输出三部分占比、各部分下界；`不消费新随机` 加样本下界（有排除重跑、有两层扫描）与"前瞻集第一个 = 高难的选择"；`缓存开关不改变专家决策` 加"记录里确有 sup= / two="。
8. `前瞻中的停手口径Tests.高难会Pass时专家也Pass`：追加预设配置同样 Pass、无补充无扫描。
9. `前瞻模拟的公平信息Tests`：`对手真实手牌不同结果不变`、`未揭示信物不被读取` 追加打开 S / λ 的同样比对；`守门覆盖前瞻代码` 追加 `Simulation` / `LookaheadMember` 为闭包根与新代码口径下界。
10. 夹具 `前瞻模拟的公平信息Tests.ContactPosition`、`前瞻中的下一名对手Tests.LastOpponentPosition` 只改可见性（private → internal），内容不动；`LookaheadFixtures` 新增 `OneLayerConfig` / `StrengthConfig` / `Engine` / `SyntheticCandidates.Typed`。
