## 2. 补偿判定

- [x] 2.1 效果快照生成时读取公开势力名次（参赛玩家、并列共享），名次 > ⌈参赛人数÷2⌉ → 展示 +1；名次为当前最大名次且 > 1 → 选取 +1。算例：A=60、B=45、C=30、D=20 → C 展示 6 选取 3；D 展示 6 选取 4；B 无补偿。验证：单元测试。
- [x] 2.2 并列与边界。算例：A=60、B=45、C=20、D=20 → C、D 均展示 +1 选取 +1；全员 0 → 无补偿；2 人局 A=30、B=10 → B 展示 +1 选取 +1。验证：单元测试。
- [x] 2.3 出局与弃赛者不计入参赛人数、不获补偿。算例：D 弃赛、A=60、B=45、C=30 → C 展示 +1 选取 +1。验证：单元测试。
- [x] 2.4 与信物加成相加。算例：最后一名 + 1 枚探勘 → 展示 7、选取 4。验证：单元测试。
- [x] 2.5 只在快照生成时读一次，本小回合内名次上升不回收；下一小回合重新判定。验证：单元测试。
- [x] 2.6 关闭开关时任何名次都无补偿。验证：单元测试。
