## Requirements
### Requirement: 开局选图界面

图形版在未通过命令行指定地图时 SHALL 先进入**新局界面**，确认后才建局并进入插旗阶段；命令行给了 `--map=link:<地图种子>` 时 MUST 跳过新局界面直接建局。命令行给了其他任何地图标识或地图文件路径时 MUST 报错退出并说明只接受 `link:<地图种子>`。

图形版 SHALL 保留启动选项 `--map-select`，**仅用于截图与无人值守自检**：给出时强制进入新局界面；与 `--map=link:<种子>` 同给时该标识只作为预填种子；与 `--auto-demo` 同给时先把新局操作（输入非法种子、输入合法种子、换一张、开始）自动走一遍并逐步核对，任一步不符 MUST 以失败退出，通过后照常自动演示。

新局界面 SHALL 显示当前地图种子与完整标识 `link:<种子>:<人数>[:<档>]`，并提供：

- **种子输入**：输入十进制地图种子后按确认采用该种子；非法输入 MUST 给出提示且不改变当前种子。
- **换一张**：取一个新的地图种子。
- **人数**：2–4。
- **尺寸**：大 / 小（big-map 裁决 11；large-default 裁决 1–2：**缺省大**，选项"大"在前，小图标为"旧模式"、保留不删且行为不变）：大即标识带 `:l`、预览为 150×150 大陆，选小回到三段标识、预览回到浮空岛；换一张、输入种子、选人数都不改尺寸；生成失败回退时尺寸与种子、人数一起退回。顶部说明与尺寸提示先写大图、后写小图。
- **大图缩略上插旗**（relic-sites 裁决 1–4）：选大图时右侧整块大陆的缩略可点格插旗——像素 → 格只经图形版那一份小地图映射换算，合规与否、不合规的原因只取 `FlagRules.FlagCellProblem`（经表现层视图模型，Godot 不判规则）；悬停时画旗心 13×13 构筑范围框（合规绿 / 不合规红）并显示坐标与原因，点格记为本机选中格并常显框，再点别的合规格可改选；缩略暂不放大缩放。换种子 / 人数 / 尺寸后选中格清空。小图（旧模式）不启用。
- **开始**：小图以当前种子建局，进入座位盲选的插旗阶段。大图未选格时"开始"MUST 禁用并提示"先在地图上点一格插旗"；选中后文案为"插旗并开始"，点下即建局、本机旗插在所选格、其余玩家按「原型插旗替代路径」盲抽、锁定，直接进入构筑期（相机对准本机旗，与 3D 插旗锁定后同一流程）；带入带出开启时仍先进补给阶段，补给确认后再插旗。

界面背景 SHALL 显示小图 n 个出生座位的占位轮廓（位置与边长），MUST NOT 显示棋盘内部布局；大图没有座位占位，背景就是整张基图的地形（与插旗阶段的可见范围同构，match-setup「大图自由插旗」；分块流式只建画幅中心附近的区块），不画任何格网；选大图时面板旁 SHALL 另显示整块大陆的缩略（复用小地图的地形像素图放大居中，large-default 裁决 4），缩略上 SHALL 标出信物遗址（稀有金色星、普通白色点，悬停显示"稀有 / 普通信物遗址"，relic-sites 裁决 10），点"开始"进局后缩略撤掉、按原流式渲染。预览阶段 MUST NOT 接受落子；插旗只在大图缩略上进行（见「大图缩略上插旗」），3D 预览本身不接受插旗。界面 MUST NOT 列出任何其他地图；旧地图清单与显示名对照表 SHALL 删除。批量与终端入口在未给地图选项时的缺省地图为 `link:1:4`（小图）。

#### Scenario: 缺省进入新局界面
- **WHEN** 不带地图选项启动图形版
- **THEN** 先显示新局界面，已取好一个地图种子并显示 `link:<种子>:4:l`（缺省大图、4 人），顶部说明为大图口径，面板旁是 150×150 大陆的整图缩略（带信物遗址标记），"开始"禁用并提示先在地图上点一格插旗；选"小（浮空岛，旧模式）"后背景是 n 个占位轮廓、"开始"可用

#### Scenario: 大图在缩略上插旗并开始
- **WHEN** 在缺省大图的新局界面上悬停、点击缩略上的格
- **THEN** 悬停不合规格显示红框、坐标与 Core 给出的原因（压到遗址 / 平台 / 出界……），点下不选中、"开始"仍禁用；悬停合规格显示绿框，点下记为选中格、常显框、"开始"启用并改为"插旗并开始"；换种子 / 人数 / 尺寸后选中格清空、按钮回禁用；点"插旗并开始"后本机旗锁定在所选格、其余玩家盲抽、直接进入构筑期，面板与缩略撤掉

#### Scenario: 命令行指定则跳过
- **WHEN** 以 `--map=link:12345` 启动图形版
- **THEN** 不显示新局界面，直接进入插旗阶段

#### Scenario: 旧标识被拒绝
- **WHEN** 以 `--map=siege-4p-base-v5` 或 `--map=board:12345` 启动图形版
- **THEN** 报错退出，说明只接受 `link:<地图种子>`

#### Scenario: 换一张
- **WHEN** 在新局界面点"换一张"
- **THEN** 种子变化，占位轮廓随之更新，界面显示新的完整标识

#### Scenario: 非法种子
- **WHEN** 在种子输入框里输入 `abc` 并确认
- **THEN** 界面提示种子须为非负整数，当前种子不变
#### Scenario: 选尺寸
- **WHEN** 在新局界面点"小"，再点"大"
- **THEN** 第一次后标识变为三段 `link:<种子>:<人数>`、预览换成浮空岛（座位占位轮廓）、缩略撤掉；第二次后标识回到 `link:<种子>:<人数>:l`、预览回到 150×150 大陆（无座位占位、无格网）与整图缩略；种子与人数都不变

#### Scenario: 强制进入新局界面的自检选项
- **WHEN** 以 `--map-select --auto-demo --map=link:12345` 启动图形版
- **THEN** 进入新局界面并预填 12345，自动走完新局操作且每步核对通过后，以 `link:12345` 建局进入插旗并照常自动演示；不预填（缺省大图）时自检另走"未选格开始禁用 → 点不合规格只提示 → 点合规格启用 → 换人数清空 → 再点合规格 → 插旗并开始"并核对本机旗在所点格、已进构筑期、缩略已撤

#### Scenario: 确认后开局
- **WHEN** 在新局界面点"开始"
- **THEN** 以当前种子建局；小图进入座位盲选的插旗阶段，大图（已在缩略上选格）直接锁定并进入构筑期；对局日志首部记录的地图标识与界面显示的一致

#### Scenario: 批量入口缺省
- **WHEN** 不带地图选项启动批量跑局或终端版
- **THEN** 加载的是 `link:1`
