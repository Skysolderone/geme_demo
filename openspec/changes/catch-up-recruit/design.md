## Context

multiplier-rebalance 之后第 3 大回合领先者胜率 54.0%（§16 目标 ≤ 50%）。拆解 200 局：第 1 大回合随机行动顺序对最终名次无影响；第 3 大回合末领先者与其他人信物数、领地相同；差异集中在保护期征募到的倍增子（1.79 vs 0.96）、堡垒子（3.37 vs 2.77）与棋串集中度（3.9 vs 5.0 条）。倍率只放大基础军势后，早期结构优势稳定延续，落后方没有追赶手段。

本 change 在供给侧给落后者补偿，直接对准"抽到关键棋子的机会不均"。

## Goals / Non-Goals

**Goals:**
- 第 3 大回合领先者胜率回到 ≤ 50%。
- 补偿规则公开、可推算、按当时名次实时判定，不累计。
- 复用结构参数与效果快照体系，只在快照生成一处读取名次。

**Non-Goals:**
- 不改先手值公式、不做保护期保底、不惩罚领先者、不改碾压 / 倍率 / 部署上限。

## Decisions

**D1：补偿给"展示数"与"选取数"，不给部署上限或军势。**
落后的根因是没抽到关键棋子。展示数 +1 提高见到关键棋子的概率，选取数 +1 让最后一名能多拿一枚；部署上限 +1 或直接加势力会绕过"构筑"本身，变成白给分。

**D2：分两档——后半名次展示 +1，最后一名再选取 +1。**
阈值用 `⌈参赛人数 ÷ 2⌉`，与人数无关地表达"后半"；2 人局第 2 名、4 人局第 3–4 名、3 人局第 3 名。最后一名额外选取 +1 让补偿有梯度，避免第 3 名与第 4 名完全等价。

**D3：名次在效果快照生成时读取一次。**
与 relic-effects「效果快照在小回合开始时生成」的既有契约一致：本小回合内名次变化不回收补偿。读取对象是公开势力名次（含并列共享），与 initiative-order / power-score 使用同一份排名，不另算。

**D4：全员并列第 1 时无人获得补偿。**
名次 > 1 是"最后一名"补偿的必要条件；第 1 大回合全员势力 0 时自然无人补偿，不需要额外"保护期不生效"的特判。

**D5：补偿是对局配置开关，沿用 dominance-victory 的配置处理。**
`MatchOptions` 新增布尔开关（标准局开启），开局固定、公开、入存档、旧存档回填开启。测其它规则（征募面板、类型槽、强制弃牌、手牌两段账等）的既有测试在建局时显式关闭，测试方法本身不改；夹具默认保持开启。

**D6：来源拆分新增「落后补偿」来源。**
结构参数来源目前按"分阶段基础 / 各枚信物"拆分；新增一类非信物来源，手牌面板与预演文案同步显示。

## 接口契约

**输入：** 小回合开始时的公开势力名次（参赛玩家、并列共享）、参赛人数、对局配置开关。

**输出：**

| 输出 | 变化 | 消费者 |
|---|---|---|
| 效果快照的展示数 / 选取数 | 加入补偿 | 征募面板、AI 征募、手牌两段账 |
| 结构参数来源拆分 | 新增「落后补偿」 | 手牌信息面板、终端 / Godot 界面 |
| 对局配置 / 存档 / 公开视图 | 新增开关字段 | 持久化、界面、Sim 日志首部 |
| 平衡报告 | 新增落后补偿段落 | 数值调整决策 |

## Risks / Trade-offs

- **[故意落后换补偿]** → 补偿只加供给不加势力，且领先才能碾压获胜，故意落后的收益有限；回归观察 Pass 率与"最后一名停留时长"是否异常上升。
- **[补偿过强导致对局更拉锯]** → 平均结束大回合已是 11.14；若补偿让领先者胜率掉到明显低于基线 25% 附近，或结束大回合继续上升，考虑只保留"最后一名选取 +1"一档。
- **[既有测试大面积受影响]** → 所有在"非第 1 名"局面断言展示 5 / 选取 3 的测试都会变化；按 D5 显式关闭，不改测试方法体。
- **[名次读取时序]** → 快照生成与势力重算的先后必须确定：读取的是"上一次结算 / Pass 后"的排名；不在快照生成时触发新的重算。
- **[AI 适应]** → AI 征募读快照面板，不需要改代码；但 AI 的供给匹配维度可能因面板变大而改变选择，回归如实记录。

## Migration Plan

1. 对局配置开关 + 存档 / 公开视图 / 旧存档回填。
2. 效果快照生成处读取名次、计算补偿；来源拆分加「落后补偿」。
3. 既有测试建局点显式关闭补偿；新增补偿 Scenario 测试。
4. 设计文档 §5.3、§10.2、§11 与变更记录。
5. Sim 日志首部记开关；报告新增落后补偿段落。
6. 200 局回归，对照 multiplier-rebalance 之后数据。

## Open Questions（建议裁决）

1. **补偿强度** → 建议按"后半展示 +1、最后一名再选取 +1"起步，回归后再调。
2. **是否在保护期内生效** → 建议生效（D4 已保证第 1 大回合全员并列无补偿；保护期内出现落后正是需要补偿的时候）。
3. **报告口径** → 建议统计：获补偿小回合占比、各档触发次数、获补偿玩家的最终名次分布、第 3 大回合领先者胜率。

## 裁决记录（已确认）

1. **两档补偿**（2026-09-15，项目负责人确认）：名次 > ⌈参赛人数 ÷ 2⌉ → 展示数 +1；名次为当前最大名次且 > 1 → 免费选取数再 +1。4 人局即第 3、4 名展示 +1，第 4 名再选取 +1。
2. **快照生成时读一次名次**，本小回合内名次上升不回收，不累计不结转。
3. **并列共享名次**；全员并列第 1 时无人获得补偿，因此保护期内也照常生效，无需特判。
4. **开关进对局配置**（标准局开启，0/关闭可配），开局固定、公开、入存档、旧存档回填开启；测其它规则的既有测试在建局时显式关闭，方法体不改，夹具默认保持开启。
5. **手牌面板显示「落后补偿」来源**，与分阶段基础值、各枚信物并列。
6. **先手值公式不动**：数据显示第 1 大回合随机顺序下行动早晚对最终名次无影响，滚雪球不来自行动顺序。
