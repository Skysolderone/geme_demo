## ADDED Requirements

### Requirement: 地形规则的当前来源

`retire-legacy-maps` 起所有可加载的地图都由互不连通的棋盘组成（负责人 2026-10-06 裁决）：棋盘内只有 h=0 草地，棋盘之外的场景格全是障碍，地图上没有深水、桥、栅栏、林地、土路与四种新地表（`map-definition`「棋盘档预算与校验」）。因此下列地形规则在当前任何地图上都**不产生**，但规则本身 SHALL 保留待用（负责人 2026-10-06 裁决：地形规则的去留另开 change 决定），其规格、实现与测试 MUST NOT 随本 change 删除或改变：

- 高度与崖壁（`terrain`「格属性」「气边」「覆盖关系」中的高度差条款，`piece-effects` 的高地压制加值）；
- 未架桥深水与隔水覆盖、预置桥与「搭桥」改造（`terrain-edit`）；
- 林地与「烧林」改造（`terrain-edit`）；
- 土路（只有呈现）；
- 荒漠、沼泽、岩台、浅滩四种新地表（含 `power-score`、`coverage-territory`、`life-shape`、`tactical-layers`、`ai-decision` 中与它们相关的条款）。原唯一来源边疆档生成器的新地表投放（`gen:…:s1`）已删除。

栅栏仍有来源：棋盘图开局没有栅栏，但「立栅」改造在棋盘图上有合法目标（棋盘内的边，以及棋盘格与相邻场景格之间的边），栅栏挡气不挡覆盖的规则照常生效。匠人改造框架照常可用，在棋盘图上实际可用的动作只有立栅。

工坊信物只扩展搭桥与烧林的格目标，在棋盘图上效果恒为空，但仍会按权重表生成（已知问题，留给地形去留或内容校准的 change 处理）。

这些规则仍由不经校验入口构造的合成盘面守门；任何把它们当作"已删除"而删掉实现或测试的改动，MUST 先经地形去留的 change 裁决。

#### Scenario: 棋盘图上不产生不可达地形
- **WHEN** 加载任一内置棋盘图或棋盘档生成图并统计开局地形
- **THEN** 没有高度不为 0 的格，没有深水、桥、栅栏、林地、土路与四种新地表

#### Scenario: 地形规则在合成盘面上照常生效
- **WHEN** 在不经校验构造的合成盘面上，h=0 孤子上方是 h=2 的空格
- **THEN** 该 h=2 格不计入孤子的气，判定与引入本条之前相同

#### Scenario: 棋盘图上立栅有合法目标
- **WHEN** 在棋盘图上，匠人持有者查询某个棋盘内落点的合法改造目标
- **THEN** 结果含立栅目标，不含任何搭桥与烧林目标
