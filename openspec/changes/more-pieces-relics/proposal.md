## Why

设计文档 §19 第 3 项把"增加更多通过连接、成线、邻接和资源位置生效的棋子与信物"排在 2 / 3 人地图（`small-maps` 已完成）之后。原型只有六种棋子、六类信物，§17 的平衡分析方向与 AI 评价都只覆盖这一组内容，组合空间偏窄。负责人 2026-09-25 裁决：新增四种棋子、四类信物，规则与数值按裁决原样落地（见 design.md「裁决记录」）；不重新校准 AI 权重，只跑 20 局冒烟。

## What Changes

- **四种新棋子**（基础军势各 1，只提供位置加值，参与倍增子 ×1.5ⁿ，不提供额外气、不免死，邻接一律沿气边）：
  - 旗手子：自身格与气边邻格中每有一个信物格 +3（按位置计，不论揭示与控制）。
  - 铁链子：每枚为所在棋串提供"棋串棋子数 − 1"。
  - 哨兵子：气边邻格上每个非己方棋子（含弃赛者遗留）+2。
  - 界碑子：气边邻格中每个己方独占空格 +1。
- 协同子的"类型数"计入四种新类型；位置加值与势力明细的来源由三项扩为七项。
- **四类新信物**（都没有 +2 版本）：
  - 连营：持有者每条长度 L ≥ 2 的连珠线额外 +L（计分信物，势力计算时实时读取）。
  - 犄角：持有者协同子每种加值由 2 变为 3，每多一枚再 +1（计分信物，实时读取）。
  - 驿站：持有者每控制一枚其他信物，征募展示数 +1（小回合开始的效果快照读取）。
  - 工坊：持有者的匠人格改造目标可隔一格（同行 / 同列直线距离 2）；立栅边目标与其余改造约束不变（快照读取，不叠加）。
- **征募**：棋池加入四种新棋子各 8（未校准），总权重 142；流派徽记可绑定十种类型。
- **生成**：权重表改为千分制；新四类在出生区各 50‰、公共区各 70‰，原六类等比缩减到 80% / 72%；高阶升级只对原有六类，新四类不消费升级抽签。
- **对局内容集**（v1 = 原六 + 六，v2 = 十 + 十）：新局缺省 v2；旧存档、旧日志缺字段按 v1，保证同种子重建出相同的信物分布与征募序列；v1 下与改动前逐步相同。
- **AI 适配**：新信物估值（未校准初值）与千分制期望；改造目标枚举带工坊标记；评价经唯一势力计算感知新棋子与计分信物，只用公开已揭示内容。
- **表现与遥测**：终端字母 / 名称 / 图例；Godot 四种新轮廓（灰度可辨）、手牌面板、势力层七项拆分、工坊目标高亮；日志记录内容集、七项来源、驿站来源与工坊扩展标记，分析报告增加新来源占比。
- 设计文档 v1.13 → v1.14（§8 / §9 / §20 与变更记录，另同步 §3.4 / §10.1 / §15 的受影响表述）。

## Capabilities

### New Capabilities

（无）

### Modified Capabilities

- `piece-effects`：基础军势表扩为十种；新增旗手 / 铁链 / 哨兵 / 界碑四条位置加值；协同类型数计入新类型并接受犄角；连珠接受连营；倍率作用范围列全七项来源。
- `power-score`：位置加值公式与势力明细的来源拆分扩为七项。
- `relic-effects`：信物表扩为十类；快照加入驿站加成与工坊标记；叠加规则注明工坊不叠加；新增驿站、工坊、计分信物（连营 / 犄角）三条规则。
- `relic-generation`：出生区 / 公共区权重改为千分制十类表；徽记绑定十种；升级只对原六类。
- `recruitment`：棋池十种、新四种各 8；新类型徽记调权；展示数计入驿站。
- `terrain-edit`：工坊生效时格目标可隔一格；"其余九种棋子"不得改造。
- `ai-decision`：先验表按内容集；新增 AI 适配（估值、工坊目标、类型次序、信息边界）。
- `match-telemetry`：日志字段与分析方向扩展，旧日志照常解析。
- `tactical-layers`：势力层七项拆分；匠人目标高亮含工坊扩展。
- `visual-style-baseline`：轮廓语言扩为十种。
- `hand-info-panel`：新类型显示与驿站来源逐枚列出。
- `batch-preview`：预演计入新棋子与已揭示计分信物，将揭示者不计。
- `match-setup`：新增"对局内容集"配置与旧存档兼容。

## Impact

- **Siege.Core**：`PieceType` / `RelicType` 末尾追加；`PieceEffects`（四条新加值、协同 / 连珠接信物修正）、`GroupPower` 与 `PowerCalculator`（多一份"已知信物内容"输入）；`RecruitWeights`（十档 + v1 表）；`RelicWeights` / `RelicGenerator`（千分制、稀有度刻度、跳过升级抽签、徽记绑定集合按内容集）；`RelicContent`（新四类只许 +1）；`EffectSnapshot`（驿站、工坊）；`TerrainEditRules.LegalTargets / Reject`（新增工坊参数，接口变更）与批次预演；`GameBoard` 类型码 `N C T K`；`MatchOptions` / 存档 / 日志首部的内容集字段；`RelicEstimate`、`BatchEvaluator`、`HeuristicTurnController` 的改造枚举。
- **Siege.Presentation / Siege.Sim / Godot**：`PieceStyleTable` 与轮廓枚举、`Labels`、`BoardRenderer`、`ConsoleController`、分析器、Godot 棋子几何 / 手牌面板 / 势力层 / 改造高亮。
- **走法变化**：v2 下同种子的信物分布、征募序列整体改变；依赖走法的黄金哈希 / 期望写死 v1 保持不变，v2 的期望按行为变更重建并归因。
- **AI 校准口径**：计分规则扩展，按 `ai-decision`「默认评价权重的校准」把权重表标注为"新内容下未重扫"，数值不变。
- **验证跑局**：v5 标准难度 20 局冒烟，只报告；不跑 200 局。

## Non-goals

- 带入带出与局外成长（下一个 change）。
- 公平信息边界下的正式 AI（之后的 change）；本 change 只做适配。
- 任何权重校准：征募 8、生成 50‰ / 70‰、信物估值初值与 AI 评价权重都不扫档。
- 不改基础四邻接、气、批次围杀、占据优先与唯一覆盖规则（§19 约束）。
