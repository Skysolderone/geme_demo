## Context

节拍生成（`Siege.Presentation.Show.SettlementBeats`）与时间线（`ShowTimeline`）已存在：落子 → 提子 → 势力三种节拍，遮罩 `ShowMask` 给出未落子集合、淡出中的被提子、各玩家当前显示势力值。公开快照的 `PowerSnapshot.Players[i]` 有 `TerritoryScore`、`GroupScore`、逐棋串 `GroupPower`（基础、七项加值、倍增数、军势）；`Relics` 有 `IsRevealed` 与内容；`PlayerStates` 有状态；`Result` 有终局结果。

## Goals / Non-Goals

**Goals**：每一枚落子、每一次提子、每一分势力都有看得见的反馈；节奏是"咣、咣、咣"的分段到账。

**Non-Goals**：见 proposal。

## Decisions

### D1 飘字内容全部来自结算后快照，节拍生成仍是纯函数

- 落子飘字：棋子类型名（经既有 `Labels.Piece`）+ 该格所在棋串在**结算后**快照里的军势算式文案。算式文案沿用势力层已有的 `FormulaText` 口径（同一份拼法，不另写）。找不到棋串（理论上不会）时只显示类型名。
- 提子飘字：固定文案"提"；节拍合计文案"提 N 子"。
- 势力分项：`TerritoryDelta = after.TerritoryScore − before.TerritoryScore`、`GroupDelta = after.GroupScore − before.GroupScore`，两者之和恒等于总增量（由 `Total = TerritoryScore + GroupScore` 保证，测试守住）。结算前无势力快照时两项旧值按 0。

### D2 势力节拍分段

势力节拍 0.9 秒拆成三段：领地段 0.35 秒（显示值从旧值滚到 旧值 + 领地Δ，段首数字放大 1.3 倍、段内回落）、军势段 0.35 秒（再滚到新值，同样弹一下）、定格 0.2 秒。某一分项为 0 时该段跳过、时长让给定格。多名玩家同时进行（与现状一致）。遮罩新增：每名玩家"当前段（领地 / 军势 / 定格）、段内进度、本段增量文案"。

### D3 新节拍

| 节拍 | 位置 | 内容 | 时长 |
|---|---|---|---|
| 信物揭示 | 提子之后、势力之前 | 本次结算 `IsRevealed` 由假变真的信物格：坐标、信物名（经既有标签） | 0.6 秒，与数量无关 |
| 横幅 | 势力之后 | 本次结算状态变为出局的玩家各一条"X 出局"；`Result` 由空变非空时一条"对局结束" | 每条 0.8 秒，依次 |

弃赛不是结算效果，不入横幅。空节拍省略，与既有规则一致。

### D4 落子飘字的时间

每枚棋子出现时飘字同时出现，上浮并在 0.6 秒内淡出；可跨到下一节拍继续淡出（遮罩里保留"活跃飘字"列表及各自剩余时间）。压缩落子（本机确认）时全部飘字同时出现。

### D5 零时长与既有基线

零时长模式下所有新节拍与飘字都不出现；`turn-settlement-show` 的 53 帧基线与截图自证必须保持一致。

### D6 图形实现

- 飘字：`Label3D` 与坐标标注同一画法（平铺、不用 billboard），字号按相机距离两档（沿用禁手标记的远近两档）。
- 排名栏数字弹跳：`Hud.RefreshRank` 按遮罩的段与进度设置字号缩放。
- 信物闪光：既有信物标记加一圈亮环，随进度衰减。
- 横幅：中央面板位置的一条大字，随进度淡入淡出；终局面板在横幅播完后才显示（现状是演出开始那帧就出现，A4 已知问题一并修）。

## Risks / Trade-offs

- **演出变长**：一次结算最长约 落子 1.0 + 提子 0.6 + 信物 0.6 + 势力 0.9 + 横幅 0.8×n。四倍提速仍在。
- **飘字重叠**：一批 3 枚相邻落子的算式会互相盖住 → 飘字按放置顺序错开 0.25 秒（本来就是逐枚出现），字号取小。
- **算式文案过长**：七项加值全展开会很长 → 只显示非零项，与势力层 `FormulaText` 一致。

## Migration Plan

纯新增。回滚 = 时间线里禁用新节拍、遮罩不输出飘字。
