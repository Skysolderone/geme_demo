## Context

现状（设计文档 v1.27）：`link:<种子>` 生成 5 块主题出生棋盘，间距 3 一字排开、彼此隔绝；战场 = 可落子格连通分量；合法落子范围恒为"所在战场的可落子格 − 禁入格"；第 3 大回合结束独占者两两配对、边对边拼接；每个大回合结束按战场结算淘汰，决赛再拼接；等待者与决赛倒计时 K 补救等待失衡。按座位视图与 AI 座位视野都以"战场"为边界。

负责人 2026-10-19 裁决 O1–O8（见 proposal）把"区域隔绝"本身去掉。本设计只描述状态模型、计算顺序与边界，不定技术栈。

## Goals / Non-Goals

**Goals**
- 建局即一张连通地图；构筑期按"自己的出生棋盘"限制落子与改造；第 4 大回合起全图；锁定后全图可见。

## Decisions

### D1 初始布局：建局时一次性紧贴（O3 = A）

- 生成器随机消费顺序不变：次序（Fisher–Yates）→ 各棋盘宽高 → 主题排列 → 按编号逐块地形 → 出生区信物 → 公共信物。**布局不消费随机**。
- 记种子决定的次序为 o0…o4。布局形态固定为 3+2 两行，**每块以一块具体的棋盘为锚**（不是以已合并的外接矩形为锚——那样 o4 只能叠在 o3 顶上，成 3+1+1 的塔）：
  - **第一行**：o0 的底边在留白行、西边在留白列；o1 的最西列 = o0 最东列 + 1，o2 的最西列 = o1 最东列 + 1，三块**底边对齐**（与现行 `Layout` 一致，只是间距从 3 改为 0）。相邻两块的共享边 = 二者中较矮者的高 ≥ 6。
  - **o3 贴 o0 北侧**：o3 的最南行 = o0 最北行 + 1；列偏移在"与 o0 共享边最长"的候选里取偏西者（即西边与 o0 对齐），共享边 = min(w0, w3) ≥ 6。
  - **o4 贴 o1 北侧**：o4 的最南行 = o1 最北行 + 1；列偏移在"与 o1 共享边最长、不越出原点、且不与已放下的棋盘重叠"的候选里取偏西者。
  - **换锚**（实施发现 R-1，规划时漏算了 o2）：第一行三块高低不齐时，较高的邻块会挡住原锚的北侧——o4 比 o1 宽且 o2 比 o1 高时 o1 北侧没有不重叠候选（o3 对 o0 / o1 同理），按原规则种子 1–400 有 21 张生成失败。规则：锚北侧放不下或最长共享边 < 4 时，改以第一行三块中与之共享边最长者为锚（并列取编号小者），仍贴北侧；种子 1–20 只有 `link:7` 的 o4 换锚 o2，1–2000 约 20.6% 换锚。
  - 每块都与第一行的一块共享边 ≥ 4，第一行自身相连，因此全图恰 1 个连通分量；外圈平坦无栅栏，接缝必有气边。画布区间取理论边界（列 22–30、行 16–20），种子 1–2000 实测列 22–28、行 16–20。画布原点固定在 (0,0)，按 5 块的包围盒四周留白 2 一次裁出；包围盒内棋盘之外的格（如 o3 与 o4 之间、o3 / o4 上方高低不齐处）是场景格。
- 结果 `MapVersion = 0`；地图在对局中不再变化。"矩形贴边 + 共享边长度 + 重叠排除"抽成布局用的纯函数；段 B 删除链接事件后它是唯一的布局几何实现。
- 画布尺寸区间与可落子总数区间按种子 1–20 实测回写校验器链接行（可落子总数 = 5 块之和，应仍落在 212–280）。

### D2 战场导出与校验

- `Battlefields.Of` 不改：按几何四邻导出连通分量，开局即恰 1 个、含全部 5 块出生棋盘、标识为 0。
- 校验器：「物化状态校验」改为"恰 1 个连通分量且含全部出生棋盘"（删"分量数 = 出生棋盘数 − 版本号"与"未链接战场不相邻"）；接缝 ≥ 1 气边的检查保留并对全部相邻棋盘对执行；棋盘不重叠保留；可落子格都属于某块棋盘保留。
- 地图数据里的 `MapVersion`、`Boards` 清单保留；`BirthBoard(zone)` 给出整块棋盘的格集合，是构筑期合法范围的几何基。

### D3 合法落子范围按大回合两段（O1 / O2）

- 唯一实现 `PublicRules.LegalRange(board, birthZone, player, life, majorRound)`：
  - `majorRound ≤ BuildProtectionRounds`（= 3）：范围基 = 出生棋盘 `birthZone` 的格 ∩ 当前可落子格（按当前地形现算，本局架的桥立即可落；岩石与未架桥深水不可落）。同区者的范围基相同。
  - 否则：范围基 = 所在战场（= 全图）的可落子格。
  - 两段都扣除本人禁入格，扣除只在这一处（R12 不变）。
- 调用点：对局流程的小回合批次上下文（传当前大回合）；专家前瞻模拟对手（传该对手的行动大回合，跨大回合时为当前 + 1）与两层加分（专家本人下一大回合）。
- 出生区标记（3×3 核心区）MUST NOT 施加限制：构筑期范围是整块棋盘。

### D4 构筑期内改造目标限自己棋盘（O6）

- 新增公开纯函数 `PublicRules.EditScope(board, birthZone, majorRound)`：构筑期 = 出生棋盘格集合，否则 = 全图格集合（不扣禁入格；改造目标不是落点）。
- 改造候选枚举与批次校验 MUST 都经它过滤：搭桥 / 烧林的目标格 ∈ scope；立栅的边两端格都 ∈ scope（以场景格为一端的边本就无效果，不额外放行）。
- 候选枚举是 AI 与预演共用的一处；校验失败的原因文案指明"构筑期内改造目标须在自己的出生棋盘内"。

### D5 可见性与占位（O4）

- 按座位视图的过滤边界仍是"所在战场"，锁定后战场 = 全图，因此投影自然含全图：全部棋子、地形与设施、空格归属、信物揭示、全部玩家的势力明细与禁入格、本大回合全员 Pass 名单。数据层过滤机制保留（段 B 可简化为"插旗前 / 后"两态）。
- 插旗阶段：仍只见 5 个占位（位置、宽高、主题名），盲选不变。锁定后：5 个占位全部展开；"未展开"状态在锁定后不存在。
- AI 缺省座位视野随之为全图；全知开关在段 A 保留（结果与座位视野相同），段 B 删除。

### D6 流程：段 A 自然直通，段 B 删除

- 段 A 不改阶段机：第 3 大回合结束时首轮配对候选 = 独占者所在战场集合 = {0}，候选 ≤ 1 → 现有分支"直接进入交战"；决赛触发条件"每个含在局玩家的战场只剩 1 人"在唯一战场上只有结算后才成立，而结算即终局（最后战场结算）。倒计时：已核对 `MatchFlow.Countdown.IsWaitingForFinal`——"等待决赛的玩家"要求其所在战场**只剩他一名在局玩家**，唯一战场上在局 ≥ 2 时没人满足，在局 = 1 时对局已因"只剩一名参赛玩家"终局，因此 K = 2 缺省下起点 R 永不设定、不赋任何期限；段 A 不改 K，由基线自洽检查（`*-k0.txt` 与缺省相同）兜底。构筑期内全员 Pass 同样结算终局。
- 段 B 删除：`AwaitingPairing` / `AwaitingFinalLink` 阶段、配对事件与来源、链接事件与记录、等待者统计、倒计时与 K（对局配置、存档、日志首部、批次配置）、`LinkStage`、存档的链接段、`LinkMapGenerator.Link` / `Sequences`、`MapVersion` 增长路径。`EndReason.LastBattlefieldSettled` 与"战场落败"的出局类别保留（命名不改）。
- 改动前的链接存档：地图按种子重新生成后摘要不符 → 现有机制拒绝恢复；旧日志回放同理。不迁移。

### D7 表现层与图形版

- 渲染 / 相机 / 底座：按整张地图（= 唯一战场）绘制地砖、棋子、设施与信息层；底座覆盖整张画布的棋盘包围盒；全局预览（M）在一屏看不全时照旧。
- 锁定后：5 块棋盘直接整图显示（与现行"锁定即重搭显示"同一路径，不加展开演出；原「棋盘展开节拍」是拼接时的滑入演出，随链接一起删除）。
- 删拼接演出、战场结算横幅、他场提示条、倒计时提示条的触发（段 A 不触发即可；段 B 删代码）。终局沿用既有终局横幅与出局横幅。
- `--auto-demo` 自检（`LinkDemoAudit`）改为四步：插旗锁定（5 块占位全部展开，可见格 = 全图可落子格）→ 构筑期（第 1–3 大回合合法范围非空且 ⊆ 自己的出生棋盘）→ 全图解禁（第 4 大回合合法范围 = 全图可落子格 − 禁入格，严格大于自己棋盘的格数）→ 终局（原因"最后战场结算"或"只剩一名参赛玩家"）。`--rounds=0` 要求四步齐全。`--pick-check` 只在锁定后对全图跑一次拾取。

## 已知歧义与风险

- **3+2 布局公平**：中间块（o1）与 3 块相邻，角块与 2 块相邻；插旗时位置公开。登记观察，不处理。
- **对局长度**：4 人从第 4 大回合起在 212–280 格上混战，可能比现行 15–16 大回合长；D10 只报数。
- **接缝覆盖**（O7）：靠边棋子覆盖伸进邻居外圈、算领地分；构筑期内双方都不能落到对方棋盘，覆盖对称，接受。
- **构筑期内提子**：构筑期内只能在自己棋盘落子，但靠接缝的棋串的气在对方棋盘上，对方不能落子去堵，所以构筑期内不可能跨接缝提子；第 4 起正常。无需特例。
- **AI 耗时**：座位视野 = 全图后，AI 评价范围从单棋盘扩到全图（约 250 格），与现行决赛阶段量级相同，冒烟记录单小回合耗时。
