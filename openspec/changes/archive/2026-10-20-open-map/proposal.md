## Why

负责人 2026-10-19 试玩反馈：链接模式把 4 人锁在各自隔绝的出生棋盘上，看不见的对手把自己的棋盘填满也无人能制裁；为了让隔绝的人碰面又引入了配对 / 拼接（"区域融合"）/ 逐战场结算 / 决赛 / 倒计时一整套机制——根因是"限制区域"本身。本 change 取消区域隔绝：5 块出生棋盘在建局时就边对边紧贴成**一张连通地图**，第 1–3 大回合只能在自己的出生棋盘内落子与改造，第 4 大回合起全图可落；插旗锁定后全图全可见。配对、拼接、等待者、决赛链接与决赛倒计时随之删除，对局阶段只剩 插旗 → 构筑 → 交战 → 终局。

对应设计文档章节：§3.3（链接档地图与拼接）、§4（开局与前三大回合；§4.2 构筑期；§4.3 配对、拼接与等待）、§12.3–12.4（战场结算、决赛与终局）、§13（信息公开）、§15.2（专家前瞻的名册与合法范围）、§17（日志中的配对 / 链接事件与等待统计）、§19 观察项。设计文档 v1.27 → v1.28。

## What Changes

- **地图**：初始布局由"5 块棋盘间距 3 一字排开、彼此隔绝"改为"5 块棋盘边对边紧贴成一张连通地图"（3+2 两行；贴边几何复用现行拼接规则：共享边最长、并列偏南 / 偏西、画布原点固定、四周留白 2）。校验器改为"恰一个连通分量且含全部 5 块出生棋盘、每条接缝至少 1 条气边"；画布区间按种子 1–20 重新实测回写。地图不再在对局中增长，`MapVersion` 恒为 0。
- **合法落子范围**：第 1–3 大回合 = 自己锁定的出生棋盘的可落子格（同区共享，按当前地形现算）− 本人禁入格；第 4 大回合起 = 全图可落子格 − 本人禁入格。合法范围重新带大回合参数，仍只有一处实现。
- **保护期内改造目标**（O6）：第 1–3 大回合，搭桥 / 烧林的格目标与立栅的边的两端格都 MUST 在自己的出生棋盘内；候选枚举与批次校验同一实现。
- **可见性**（O4）：锁定后整张地图就是唯一战场，按座位视图含全图（地形、棋子、设施、信物揭示、全部玩家的势力明细、Pass 名单）；"未展开"只在插旗阶段存在，锁定后 5 块棋盘一起展开。AI 缺省座位视野随之等于全图（全知开关在段 B 删除）。
- **BREAKING（规则）** 删除配对事件、链接事件、等待者、决赛链接、决赛倒计时（含对局配置 K）；阶段只剩 插旗 → 构筑 → 交战 → 终局。整张地图是唯一战场：整轮 Pass / 填满 / 只剩一人即结算、即终局；名次沿用现有判定链（O5）。构筑期内全员 Pass 同样结算终局（与旧规则一致）。
- **BREAKING（存档 / 日志）**：存档与日志不再写配对 / 链接记录与 K；改动前的链接模式存档因地图内容摘要不符被拒绝，不做迁移；旧日志的回放同理拒绝。
- **Sim / 遥测**：删 `--pairing-seed` 与配对来源、`map --links`、链接事件、等待者评估、决赛倒计时记录与分析；链接模式报告段只剩同区率与各出生棋盘被选次数。
- **图形版 / 表现层**：按整张地图渲染、取景与铺底座；锁定后 5 块棋盘一起展开（一次展开演出）；删拼接演出、战场结算横幅 / 他场提示条、倒计时提示条（终局沿用既有终局横幅）；`--auto-demo` 自检改为 插旗锁定 → 构筑期 → 全图解禁 → 终局 四步；`--pick-check` 只在锁定后对全图跑一次拾取。
- **测试与基线**：15 份链接图决策序列基线重钉；只测配对 / 拼接 / 倒计时 / 等待者 / 拼接演出的测试段 A 整文件 Skip、段 B 随代码删除；`link:90008` 单棋盘载体上的规则测试不受影响。
- **文档**（段 B）：设计文档 v1.28、HANDOFF、`.trellis/spec/core/boundaries.md` 同步；登记对局长度与布局公平两项观察。
