## Why

领地层与气层在棋盘上点亮的是**完全同一批格子**。这不是近似，是定义上的等价：覆盖的规则是"棋子向四邻接相邻格提供覆盖"，气的规则是"棋串的空邻格"，所以一个空格被某方覆盖，等价于它紧挨着该方的某枚棋子，也就等价于它是那条棋串的一口气。

实测确认（4 人盘面，P0 三子、P1 两子、P2 两子、P3 一子）：

| | 领地层 | 气层 |
|---|---|---|
| 点亮的空格 | 21 个 | 21 个 |
| 两集合是否相同 | 是，双向差集均为空 | |

玩家在两个层之间来回切换，看到的是同一片格子换了一种着色规则。这正是它读起来像重复的原因——用户在试玩截图上圈出这两个按钮，标注"重复"。

两者各自仍有对方没有的信息：领地层另画有棋子的格（本例 8 格）与无人覆盖的中立格（52 格），气层另给棋串分组（4 条）与各自的危险度。所以重复的是**哪些格子被点亮**，不重复的是**为什么点亮**。

## What Changes

- **BREAKING** 领地层与气层合并为**盘面层**，它有两种读法：**归属**（占据 / 独占 / 争议 / 中立）与**棋串**（棋串轮廓、每口气、危险度）。信息层由五种变为四种。
- 盘面层的两种读法一次只显示一种，切换不影响其它层的互斥规则。
- **BREAKING** 键位顺延：`1` 盘面层、`2` 势力层、`3` 信物层、`4` 顺序层。手柄同步顺延一位。
- 点击切换模式下，盘面层键循环三态：关闭 → 归属 → 棋串 → 关闭。
- 按住显示模式下，盘面层键只管显示与隐藏；读法用独立键 `Tab` 切换（按住期间无法"再按一次"同一个键，见 design.md D3）。
- 设计文档 §14.2 的五层列表改为四层，并写明合并的依据。

## Capabilities

### New Capabilities
无。

### Modified Capabilities
- `tactical-layers`: Requirement「五种战术信息层」改为四种并新增盘面层的两种读法；新增 Requirement「盘面层的读法切换」。

## Impact

- 前置：`add-tactical-ui`（层状态机与键位表）、`coverage-territory`（覆盖定义）。
- 受影响代码：`TacticalLayer` 枚举、`TacticalLayerState`、`LayerContents`、`VisualBaseline` 的 `SceneTreatment`、`BoardView` 的层绘制、`Hud` 的按钮栏与图例、`InputBindings` 的键位表。
- 受影响测试：所有引用 `TacticalLayer.Territory` / `TacticalLayer.Liberties` 的测试。
- 不影响任何规则计算：层只读公开视图，零副作用的约束不变。

## Non-goals

- 不合并势力层。它与右上角排名面板的重复程度不同，需要单独评估。
- 不改覆盖与气的规则本身。
- 不改「一次只显示一层」的互斥规则。
- 不改按住显示 / 点击切换这两种输入模式本身。
