# 任务：merge-board-layer

## 1. 守门测试先行

- [ ] 1.1 测试：两种读法点亮的空格集合恒等（规格 Scenario「两种读法点亮同一批空格」）。用真实盘面，测试内独立取集合做双向差集，不调用实现自己的比较。验证：变异——让归属读法把争议格也算成中立，测试变红。
- [ ] 1.2 测试：归属读法另有棋串读法没有的格（占据格与中立格）。这条挡的是"合并时顺手把归属读法削成气的子集"。
- [ ] 1.3 测试：点击模式下层键三态循环（关闭 → 归属 → 棋串 → 关闭）。验证：变异——把第三态改成回到归属，测试变红。
- [ ] 1.4 测试：按住模式下，两次按住之间读法不变。验证：变异——把读法推进挪到 `Press` 里，测试变红。
- [ ] 1.5 测试：读法跨越关闭被记住。
- [ ] 1.6 测试：切换读法不改变其它层可见性，也不触碰任何对局对象（沿用既有的零副作用守门写法）。
