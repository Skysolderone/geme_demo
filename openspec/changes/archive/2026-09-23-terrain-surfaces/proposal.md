## Why

现有地表只有草地 / 土路 / 林地 / 深水四种，其中草地与土路规则等价，真正带规则差别的只有林地（不接收覆盖）与深水（不可落子、可隔一格覆盖）。地图在视觉与战术上都偏单一：一张图上能"读"出来的地形取舍只有崖壁、栅栏、林地、河四样。本 change 新增四种**带规则效果**的地表，每一种只在既有的一个规则杠杆上做差别（产生覆盖 / 覆盖射程 / 气 / 领地计分），让地形读法更丰富而不引入新机制。对应设计文档 §3.1（格属性、气边、覆盖关系）、§3.4（地形改造）、§7.2（空格归属）、§10（势力值）、§14（信息界面）、§15（AI 设计）、§20（视觉风格基准）；裁决记录见本 change 的 design「裁决表 S-1–S-10」。

## What Changes

- **地表由四种扩为八种**：新增 **荒漠**、**沼泽**、**岩台**、**浅滩**，全部是可落子格，高度与地表互相独立。
  - **荒漠**：空的荒漠格可被独占（参与信物控制与盘面读法），但**不计领地分**；棋子在荒漠上照常计军势。
  - **沼泽**：沼泽上的棋子**不产生覆盖**；沼泽格本身照常接收覆盖、提供气、计分。
  - **岩台**：岩台上的棋子除常规覆盖目标外，还覆盖四个方向**直线距离 2** 的格；远格同样受"可落子、非林地、不仰视崖壁"约束；中间格为障碍、盘外或高出崖壁时阻挡，深水、棋子、栅栏、林地不阻挡。
  - **浅滩**：**空的浅滩格不是任何棋串的气**；浅滩上的棋子照常按邻格计气。空浅滩不能成为眼空间的一部分，且会破坏相邻空区的封闭。
- **BREAKING（地图文件格式）**：地图文件的地表字段新增四个取值；旧地图文件仍可原样读取，内置地图 `siege-4p-base-v5` 与 `siege-frontier-v2` 逐格不变。
- **生成器**：新增生成参数"新地表"（开 / 关）；标识新增可选段 `:s1`。缺省关——既有 `gen:<种子>[:p<N>]` 标识生成的地图逐字节不变；入口"随机取种子"（裸 `gen` 与选图界面"换一张"）改为默认开启新地表。
- **匠人改造**：四种新地表都不是任何改造动作的目标；改造动作集不变。
- **AI**：启发式评价通过 Core 的唯一规则查询自然感知四种地表（覆盖、气、领地分都走同一实现），另为候选剪枝与廉价预筛补上地表感知；不另写规则。
- **表现**：每种新地表有独立的地砖色 + 灰度下可辨的形状提示（装饰部件），并纳入 `--export-parts` 导出；气层标出"空浅滩不算气"，覆盖 / 归属读法画出岩台远格；终端版有独立字符。
- **设计文档**：§3.1 地表清单、标准算例与一句话记法同步更新，变更记录追加一条。

## Capabilities

### New Capabilities
无。

### Modified Capabilities
- `terrain`: 修改「格属性」（地表八种与各自规则语义）、「覆盖关系」（沼泽源、岩台远格）。
- `board-topology`: 修改「气的计算」（空浅滩不计入气）。
- `coverage-territory`: 修改「棋子向四邻接相邻格提供覆盖」（沼泽 / 岩台）、「空格归属三态」（荒漠独占不计分）。
- `power-score`: 修改「总势力」（领地分只计非荒漠的独占空格）。
- `life-shape`: 修改「空区与封闭眼空间」（空浅滩不属于任何空区、并破坏相邻空区的封闭）。
- `piece-effects`: 修改「高地压制加值」（明确沿用唯一覆盖关系：沼泽棋子无压制、岩台远格参与压制）。
- `terrain-edit`: 修改「改造动作集」（新地表不是改造目标）。
- `map-definition`: 修改「地图静态校验规则」（新增第 9 条：出生区内不得有四种新地表）。
- `map-generation`: 修改「生成参数」「布局规则」「生成图的地图标识」（新地表开关与投放规则、`:s1` 段）。
- `tactical-layers`: 修改「五种战术信息层」（盘面层差集的地形来源增加岩台远格、空浅滩、沼泽源）；新增「新地表的规则标示」。
- `visual-style-baseline`: 修改「方格边界与合法落点始终清晰」（新地表在默认视图下可判读）；新增「新地表的灰度可辨」。
- `ai-decision`: 新增「AI 对地表的感知」。

## Impact

- **前置 change**：`ai-eye`（在途，修改 `ai-decision`「启发式评价维度」与 `GroupSafety`；本 change 的 AI 段必须在其归档之后实施，且只以 ADDED 需求触碰 `ai-decision`，避免与其 MODIFIED 冲突）；`life-shape`、`terrain-model`、`artisan-terrain-edit`、`map-generator` 已归档。
- **受影响代码**：`Siege.Core/Board`——`Surface`、`TerrainData`、`MapFile`、`Adjacency`（覆盖源、岩台远格、气邻格）、`TerrainEditRules`（守门）、`Maps/FrontierMapGenerator`、`FrontierMapLayout*`（投放与校验）、`GeneratedMapId`；`Siege.Core/Scoring`——`CoverageMap` / `PowerCalculator`（荒漠不计分）；`Siege.Core` 活形分析（空区定义）；`Siege.Core/Ai`（剪枝与预筛）；`Siege.Presentation`——`LayerContents`（气层 / 盘面层标示）、`VisualBaseline`；`Siege.Sim`——`BoardRenderer` 字符、`Program`；`src/godot`——`BoardView`、`LowPoly`、`Visuals`、`PartExport`。
- **测试**：每条新增 / 修改的 Scenario 对应中文命名测试；既有 v5 / frontier-v2 相关测试、200 局基线与生成图逐字节快照 MUST 保持不变。
- **数值**：岩台与浅滩直接改变覆盖与气的供给，段 3、段 4 完成后各跑 200 局同种子对照，报告交负责人裁决。

## Non-goals

- 不改内置地图 `siege-4p-base-v5` / `siege-frontier-v2`；若要一张展示新地表的内置图，另开 change。
- 不新增改造动作（例如"排干沼泽""填浅滩"）；需要时另开 change。
- 不让地表影响征募、信物生成权重或行动顺序。
- 不做地表的随对局变化（季节、水位等）。
- 不调 `ai-eye` 校准后的九维权重本身；若 200 局对照显示新地表下权重明显失配，另开数值 change。
