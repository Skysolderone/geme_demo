## Context

`terrain-model` 定下了地形的三层结构：格属性（高度 / 地表 / 障碍 / 桥）、边属性（栅栏），以及从中导出的两套关系——**气边**与**覆盖关系**，各只有一处实现（设计文档 §3.1）。在此之上，空格归属与领地计分（§7.2、§10）、活形分析（§6.4、`life-shape`）、高地压制（`piece-effects`）都只通过这两套关系读取地形。

现有地表只有四种，真正带规则差别的只有林地（不接收覆盖）与深水（未架桥时不可落子，覆盖可隔一格）。本 change 新增四种地表，每种只动一个既有杠杆：

| 地表 | 杠杆 | 唯一落点 |
|---|---|---|
| 荒漠 | 领地计分 | 空格归属 → 领地分的过滤 |
| 沼泽 | 覆盖**源** | 覆盖关系 |
| 岩台 | 覆盖**射程** | 覆盖关系 |
| 浅滩 | 气（空格能否作为气） | 气的计算 + 空区定义 |

新地表全部是可落子格，**不改变气边**。这使得连接、棋串、栅栏 / 崖壁语义、盘面同形比对（地表本就在比对状态里）全部不需要改动。

## Goals / Non-Goals

**Goals**
- 四种地表的规则差别各自只在一处唯一实现里出现，其余规则通过既有查询自然继承。
- 内置地图与既有生成图标识的产物逐字节不变；既有 200 局基线仍可复现。
- 四种地表在默认视图与灰度下可辨，信息层能解释它们造成的"覆盖 ≠ 气"差集。
- AI 不另写地表规则，通过唯一查询感知地表。

**Non-Goals**
- 不改内置地图、不新增改造动作、不让地表影响征募 / 信物 / 行动顺序、不做地表随对局变化、不重新校准 `ai-eye` 的权重（均见 proposal）。

## Decisions

### D1 地表仍是单一枚举，规则分支只进唯一查询

`Surface` 从 4 值扩为 8 值。规则层对地表的判断只允许出现在下列四个既有的唯一实现里，每处新增一个**具名谓词**，其他代码只能调用这些谓词：

| 谓词（语义名） | 所在唯一实现 | 真值 |
|---|---|---|
| 产生覆盖 | 覆盖关系 | 地表不是沼泽 |
| 覆盖射程为 2 | 覆盖关系 | 地表是岩台 |
| 空格可作为气 | 气的计算 | 地表不是浅滩 |
| 独占计分 | 空格归属 → 领地分 | 地表不是荒漠 |

守门测试（源码扫描）：规则层与表现层中，除上述四处与地图读写 / 生成器 / 渲染的地表映射外，MUST NOT 出现对四种新地表枚举值的直接比较。表现层与 Godot 层沿用既有禁表（不得调用邻接、覆盖计算）。

备选：给每种地表挂一张"规则属性表"（产生覆盖 / 射程 / 给气 / 计分四个布尔 + 整数），规则层只查表。否决：四个属性各只有一种地表取非缺省值，表会把"唯一实现"分散成"一张表 + 四处读取"，且未来地表不一定能用这四维描述（YAGNI）。

### D2 覆盖关系的计算顺序

对棋子 s（位于格 c、高度 h_s），按下列顺序求覆盖目标集合，结果按格去重、按坐标序输出：

1. c 是沼泽 → 返回空集。
2. 近格：沿用现有规则（相邻格；一格宽未架桥深水 → 对岸）。
3. c 是岩台 → 对每个方向：m = c + d，u = c + 2d；若 m 在盘内、m 不是障碍、h_m − h_s < 2，且 u 接收来自 s 的覆盖，则加入 u。

"接收来自 s 的覆盖"沿用现有定义（可落子、非林地、h_t − h_s < 2），不改。

边界条件：
- m 在盘外 → u 必在盘外，自然排除；显式判定 m 仍保留，避免依赖坐标越界行为。
- m 是未架桥深水时，第 2 步已经可能加入 u（隔水覆盖），第 3 步再次加入同一格，由去重吸收。
- m 是比 s 高 1 的缓坡格不阻挡（h_m − h_s = 1 < 2）；m 是崖壁（高出 ≥ 2）阻挡——这是 S-3a′ 在高度维度上的自然推论（覆盖不越过仰视崖壁），**请负责人在审阅规格时确认**（规格「岩台远格被高崖阻挡」已按此写）。
- 岩台上的棋子若同时位于高处（h_s = 2），远格可以是 h = 0 的低地，此时远格照常参与高地压制（S-2′ 的对偶）。

### D3 浅滩：只改"空格能否作为气"，不动气边

气的计算从"有气边的空可落子格"改为"有气边、为空、且空格可作为气的可落子格"。气边本身不变，因此：

- 浅滩上的棋子照常沿气边连串；
- 浅滩格被占据时，它对邻居来说本来就不是气（被占格）——浅滩只在**为空**时生效；
- 提子把浅滩格腾空后，它不回到任何棋串的气里。

连带影响（全部经由既有规则自然产生，不另写）：

| 规则 | 影响 | 是否需要改规格 |
|---|---|---|
| 无气判定 / 提子 / 自杀（`capture-resolution`） | 只挨空浅滩的棋串无气，按"以整批最终状态判定合法性"处理 | 否，规格按"气"定义 |
| 活形分析（`life-shape`） | 空浅滩不属于任何空区；贴着空浅滩的空区不封闭 | **是**，见下 |
| 禁入格 | 由活形分析决定，自然继承 | 否 |
| 盘面层棋串读法 | 空浅滩邻格需与"气"区分显示 | **是**（`tactical-layers` 新增） |
| AI 安全 / 眼位维度 | 走唯一查询，自然继承 | 否（`ai-decision` 新增的是约束，不是改算法） |

**活形分析为什么不把空浅滩当墙**：墙（障碍、深水、崖壁、栅栏、盘外）的共同点是**任何玩家都不能从那里进入**。空浅滩可以被任何玩家落子，一旦敌子落进去，它就贴上了该空区——所以它必须破坏封闭（新增第 4 条），而不是被当作墙跳过。

备选：把空浅滩当作"对 P 封闭时可以属于 P 的眼空间、但眼值为 0"。否决：眼值三态的分类表（`life-shape`「活形三态」）不认识"零值格"，要改分类表，远超本 change 范围。

### D4 荒漠：领地分过滤在"归属 → 计分"之间

空格归属三态本身不看地表（荒漠照样可以独占、争议、中立），因此信物控制与归属读法都不受影响；只在"独占格数 → 领地分"这一步过滤掉荒漠。势力明细与势力层用同一个过滤后的数，不另算。

### D5 地图文件与终端字符

- 地图文件地表码：`G` 草地、`R` 土路、`F` 林地、`W` 深水，新增 `D` 荒漠、`M` 沼泽、`P` 岩台、`S` 浅滩。解析错误信息列出全部 8 个码。旧文件只含 4 个旧码，原样可读；序列化旧地图逐字节不变。
- 地表 ↔ 字符码的映射仍只在地图读写一处；终端版字符另有一张映射，两张表各自有"8 值全覆盖"的守门测试。

### D6 生成器：独立随机子流，布局后投放

新地表投放在全部布局与校验（平台、过渡带、河、桥、栅栏、林地、信物、填充）完成之后进行，使用由地图种子派生的**独立**子流；开关为关时不派生、不消耗该子流。因此：

- `gen:<种子>[:p<N>]` 的产物逐字节不变（既有快照测试与 200 局基线不受影响）；
- 同一种子下 `:s1` 与无 `:s1` 两张图只差被改写的地表格。

投放算法（只描述约束，不限定实现）：在"平台之外、非桥、非信物的草地 / 土路格"集合上，按坐标序、按浅滩 → 岩台 → 荒漠 → 沼泽的顺序（约束最紧的先投，段 5 实测：荒漠 / 沼泽先投会占掉河岸，p5 / p7 / p8 的个别种子上浅滩无处可放），每种先选种子格再沿几何四邻生长到 2–6 格；浅滩的种子格从"与主河深水几何相邻"的候选里选（主河含桥格——桥格地表仍是深水；过渡带只在桥处跨河，不算桥格时河岸候选几乎为空），岩台的候选限定 h ≤ 1；同种地表的新块不得与已投放的同种块几何相邻（否则两块连成一块）。投放目标在 [max(下限 + 1, 8), 上限] 中取（8 = 四种各一块最小块，第 0 轮为后面的种类预留余量），下限 = 平台外可落子格 × 15% 向上取整，上限 = × 25% 向下取整（2026-09-23 负责人裁决由 8%–16% 调高：旧比例在 25×30 图上只投 9–19 格，视觉偏稀）。已投放的格不再被后续地表改写。候选不足以满足"每种至少 1 块"时，生成 MUST 报错并给出种子，而不是静默少投——该情况在 25×30 边疆档下预期不会发生，由 1–50 种子的 Scenario 兜底。

投放完成后照常跑一遍 `map-definition` 静态校验（新增第 9 条：出生区内无新地表）。因为投放不改可落子性、高度与气边，既有的连通性、走廊宽度、"一子隔断"检查的结论不会变；仍然重跑是为了让"校验闭环"保持一处。

### D7 标识与入口

标识语法 `gen:<种子>[:p<N>][:s1]`，段序固定（`:p` 在前）。解析器接受 `:s1`，拒绝 `:s0`（缺省值必须省略，保持规范化唯一）与任何其他 `:s` 值。裸 `gen` 与选图界面"换一张"默认拼 `:s1`；手输 `gen:<种子>` 仍得到无新地表的图。

选图界面（实现口径，段 5 落地）：随机图一项进入时即为开（它本身就是入口随机取的种子）；按标识预选（`--map-select --map=gen:…`）照标识原样，不带 `:s1` 就是关；"换一张"一律置为开；输入种子、调平台数保持当前开关。批量跑局的"每局换图"沿用起始标识里的开关（`gen:100:s1` → `gen:101:s1`）。

### D8 表现层

- Presentation：盘面层的格视图模型新增"空浅滩邻格"的标记（来自气查询与格地表的差），势力层的独占格区分"计分 / 不计分"（来自 D4 的同一过滤）；图例文本只列当前地图出现过的新地表。
- Godot：`BoardView` 按地表选地砖色；新增四类装饰部件（荒漠点缀、沼泽水洼与芦苇、岩台裂纹与加厚边、浅滩鹅卵石），与既有部件一样按坐标散列取变体（不用随机数）；浅滩水面与地砖齐平，深水维持低于地砖。四类部件加入 `PartExport` 的导出清单。
- 灰度可辨的验收沿用项目惯例：截图 + 灰度版 + 人工清单（`art/` 下新目录），不做图像比对。

### D9 与其他 change 的接口契约

| 对方 | 输入 / 输出 | 时机 |
|---|---|---|
| `ai-eye`（在途） | 本 change 的 AI 段只以 ADDED 需求触碰 `ai-decision`；剪枝 / 预筛读覆盖与气的唯一查询。`ai-eye` 修改的「启发式评价维度」与 `GroupSafety` 以其归档后的版本为准 | 本 change 全部实现在 `ai-eye` 归档之后开始 |

## Risks / Trade-offs

- **浅滩改变气的供给** → 可能显著增加早期提子与"开局自杀"式的非法批次；段 4 的 200 局对照专门观察整局无提子占比、非法批次率、首次活形确立大回合。
- **岩台放大覆盖** → 生成图上岩台块的归属可能左右中局领地；投放占比（15%–25%）与每块上限（6 格），段 3 的对照若显示岩台控制者胜率异常，下一个数值 change 调投放而不是调规则。
- **AI 的近似量** → 剪枝阶段若仍按草地估计，AI 会系统性高估荒漠 / 沼泽落点。`ai-decision`「AI 对地表的感知」用"剪枝估计等于唯一查询"的测试钉住。
- **视觉混淆**（沼泽 vs 林地、浅滩 vs 深水、岩台 vs 高一层）→ 规格给出了形状通道的硬约束与四个人工检查 Scenario。
- **规格文本膨胀** → MODIFIED 需求整段复制，归档时以本 change 的版本覆盖主规范；`ai-eye` 同时在修改 `ai-decision`，本 change 只 ADDED，避免合并冲突。
