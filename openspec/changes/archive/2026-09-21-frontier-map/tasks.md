## 4. 段 C——相机逻辑（Siege.Presentation，零 Godot）

- [x] 4.1 相机视图模型：状态为注视点 (x, z) 与距离 d；输入为平移意图（-1..1 的二维向量）、缩放步进、"回家"目标、地图外接矩形；输出相机位姿。俯角恒为 60°、朝向恒定。平移速度与 d 成正比。验证：单元测试——平移不改 d 与俯角；缩放不改注视点与俯角；d 在最近 / 最远限值夹取。
- [x] 4.2 边界夹取：可行矩形 = 外接矩形向内收缩所见范围之半（所见范围按 d 线性近似）；某方向所见范围 ≥ 地图跨度时锁中线；缩放后立即重夹。算例：v4 在最远缩放下两方向都锁中线，任意平移意图后位姿不变；边疆图上持续向左推，注视点停在可行矩形左缘；在一角拉到最远后注视点被拉回。验证：单元测试逐条。
- [x] 4.3 最远限值 = min(整盘一屏所需距离, 上限)；最近限值保证完整显示一个 5×5 平台；v4 的最远距离 MUST 等于现固定相机的距离公式取值。验证：单元测试断言 v4 初始位姿与现 `BoardView` 的相机位置 / 注视点数值相等。
- [x] 4.4 回家目标：出生平台中心 = 该出生区格子的外接矩形中心；未选区时为地图中心；回家只改注视点不改 d，结果同样经过夹取。验证：单元测试。
