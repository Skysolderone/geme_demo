## Context

`LinkMapGenerator.Themes.cs` 的 `Draft` 按主题往中间带放地形：
- `River()` 从 `RiverCourses()` 选一条贯穿中间带、两端抵到外圈内侧的河道，加 1 座桥；
- `Plateau()` 放 2–4 格高 2 平台，四邻是高 1 的坡。

外圈由 `BoardPlate.OnRim` 定义，校验器 `BOARD_RIM_NOT_FLAT` 要求外圈全平。布局子流的消费顺序固定，新地表另用独立子流叠加。裁决见 proposal（H1–H8）。

## Goals / Non-Goals

**Goals：** 河流 / 高台成为横穿棋盘的隔断线，各只留 1 处通道；每块加 1 团湖泊或岩区，把全图可落子格压到约 180–230；其余规则与布局几何不变。

**Non-Goals：** 见 proposal 的 Non-goals。

## Decisions

### D1 隔断线的几何（按实施修订 J1–J3 改写）

> 修订：隔断线取自中间带的一整列 / 一整行，只要求不穿过核心区本身（J1、J2）；高台只把线本身抬到高 2 成山脊（J3）。下面原文中的"核心区 ±2""外侧整片高 2""取外圈那一行 / 列"均作废。

在核心区之外、与棋盘的一条边平行，选一条直线：行或列，且 MUST NOT 与核心区及其四邻相交，从棋盘一侧外沿贯穿到另一侧外沿。候选是"核心区 ±2 以外的行 / 列"。6×6 的棋盘核心区在中间，外侧只剩 1 行或 1 列，那就取外圈那一行 / 列本身。方向与候选由布局子流均匀抽取。

- 河流：直线上全部格设为深水，抽 1 格设为桥。
- 高台：直线外侧（远离核心区的一侧，含该直线）全部设为高 2，抽直线上 1 格设为高 1 的坡口；坡口与核心一侧相邻的格保持高 0。这样 h0 → h1 → h2 沿气边连通。
- 难到达格（公共信物）：河流取对岸一侧，高台取高 2 一侧，沿用现有定义。
- 备选：保留折弯河道。不选，因为横穿外圈后折弯会和接缝的几何互相影响，直线更容易保证"每条接缝至少 1 条气边"。

### D2 接缝气边保证（已被 J1–J2 取代）

> 修订：首次实施证明原 D2 不成立（见 proposal「实施修订」）。现行做法：隔断线不取外圈行 / 列，两端只占外圈各 1 格；生成器生成地形时布局已知，若某块的隔断线使某条接缝缺气边，按棋盘级自检失败处理，在同一流上重抽该块。种子 1–20 穷举与 1–2000 抽查必须零失败。

隔断线走到外圈后，可能正好落在某条接缝上，比如河道沿着整条共享边，让该接缝没有气边。生成时规避：隔断线 MUST NOT 与任何一条共享边完全重合。建局时还不知道邻居，因为布局在主题生成之后才拼，所以规避条件取"隔断线平行于棋盘边时，不占用外圈那一行 / 列的全部格"。6×6 只能用外圈那一行时，桥或坡口就是那一行上的通道；如果这样仍让某条接缝缺气边，布局后的校验会抛 `MapGenerationException`。必须用种子 1–20 穷举和 1–2000 抽查证明从不触发。触发了就回主会话，改为"隔断线只取中间带内的行 / 列，端点外圈格设为深水 / 崖但保留一侧通道"。

### D3 湖泊 / 岩区（J4：中间带 ≤ 12 格的棋盘不放）

在隔断线和主题地形之后，在中间带剩余的空草地里放 1 团 3–5 格（种子决定"深水 / 岩石"与形状：从一格出发四邻生长）。放完立即做棋盘级自检（可落子格几何四邻连通、匠人改造目标 ≥ 2），不过就在同一流上重抽该块，沿用现有 ≤ 16 次的机制。

### D4 随机消费与确定性

布局子流的消费顺序变为：次序 → 宽高 → 主题排列 → 逐块（主题地形含隔断线 → 湖泊 / 岩区）→ 出生区信物 → 公共信物。新地表子流不变。所有 `link:` 地图都会变，按 M10 的先例接受。

### D5 校验器

- 外圈规则：河流 / 高台主题，允许隔断线经过的外圈格为深水 / 桥 / 高 1 / 高 2；
- 新增 `BOARD_BARRIER_INVALID`：棋盘内若有横穿棋盘的隔断线，须恰 1 处通道（河道恰 1 桥、山脊恰 1 坡口），两侧除通道外无气边；不要求一定有（J5）；
- 可落子格与画布区间按种子 1–20 穷举回写。

### D6 与其他 change 的接口

- `fence-eye-rule`：崖壁与深水仍是墙。隔断线附近更容易形成贴墙眼，冒烟时观察活形数。
- `link-map-surfaces`：候选格变少，按现有规则少放；浅滩候选"沿河岸"会变多。

## Risks / Trade-offs

- [河流 / 高台主题的棋盘被切成两半，核心一侧太挤] → 隔断线不得进入核心区 ±2；冒烟看这两个主题的名次。
- [隔断线让接缝缺气边] → D2 规避 + 穷举证明。
- [可落子格降得太多，对局太短或开局太挤] → 区间目标 180–230，冒烟大回合中位低于 18 时回负责人。
- [画面：外圈出现深水 / 崖壁] → 只要求 headless 自检通过，截图人工看，缺陷登记给 Godot。
