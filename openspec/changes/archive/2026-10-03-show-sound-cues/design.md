## Context

`ShowTimeline.Advance(deltaMs, fast)` 返回本次推进跨过的节拍；`ShowMask` 给出每名玩家的势力段（领地 / 军势 / 定格）与段内进度、活跃飘字。Godot 每帧调用一次。仓库无音频代码。

## Goals / Non-Goals

**Goals**：每个视觉节拍都有对应的声音，零资源即可运行，无人值守零影响。**Non-Goals**：见 proposal。

## Decisions

### D1 提示导出是纯函数，挂在时间线旁

`SoundCues.Between(maskBefore, maskAfter, crossedBeats)`：比较推进前后的遮罩与跨过的节拍，输出有序提示列表：

| 提示 | 触发 |
|---|---|
| 落子 | 某枚棋子由"未落下"变为"已落下"（每枚一次；压缩落子时整批一次） |
| 提子 | 跨入提子节拍 |
| 信物 | 跨入信物揭示节拍 |
| 领地到账 | 某玩家势力段进入"领地" |
| 军势到账 | 某玩家势力段进入"军势" |
| 横幅 | 跨入横幅节拍的每一条 |

同一帧内同种提示合并为一个（多名玩家同时到账只响一声）；提示带整数序号用于稳定排序。无浮点。

### D2 波形在启动时合成，不引入文件

Godot 启动时按固定参数合成六段 16-bit 单声道 PCM（44.1 kHz，时长 60–400 ms）写进 `AudioStreamWav`：

| 提示 | 波形 | 频率 | 时长 |
|---|---|---|---|
| 落子 | 三角波 + 快速衰减 | 880 Hz | 60 ms |
| 提子 | 噪声 + 衰减 | — | 120 ms |
| 信物 | 正弦双音 | 1320 → 1760 Hz | 180 ms |
| 领地到账 | 正弦 + 中等衰减 | 440 Hz | 200 ms |
| 军势到账 | 正弦 + 慢衰减 | 330 Hz，音量更大 | 250 ms |
| 横幅 | 正弦 | 220 Hz | 400 ms |

参数放在 Godot 侧一张表里，便于后期替换为文件资源时整表换掉。合成用固定种子的确定性噪声。

### D3 播放规则

- 一个 `AudioStreamPlayer` 池（4 个），提示按序号依次占用空闲播放器；同帧多于池容量时丢弃多余。
- 提速（按住空格 / 左键）时音量 −9 dB。
- `--mute` 或无人值守（零时长模式）：不创建播放器、不合成波形。

### D4 不写入测试的部分

波形合成与播放只做"不崩、`--mute` 与无人值守下无音频节点"的自检；提示导出的纯函数有单元测试。

## Risks / Trade-offs

- 占位音简陋 → 明确是占位，表里可整体替换。
- 高频落子音连续 4 枚会密集 → 落子节拍本身每枚间隔 ≥ 250 ms（超过 4 枚压缩时更密），可接受。

## Migration Plan

纯新增；回滚 = 不创建音效节点。
