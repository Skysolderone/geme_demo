## Context

停手阈值在 `BatchEvaluator` / `HeuristicTurnController` 的保留判定处生效（`next − current > PassThreshold`）。简单难度只算即时势力、敌损、眼位三维，空盘上单子收益低于 80，全员 Pass 后三类终局之"整轮 Pass"立即成立。

## Decisions

### D1 阈值豁免在决策入口一次算定

决策开始时读正式盘面判断"该玩家是否有棋子"，得出本次决策的实际阈值（0 或配置值），整个决策（单点排序与贪心组批）共用，不在组批过程中重算。备选"按难度拆阈值"推翻 `ai-eye` R1、需要再扫档，不采用；备选"保护期内阈值为 0"会让标准难度在前三大回合多落低价值子，影响面更大，不采用。

### D2 日志与回放

日志首部仍记录配置阈值；豁免是确定性函数（由盘面推出），回放按同一实现重建，不需要新字段。

## Risks / Trade-offs

- [出局边缘玩家被全灭后又能低价值落子] 盘上无子但尚未出局的玩家（例如只剩领地分）会以阈值 0 行动 → 属预期：无子时优先重新落脚。
- [标准难度走法变化] 开局首批通常已有高收益，影响应很小 → 探针归因。
