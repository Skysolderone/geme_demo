## Context

`LinkMapGenerator.Layout` 只消费 `MapRandom.ForLinkLayout(seed)` 一条流，顺序固定：次序 → 宽高 → 主题排列 → 按编号逐块地形（`DraftBoard`，自检失败在同一条流上重抽）→ 出生区信物 → 公共信物；最后过一遍链接档静态校验。`MapValidator.ValidateBirthBoardTerrain` 对出生棋盘报 `BOARD_SPECIAL_SURFACE`（棋盘内任何新地表即失败）。四种地表的规则与 AI 感知都经唯一查询（`terrain`、`coverage-territory`、`life-shape`、`ai-decision`「AI 对地表的感知」），Godot `TerrainParts` 已有 Desert / Marsh / Crag / Shallows 四类点缀部件。

## Goals / Non-Goals

**Goals**：按主题在中间带投放新地表；现有地形逐格不变（E4）；校验器放开中间带、守住核心区与外圈；可复现、可核对。

**Non-Goals**：不改地表语义、AI、匠人改造规则；不补偿平衡；不改布局与主题集。

## Decisions

### D1 独立子流叠加（E4）

- 新增 `MapRandom.ForLinkSurfaces(ulong mapSeed)`：由地图种子派生、与 `ForLinkLayout` 互不扰动的子流（域常量不同）。
- `Layout` 在公共信物之后、组装 `TerrainData` 之前调用 `OverlaySurfaces(plates, boards, relics, rng2)`：按出生棋盘编号 0–4 逐块处理，只改该块 `Surfaces` 字典里若干格的取值。现有流的消费顺序与次数不变，因此高度、林地、深水、桥、栅栏、岩石、信物格位置逐格不变。
- 叠加后仍过一遍链接档静态校验，不通过即生成器缺陷（抛 `MapGenerationException`）；叠加不做重抽（候选不足时少放，见 D3）。

### D2 候选格（E3）

基础候选 = 该块中间带里：高度 0、地表草地、非岩石、非信物格、不在核心区四邻（与核心区任一格几何相邻的格排除，保证起手条件不因地表而不对等；实施裁决 S1）。**中间带格数 ≤ 12 的小棋盘免除 S1**（负责人 2026-10-20 裁决 F1：S1 下 6×6 的中间带几乎全挨核心区，100 块里 28 块不足 2 格；免除后种子 1–2000 不足 2 格降到约 5%）。各主题再取子集与地表（E1）：

| 主题 | 地表 | 主题候选（基础候选之内） |
|---|---|---|
| 河流 | 浅滩 | 与未架桥深水格或桥格几何相邻 |
| 高台 | 岩台 | 与高度 ≥ 1 的格几何相邻（台边） |
| 林地 | 沼泽 | 与林地格几何相邻 |
| 栅栏阵 | 荒漠 | 至少一条边有栅栏，或与这样的格几何相邻（口袋附近） |
| 混合 | 四种各至多 1 格 | 每种按上表各自的条件在本块里找；找不到该种时从基础候选补该种（裁决 F2），仍每种至多 1 格 |

主题候选不足时退到基础候选补足（同一地表种类）；基础候选也不足时少放（实施裁决 S2）。

### D3 数量（E2）

- 目标格数：中间带格数 ≤ 12（6×6 为 7、6×7 为 11）取 2，否则在 2–3 里均匀抽（按 `ForLinkSurfaces` 子流；7×7 中间带 16、8×8 为 27）；混合主题 2–4（四种按固定次序 浅滩 → 岩台 → 沼泽 → 荒漠 依次尝试，各至多 1 格，凑满目标格数为止）。
- 抽格：候选按坐标字典序排好后用子流抽取，不放回；同一地表的格之间不要求相邻或不相邻。
- 记录：每块实际放下的格数写进 `BoardTerrain`（供测试与 `map` 文本输出）；种子 1–20 每块 MUST ≥ 2（测试守），1–2000 统计分布写入任务目录。

### D4 校验器（E5）

- `BOARD_SPECIAL_SURFACE` 改为：新地表格 MUST 在中间带（不在外圈、不在核心区）；每块新地表格数 MUST ≤ 4（链接行声明 `MaxSpecialSurfaces = 4`）。外圈"只许草地或林地"、核心区"9 格高度 0 草地"两条原样保留（它们已蕴含"不进外圈 / 核心区"，新条目给出更精确的失败信息）。
- 不检查"核心区四邻不放新地表"（那是生成器口径 S1，不是地图合法性要求）。

### D5 地图导出与快照（E7）

- `link:1`–`link:20` 初始图导出：与改前逐格对照，差异 MUST 只出现在 `Surfaces` 字段且只在中间带的新地表格上；对照脚本输出存任务目录。
- 地图内容摘要随之改变，旧日志回放会在首部报"地图不一致"（既有机制），不另做兼容。

### D6 基线与黄金值（E7）

- 5 份 `decisions-link1-*` 决策序列基线、`LinkGoldenTurnHash`、G1 黄金值、平衡分析报告哈希等依赖 `link:1` 走法的期望重钉；每份记录"首个分歧小回合 + 分歧落点是否在新地表格或其四邻"，以说明分歧由地表引起。
- `link:90008` 等手写载体（不经生成器）MUST 零改动。

### D7 Godot

- 不改代码；截图 1 张（`art/link-map-surfaces/`，锁定后整图，四种点缀可见），README 记命令与人工检查项（新地表灰度可辨、图例只列出现过的地表）。四条 headless 自检退出 0。

## 接口契约

| 接口 | 输入 | 输出 | 触发时机 |
|---|---|---|---|
| `MapRandom.ForLinkSurfaces` | 地图种子 | 子流 | 生成 |
| `LinkMapGenerator.OverlaySurfaces` | 棋盘清单、各块地形、信物格、子流 | 改写后的各块地表 | `Layout` 公共信物之后 |
| 校验器链接行 | 地图数据 | `BOARD_SPECIAL_SURFACE` 新口径 | 生成后、加载时 |

## 实施裁决（缺省）

| # | 事项 | 缺省 |
|---|---|---|
| S1 | 核心区四邻 | 不放新地表（生成器口径，校验器不查）；中间带 ≤ 12 格的小棋盘免除（F1） |
| S2 | 候选不足 | 主题候选不足退基础候选；仍不足少放，不重抽 |
| S3 | 6×6 棋盘目标格数 | 固定 2 |
| S4 | 混合主题尝试次序 | 浅滩 → 岩台 → 沼泽 → 荒漠 |
| S5 | `map` 文本图 | 新地表沿用现有字符（若已有），否则补图例 |

## 实施后裁决（负责人 2026-10-20，F1–F5 全按推荐）

## 已知歧义与风险

- 浅滩空着不算气：放在河岸会让沿河棋串更脆，河流主题可能变弱——E6 不预先补偿，冒烟看主题名次。
- 荒漠独占不计分：栅栏阵口袋的价值下降。
- 岩台多覆盖远一格：高台主题变强。
- 6×6 棋盘中间带很小，基础候选可能不足 2 格（S2 少放）；种子 1–20 测试守 ≥ 2，1–2000 统计记录。
