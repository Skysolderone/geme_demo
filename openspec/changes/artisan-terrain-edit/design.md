## Context

去围棋化改造三轮中的第三轮，也是最后一轮（总体计划见 `openspec/changes/archive/2026-09-17-terrain-model/design.md` 的 Context 与裁决记录 17–23）。

第一轮让地形进入规则（高度、地表、桥、栅栏；气边与覆盖两套关系），第二轮把分数搬到 12 个据点上。地形至今只读：一局里没有任何一手能改变通路、覆盖或高差。本轮加入第六种棋子「匠人」与三种改造，让玩家能改写地形。

第二轮定案后的基线（`sim-out/sites-final/`，200 局，Safety 27、分值 5/15/45）：

| 指标 | 实测 | 与本轮的关系 |
|---|---|---|
| 石碑争议小回合占比 | 52.4% | 对峙居多；改造给相持中的一方一条出路 |
| 每批次平均提子 | 0.29（第一轮 0.40） | 立栅能直接断气提子，可能把这个数拉回来 |
| 终局据点分占比 | 22.1%（目标 25–45%） | 改造若让据点更易拿下，占比可能回升 |
| 篝火由主人控制占被控制 | 10.6% | 主人可在自家崖边立栅封住邻家下山路 |

这四项本轮只观察、不调参（裁决 T-9）。

## Goals / Non-Goals

**Goals:**
- 匠人进入棋池与手牌体系，基础军势 1、征募权重 10（可配置）。
- 三种改造（搭桥 / 立栅 / 烧林）落地，落子即改造、占 1 额度、目标几何四邻、可选。
- 改造在批次结算里先于提子生效；自杀手与同形禁则都按改造后的地形判定。
- 设施写入后地形实时重算（气边、覆盖、棋串、气、据点与信物控制）。
- 预演、公开视图、战术层、Godot、日志与分析全链路带上改造。
- 匠人权重三档扫档 + Safety 复查，出对比表由负责人拍板。

**Non-Goals:**
- 逆向改造、改高度、改据点与信物。
- 地图调整（加林地 / 改河宽）、新 AI 维度、保护期与终局条件。
- 第二轮遗留三项的修复。

## Decisions

**D-A：匠人是一枚普通棋子，能力只在落子瞬间（裁决 T-1、D14、D16）。**
基础军势 1、权重 10（与协同子同档），改造不占额外额度、不新增阶段。备选"军势 0 的纯工具子"否决：会让"落匠人"在势力上永远是亏的，AI 与玩家都不会用；备选"权重 18"留作扫档对照档。改造后匠人就是普通子，被提走不撤销设施——设施与棋子彻底解耦，规则里不需要"谁的桥"。

**D-B：目标口径是几何四邻（裁决 T-2）。**
气边口径会让搭桥根本不可能（深水没有气边），还要为它写例外。几何四邻是 `Adjacency.Neighbors` 已有的唯一实现，玩家只需看四个方向。边目标即匠人格与某个四邻格之间的 `FenceEdge`。匠人不能烧自己脚下那格（四邻不含自身）——落点选择因此有意义：要烧哪片林，先站到它旁边。

**D-B′：边目标放宽到匠人四邻格的外圈边（裁决 T-11，段 B 实测后追加）。**
段 B 实现后证明：若栅栏只能立在匠人格与其四邻之间，则**任何改造都不可能直接提子**——那条边必有一端是匠人自己刚落的棋子，既不是敌串的气，也切不断敌串内部的连接（20 局 97 次改造实测致提子 0 次）。这使 D-C / T-3 的全部理由落空。放宽为"边的至少一端是匠人落点的几何四邻格"：候选边由 4 条增至 16 条（含原来的 4 条），立栅可以堵掉敌串的气、可以切断敌串，T-3 恢复成立。格目标（搭桥、烧林）仍是几何四邻，口径不变。

**D-C：改造先于提子生效（裁决 T-3）。**
预演顺序插入第 4 步"应用改造"，正式结算插入第 3 步。立栅因此是真正的战术武器：可以敲掉敌串最后一口气。对称地，堵死自己就是自杀手、整批被拒。备选"下一批次才生效"否决：改造会变成纯粹的慢速卡位，且"这一手到底改了什么"要跨回合解释；备选"禁止在敌串最后一口气上立栅"否决：多一条例外，且玩家必须心算对手的气。

**D-D：批次内不链式（第一轮默认 2）。**
全部合法性按批次开始前的地形判定：本批架的桥不能当落点、不能作为下一次改造的跳板，同一目标不能被改两次。理由是预演要可解释、结果不依赖批内顺序；宽河因此需要多个回合逐格架（裁决 T-4 允许任意相邻深水格），架桥本身成为一项投资。

**D-E：同形禁则纳入设施（第一轮默认 4）。**
盘面表示加桥集合、栅栏集合与地表。改造不可逆，状态空间单向扩张，不会因此振荡；同时避免"棋子回到老位置但地形已变"被误判为同形。

**D-F：保护期内允许改造（裁决 T-5）。**
匠人只能落在自家出生区，目标天然限于区内与区边，主要用法是在自家崖边立栅封住邻家下山路，或在区边搭桥。不为保护期写例外。风险：四家开局都把自己封成铁桶——扫档看首次冲突大回合与整局无提子局。

**D-G：改造可选（裁决 T-6）。**
匠人没有合法目标时仍可落子，手牌不会因为抽到匠人而卡死；也允许先占位、之后再用别的匠人动地形。

**D-H：地图不动（裁决 T-7）。**
v4 地形与 Id 不变。全图 4 格林地、4 段栅栏、32 格深水（4 格已架桥）。烧林目标最少，扫档看三种动作的使用次数；若烧林接近 0 次，再单开一轮加林地（会作废本轮基线）。

**D-I：扫档为匠人权重三档 + Safety 复查（裁决 T-8）。**
1. 匠人权重 5 / 10 / 18，其余配置为第二轮定案值（分值 5/15/45、Safety 27），各 200 局（种子 1–200）。
2. 在推荐档下复查 Safety 25 / 27 / 30，各 200 局，确认 27 仍是推荐值。
3. 对比表列：改造分析第 11 项全部指标、第 3 大回合领先者胜率、每批次提子、首次冲突、终局原因分布与不收敛率、终局局平均结束大回合、整局无提子局、据点三档控制率与争议率、终局据点分占比、六种棋子选择率与胜率。
4. 负责人拍板后落默认权重，确认跑 200 局。
约 6 批 × 2 分钟。`strict-cli` 在本轮第一段先做（裁决 T-10），扫档的口径由它把关，不再靠人工核对 config.json。

**D-J：AI 如何看待改造（常规，主会话定）。**
不新增评估维度。匠人的候选改造目标作为批次枚举的一部分进入现有评分（`PowerGain` 等维度自然反映"提子""通路""覆盖变化"）。为控制搜索规模，AI SHALL 对每枚暂放匠人枚举其全部合法目标加"不改造"，与落点组合；若实测单步耗时显著上升，则限制为"只枚举能直接导致提子的改造 + 不改造"，并把该取舍记入实现记录。

## 接口契约

**输入**：批次条目（落点、类型、可选的改造目标）、当前地形、对局配置（匠人权重）。

| 输出 | 变化 | 消费者 |
|---|---|---|
| `PieceType` | 新增 `Artisan` | 征募、手牌、军势、徽记、视图 |
| `RecruitWeights` | 基础权重加匠人 10，可由对局配置覆盖 | 征募、跑局配置、日志 |
| 地形写入口（新，唯一实现） | 在 `TerrainData` / `MapData` 之上提供"加桥 / 加栅 / 烧林"的不可逆写入，产出新的地形快照 | 结算、预演 |
| 改造合法性（新，唯一实现） | 目标类型、相邻、未被改造过、批内唯一；按批次开始前地形判定 | 预演、结算、AI、界面 |
| 批次条目 | 可带一个改造目标 | 预演、结算、日志、存档 |
| 预演 / 结算顺序 | 放置后、提子前应用改造 | 全部规则 |
| 盘面同形表示 | 加设施与地表 | 同形禁则、存档 |
| `GameBoard` | 地形不再是不变量：改造后气边、覆盖、棋串、气、据点与信物控制全部按新地形重算 | 全部消费者 |
| 日志 | 改造事件；配置记录匠人权重 | 分析 |
| 分析 | 第 11 项改造分析 | 扫档决策 |
| `Siege.Presentation` | 公开视图含设施与可改造目标；预演显示改造 | Godot |
| Godot | 匠人轮廓、改造落成反馈、可改造目标高亮 | 玩家 |

## Risks / Trade-offs

- **[保护期内四家把自己封成铁桶，冲突更晚]** → 看首次冲突大回合与整局无提子局；报警线：首次冲突晚于第 5 大回合或整局无提子 > 5%。
- **[立栅致提子过强，变成"栅栏杀"主导]** → 看改造致提子次数占提子总数的比例与每批次提子；若立栅占改造的绝大多数且提子暴涨，考虑下一轮限制（本轮不改规则）。
- **[烧林几乎无人使用（全图仅 4 格林地）]** → 分析如实给出 0 次；D-H 已写明后续处理。
- **[AI 枚举改造目标使单步耗时暴涨]** → D-J 的退路；扫档记录每局 AI 计算耗时，与第二轮的 19.2 秒/局对照。
- **[地形可变打破既有"地形不变"假设]** → 全仓搜索缓存地形派生数据（气边表、覆盖表、距离表）的位置，逐处确认改造后失效或重算；实现记录逐条列出。
- **[同形表示变更使旧存档不可读]** → 旧存档按"无改造"回填，写往返测试。
- **[匠人挤占类型槽（默认 5 槽、六种类型）]** → 属于设计意图（取舍），扫档看六种棋子的选择率与弃牌频次。

**主会话定的常规项（审 change 时可推翻）**：
- R-1 流派徽记可绑定匠人（徽记类型在全部棋子类型中等概率抽取，现有实现即枚举全部类型）；这会改变既有种子的信物生成结果，第二轮基线因此作废，本轮跑出的数据不与第二轮逐项对照，只对照结构性指标。
- R-2 匠人权重为对局配置（同据点分值），默认 10，写入批次配置记录。
- R-3 改造不记录改造者：日志记录改造方用于分析，公开视图与盘面 MUST NOT 显示。
- R-4 烧林只改地表，不改高度、障碍、信物与据点。
- R-5 已架桥的深水格、已有栅栏的边、已是草地的格都不是合法目标（"没有逆向动作"的自然推论）。
- R-6 旧存档与旧日志按"无改造"回填；缺改造字段的旧日志在分析时整局排除并计数。
- R-7 预演中匠人的可改造目标属于公开信息（对手也能推出来），不做隐藏。
