## Why

负责人 2026-10-05 反馈：**游戏数值的呈现要更强烈，并且产生层级递增**。现状是三处数值呈现都没有层级——落子飘字固定字号与颜色（算出 4 和算出 100 长得一样），势力栏到账一律放大 1.3 倍（+1 和 +50 弹得一样），棋串军势常驻标注固定字号。对应设计文档 §14.4（对手行动的镜头与数值）与 §20（表现层）。

同日实测（`siege-4p-base-v5`、4 名标准 AI、种子 1–10，共 485 条落子飘字）：飘字结果值中位 4、90 分位 13、最大 106；带倍率的落子只占 24%；终局总势力中位 56。数字本身偏小，所以档位阈值必须贴着实际分布定。

## What Changes

负责人 2026-10-05 的五项裁决：先呈现后数值（本次规则与数值不动）；按数值大小分档；五档、阈值 4 / 8 / 16 / 32；手段取全套（字形分档、高档冲击环、算式逐步揭示、最高档镜头轻震）；揭示逐串依次、每步 0.22 秒、整拍上限 1.6 秒。

- **数值档位**：一张五档表（<4、4–7、8–15、16–31、≥32），三处呈现共用。阈值是初值，数值规则调整后重定。
- **军势揭示节拍（新增）**：排在信物揭示之后、势力重算之前。对结算后含本次落子的每条棋串，按军势从小到大依次揭示算式：`5` → `+2` → `×1.5` → `= 10`，只列非零项，一步比一步高一档，末步取该串的数值档；四、五档的末步多定格一会儿。
- **BREAKING（行为）**：落子飘字只剩棋子类型名，算式移到军势揭示节拍（同一条算式不再随同串的每枚落子重复出现）。
- **五档字形**：揭示的字号、颜色、描边、弹出幅度、结果停留时长逐档递增；四档格上一圈亮环、五档两圈；五档末步镜头轻震。
- **势力栏到账**：段首放大幅度按本段增量的档位取 1.3 / 1.45 / 1.6 / 1.8 / 2.0 倍。
- **棋串军势常驻标注**：字号按军势的档位逐档加大，仍用阵营色。
- **音效**：揭示每步一声；揭示与领地、军势到账的音高按档位升高。
- 每回合演出平均时长由约 1.45 秒变为约 2.2 秒（实测估算）；按住提速照常可用。无人值守（零时长）下以上全部不出现，既有定帧基线不变。

## Capabilities

### New Capabilities
无。

### Modified Capabilities
- `settlement-show`：修改「结算节拍序列的生成」「落子与提子节拍的内容」「势力重算节拍与数值变化显示」「演出音效提示」「飘字的停留时长」；新增「数值档位」「军势揭示节拍」「高档冲击环与镜头轻震」。
- `tactical-layers`：修改「棋串军势常驻标注」（字号按档）。
- `visual-style-baseline`：修改「UI 风格约束」（允许数值的分档强调、亮环与轻震，仍禁粒子）。
- `viewport-camera`：修改「回到出生平台」（"相机不得自动移动"的例外加上镜头轻震）。

## Impact

- `Siege.Presentation`：新增数值档位与分档样式表、军势揭示节拍的生成；`SettlementBeats` / `ShowTimeline`（遮罩加揭示、亮环、轻震）/ `SoundCues`（提示带档位）/ `GroupPowerLabels`（带档位）改动。
- Godot：`BoardView`（画揭示、亮环、分档标注）、`Hud`（势力栏分档弹跳）、`ShowSounds`（揭示音、按档升调）、`GameRoot`（轻震、截图入口）。
- `Siege.Core` / `Siege.Sim` 不改；规则、计分、AI、日志、存档不变；终端版不变。
- 验证：新增与修改的规格场景各有测试（纯逻辑在 Presentation），新守门做变异验证；Godot 侧出五档截图；无人值守帧序列与拾取自检不变；不跑批量对局。

## Non-goals

- 不改军势公式、倍率与任何数值规则——推迟到负责人试玩本 change 之后另开的数值 change；届时档位阈值随之重定。
- 不做粒子特效、不做震屏开关、不改终端版呈现、不改落子 / 提子 / 势力 / 横幅节拍的时长。

## 前置 change

- `settlement-show-callouts`（飘字、分段到账）、`show-sound-cues`（音效提示）、`follow-opponent`（飘字 1.4 秒、常驻标注），均已归档。
