## Why

`board-link-mode` 的拼接版冒烟（10 局）中，战场结算全部由"整轮 Pass"触发，28 名战场落败者在结算那一大回合都是手中仍有棋子时主动 Pass（上界口径）；`C15`（落后者停手阈值取 0）在同种子对比上零效果，说明多数落败者当时没有正收益的落点——但这个上界混着"错过了翻盘手"与"像围棋收官一样确无有用手"两种情况，不能直接改。另有登记的"等待者失衡"（单人战场等待者无对手、势力只增不减）需用数据判断是否影响决赛公平。

本 change 先诊断、后裁决：第一段只加诊断，不改任何行为；第二段按诊断结果由负责人在候选修法中裁决。对应设计文档 v1.21 §12、§15、§19。

## 负责人裁决（2026-10-13）

| # | 事项 | 裁决 |
|---|---|---|
| 排序 | 与 `10-13-link-map-terrain` 的先后 | 负责人明确要求先开本 change（原排序 A 改为先做 AI 停手复核）；地形主题化那条线在本 change 完成前不开工 |
| P1 | 分段 | 第一段只加诊断不改行为；第二段按诊断结果裁决修法 |
| P2 | "本可翻盘"口径 | 对每个战场落败者在结算那一大回合的最后一次 Pass 复盘：当时最好的一手（按该 AI 自身的候选与评价取最高者）落下后、对手不回应时，己方势力能否追平或反超本战场最高者；同时记下最好一手的评价收益、能否提子、合法候选数 |
| P3 | 等待者评估指标 | 决赛中"等待者"（首轮未配对或同区提前结算后等待的胜者）与"首轮刚结算的胜者"各自的决赛胜率、决赛开始时的势力差、等待大回合数 |
| P4 | 诊断规模 | `link:1` 标准难度 20 局，种子 1–20，配对缺省种子派生 |
| P5 | 第二段候选修法（诊断后再裁） | A 落后且存在翻盘手时 AI 不得 Pass；B 规则改为战场需连续两整轮全员 Pass 才结算；C 延长构筑期；D 维持现状 |
| P6 | 范围 | 第一段只动 Core 的 AI 诊断与分析、Sim 的 `analyze`；不碰图形版 |

## What Changes

- 第一段（诊断）：
  - Core 新增"战场落败复盘"纯函数：给定落败者结算那一大回合 Pass 时的局面，按其 AI 配置重算候选与评价，输出 P2 各项；不改任何决策。
  - Sim `analyze` 链接模式段新增"战场落败复盘"与"等待者决赛表现"两段报告。
  - 跑 P4 规模的诊断批次，只报告。
- 第二段（修法）：待第一段数据出来后由负责人从 P5 裁决，另行补规格增量与任务。
