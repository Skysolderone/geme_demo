## Context

链接模式下战场结算由"本战场全员在同一大回合 Pass / 填满 / 减员"触发。AI 的停手由停手阈值决定（缺省 20，己方无子或 Link 下落后时取 0，C15）。冒烟中落败者全部在结算那一大回合主动 Pass，`C15` 零效果，原因未明。

## Goals / Non-Goals

**Goals**：用数据区分"错过翻盘手"与"确无有用手"；判断等待者是否在决赛中占优。**Non-Goals**：见 proposal。

## Decisions

### D1 复盘复用 AI 自身的候选与评价

对落败者在结算那一大回合 Pass 的时刻，取当时的公开快照与其手牌，调用与正式决策同一条候选生成 + 预演 + 评价路径，取评价最高的批次；再在预演结果上重算势力，判断能否追平或反超本战场最高者（对手不回应）。不新建第二套评价，不消费对局随机子流（用独立的诊断子流或纯确定性路径，确保对局逐字节不变）。

### D2 记录点

Sim 在跑局时记录"结算那一大回合每名落败者 Pass 时的局面"所需的最小信息（或在分析时按日志回放到该时刻），择一以不改日志现有字段、不改黄金哈希为准；优先"分析时回放"，日志无需新增字段。

### D3 等待者识别

等待者 = 进入决赛时，其所在战场在首轮配对时为单人等待、或在构筑期 / 首轮提前结算后无对手的胜者；与"首轮刚结算的胜者"对比决赛胜率、决赛开始势力差、等待大回合数。

## Risks / Trade-offs

- [复盘结果依赖对手不回应的假设，偏乐观] → 报告里注明口径；第二段若选 A，再评估。
- [20 局样本小] → 只作方向判断；比例与区间一并报告。
