## 3. 盘面同形禁则

- [ ] 3.1 实现已提交盘面集合：内容哈希 + 提交序号 + 完整内容，哈希命中后必须按内容再比对一次。验证：构造哈希碰撞桩，断言不误判。
- [ ] 3.2 实现同形判定与失败信息（返回重复的历史提交序号）。算例（设计文档 §6.2）：结算后盘面与第 12 次提交相同 → 拒绝并返回序号 12。
- [ ] 3.3 断言比对内容只含每格占用者与棋子类型。算例：占用者全同但某格普通子→堡垒子 → 不同形；逐格全同但手牌与信物控制不同 → 仍同形。

- [ ] 3.5 实现已提交盘面集合的持久化与恢复。验证：第 20 次提交后存档恢复，再提交会重现第 12 次盘面的批次 → 仍被拒绝并报序号 12。

- [ ] 4.2 定义第 4/5/6 步的下游驱动接口（信物、势力、流程各一个回调点），本层不实现其内部计算。验证：用桩实现断言三个回调各被调用一次且顺序正确。
- [ ] 4.3 实现结算原子性。算例（设计文档 §6.3）：批次提走唯一覆盖某未知信物格的敌串，同时己方进入其覆盖范围 → 揭示与控制判定基于提子后的覆盖关系。
- [ ] 4.4 断言外部观察者无法看到中间态。验证：在每一步之间采样盘面对外快照，断言只存在结算前与结算后两种状态。
