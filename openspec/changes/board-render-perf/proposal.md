## Why

棋盘图上场景格（障碍）占全图一半以上，图形版给每个场景格各建一件装饰节点（巨石 / 松树 / 遗迹）与一块面砖。`board-map` 段 C 实测 `board:1` 单帧绘制调用 4243–5320 次、对象 12963–16247 个、截图帧帧率 4。另外结算演出期间棋子层每帧整层重建（`RefreshShow`），大图后期有 400 多枚棋子。两项叠加会让棋盘图明显卡顿。

对应设计文档 §20（界面）。只涉及渲染实现，画面与规则不变。

## What Changes

- 先测量：窗口模式下 `board:1` 开局静止帧与演出进行中两种情形的帧率、单帧处理耗时、绘制调用数、对象数，作为基线。
- **场景装饰合批**：同一种装饰变体用实例化绘制（一种网格一次绘制调用带多实例），场景面砖同理；绘制调用数不再随场景格数线性增长。
- **演出期间增量重画**：只更新遮罩里变化的棋子（正在出现 / 正在淡出的那几枚），不整层重建。
- 画面 MUST 不变：既有地图与棋盘图的定帧截图在水面动画区域之外逐像素相同。
