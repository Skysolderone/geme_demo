## Why

负责人 2026-10-09 裁决整体游戏模式：四名玩家各盲选一块出生棋盘（可重叠），各自在隔绝的棋盘上构筑；三个大回合后，尚未与人交战的玩家被随机配对，两块棋盘之间长出公共棋盘连通，开始战斗；两对都分出胜负后两名胜者再链接打决赛。棋盘随对局"展开"，而不是开局就全图铺好。现行所有地图（标准图、2 / 3 人图、随机图、棋盘图）都是开局全图可见、静态不变的，与该模式不兼容；负责人裁决**整个游戏只保留这一个模式**。

对应设计文档 §3（棋盘与地图）、§4（开局与前三大回合）、§12（出局与终局）、§13（信息公开规则）、§19（后续扩展顺序）。

## What Changes

- 新增对局结构 **战场**（battlefield）：对局由若干彼此隔绝的战场组成；每个战场是一组相连的棋盘（含通道）。开局 5 块出生棋盘各自成为一个战场，玩家所在战场由插旗决定。棋串、气、覆盖、领地、活形、禁手全部在战场内部计算，战场之间没有任何邻接。
- 新增 **链接**（link）事件：把两个战场合并为一个——在两块棋盘之间生成一块公共棋盘与两条通道，地图数据因此在对局中**增长**。链接是对局事件，写入对局日志与存档。
- 新增 **战场结算**：战场内全部参赛玩家在一个大回合内连续各 Pass 一次、或战场内无可落子空格，即该战场结算；势力最高者为该战场胜者，其余玩家**出局**（出局原因"战场落败"，势力可以大于 0）；并列按现行名次并列判定链。
- 新增 **阶段推进**：
  1. **构筑期**：第 1–3 大回合，各玩家只能在自己战场落子（替代现行"出生区内"）。
  2. **首轮配对**：第 3 大回合结束时，锁定时旗数恰为 1 的出生棋盘两两随机配对并链接；多人同区的棋盘不参与配对（即使已提前打完只剩胜者），就地开打或等待。候选为奇数（3 人同区 + 1 人独占，或有人提前弃赛）时，由配对事件指定一名等待者。
  3. **决赛**：全部多人战场都已结算且在局玩家 ≥ 2 时，把全部在局玩家的战场链接起来（4 人全在一块时只剩 1 名，对局直接结束）。战场结算在第 1–3 大回合同样生效。
  4. **终局**：只剩一个战场且该战场结算完毕，或只剩一名参赛玩家。
- **BREAKING** 全局终局条件改为按战场作用：现行"整轮 Pass""棋盘填满"不再直接结束对局，而是触发所在战场的结算；"只剩一名参赛玩家"保留。
- **BREAKING** 插旗改为**盲选**：玩家只能看到 5 个出生棋盘的占位与自己选中的那块的布局，看不到其他旗帜；现行"冒险概率 p"机制（依赖看见已插的旗）**废除**，AI 插旗改为在 5 个占位中均匀随机选一个。
- **BREAKING** 信息可见性按战场划分：链接之前，其他战场的地形、棋子、信物、势力明细对玩家不可见；该边界 SHALL 在数据层成立（公开视图按座位过滤）。AI 第一版仍按全知跑（见 Non-goals 与设计待裁项）。
- **BREAKING** 配对**不可复现**：配对结果由对局外部的随机源决定，作为对局事件记录；重放与存档恢复按记录结果重建，不再由对局种子推导。批量跑局中配对由 Sim 的随机源提供。
- **BREAKING** 地图入口收口：选图界面、命令行 `--map=`、批量与终端入口全部只接受新模式的地图标识 `link:<地图种子>`；标准图、2 / 3 人图、`gen:` 随机图、`board:` 棋盘图从玩家可达入口移除（作为 Core 测试夹具暂留，见 Non-goals）。
- 新增 **战场生成器**：由地图种子生成 5 块出生棋盘的布局（固定画布内的 5 个槽位）与链接时公共棋盘的布局（预留槽位）；链接时生成的公共棋盘由地图种子 + 链接序号决定，仅配对结果不可复现。坐标在整局中保持稳定。
- 图形版：选图界面改为"开始新局 / 输入地图种子"；插旗界面显示 5 个占位；对局中只渲染本机玩家所在战场；链接时播放"棋盘展开"演出节拍；出局横幅增加"战场落败"文案。

## Capabilities

### New Capabilities

- `battlefield`：战场的定义、战场内规则作用域、链接事件、战场结算、阶段推进与决赛。
- `link-map-generation`：新模式地图的生成（出生棋盘槽位、公共棋盘槽位、链接时生成）、标识 `link:<种子>` 与确定性。

### Modified Capabilities

- `match-setup`：「开局信息公开范围」改为只公开占位与自己的棋盘；「匿名同时插旗」改为盲选；「原型插旗替代路径」废除冒险概率、AI 均匀随机选占位；「对局配置公开完整地图标识」标识族改为 `link:`。
- `map-definition`：「地图为设计师固定的静态数据」改为"基础地图静态、链接时按确定性规则增长"；「地图规格档」只保留链接档；「人数适配预算」只保留 4 人；基准地图三条 Requirement 降级为测试夹具。
- `map-selection`：「开局选图界面」改为新局 / 种子输入，移除地图清单。
- `map-generation`：边疆档、棋盘档的生成 Requirement 保留为测试夹具约束（生成器与逐字节不变条款不动），只加注"不再由玩家入口可达"；新模式的生成另立 `link-map-generation`。
- `turn-sequence`：「构筑保护期的落子限制」「第 4 大回合的全图解禁」「合法落子范围的对外契约」改为以战场为范围。
- `elimination-endgame`：「出局判定」增加"战场落败"；「三类终局条件」改为战场结算 + 全局终局；「终局名次与并列判定」增加战场落败者的排名规则。
- `information-visibility`：「始终公开的信息」限定在同一战场内；新增"其他战场不可见"。
- `initiative-order`：行动顺序仍全局一轮，但等待中的胜者只能 Pass 或在自己战场落子；排名作用范围加说明。
- `simulation-harness`：「可复现回放」「随机子流隔离」加入配对事件记录；「各入口按地图标识选图」「各入口支持生成图」改为 `link:` 标识。
- `match-telemetry`：日志记录链接事件、战场结算、配对结果。
- `ai-decision`：「正式对战 AI 的信息边界」注明第一版全知的例外；候选格限定在自己战场。
- `viewport-camera`：「回到出生平台」「全局预览」「边界夹取」改为以当前战场为范围。
- `settlement-show`：新增"棋盘展开"与"战场结算"节拍。
- `carry-in-out`：「出局结算」区分"势力归零出局"与"战场落败出局"的结算（待裁）。
- `visual-style-baseline`：占位棋盘与未展开区域的可视表现。

## Impact

- **Core**：`Board/MapData`、`MapValidator`、`BoardPlate`（战场归属与增长）、`GameBoard`（邻接只在战场内）、新 `Match/Battlefield*`（战场、链接、结算、阶段）、`Match/FlagPlanting`、`PrototypeZoneAssignment`（盲选、废除 p）、`MatchFlow`（阶段推进与终局）、`MatchPublicView`（按座位过滤）、`MatchFlow.Persistence`（链接与配对事件）、`FinalStandings`、新生成器与 `MapCatalog`。
- **Sim**：`run` / `play` / `map` / `replay` 的地图选项与配对随机源；批量基线全部重建。
- **Presentation / Godot**：选图模型、插旗占位、按战场渲染、相机范围、展开演出、出局横幅。
- **测试**：依赖 v5 / 2p / 3p / gen / board 的黄金值测试与决策序列基线在本 change 内保留为夹具（地图仍可由 Core 内部加载），玩家入口不可达；新模式建立自己的决策序列基线。
- **验证**：单元测试；种子 1–20 的链接档生成校验；Godot `--auto-demo` 走完"插旗 → 构筑 → 链接 → 战场结算 → 决赛"；标准难度**至多 20 局**冒烟，只报告。不跑 200 局。

## Non-goals

- 不重新校准 AI 权重；AI 第一版按全知决策，只把候选格限定在自己战场。
- 不删除旧地图的 Core 数据与测试夹具（后续 change `retire-legacy-maps` 再删）。
- 不做 2 / 3 人局，不做联网。
- 不改棋子、信物、征募、计分公式。
- 不做链接时公共棋盘的多样地形（林地、新地表），公共棋盘沿用棋盘档的空白棋盘。
