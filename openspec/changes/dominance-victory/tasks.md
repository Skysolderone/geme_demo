- [ ] 1.2 在既有的"每次结算后 / 每次 Pass 后"检查点加碾压判定：某参赛玩家势力 ≥ 其余参赛玩家势力之和 → 终局，该玩家获胜。算例：A=210、B=80、C=70、D=55 → 210 ≥ 205，A 获胜；A=204 → 继续。验证：两条单元测试。
