## Context

战场结算现由大回合结束时的 `JudgeAtRoundEnd`（无副作用判定，S10）+ 执行两步完成，先手预测复用判定。等待决赛的玩家来源：首轮配对等待者、提前结算战场的胜者。

## Goals / Non-Goals

**Goals**：把等待时间压到 K 以内，消除决赛开局的大势力差。**Non-Goals**：见 proposal。

## Decisions

### D1 倒计时状态
`MatchFlow` 记录"倒计时起点大回合 R"（首次出现等待决赛的玩家时的大回合，未出现为空）。每个未结算多人战场的期限 = max(R + K, 进入战场时的大回合 + 1)。R 与各期限入存档、日志。

### D2 判定复用
到期作为 `JudgeAtRoundEnd` 的第三个触发条件 (c)，比较链与执行完全复用，只是原因记为 `Expired`；先手预测（S10）自动按同一判定，"假设此刻结束"时若本大回合是期限，预测剔除将到期落败者。

### D3 K = 0 不启用
K = 0 时 R 永不设定，判定路径与改前逐步相同；用 K = 0 的对照测试守住（链接图基线以 K = 0 跑应与改前逐字节相同）。

### D4 基线
链接图 5 条决策序列基线以缺省 K = 2 重钉，逐条说明哪一局哪个大回合发生了到期结算；另加一条 K = 0 的对照断言与改前基线逐字节相同。

## Risks / Trade-offs

- [强制结算可能打断仍在激烈交战的战场] → K 可调；验证批次报告到期结算时的势力差分布。
- [对局变短] → 报告对局长度变化。

## Migration Plan

旧存档缺字段按 K = 0；回滚 = 还原文件。
